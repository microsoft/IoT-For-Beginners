# నేల తేమ కొలవండి - రాస్ప్బెర్రీ పై

పాఠం యొక్క ఈ భాగంలో, మీరు మీ రాస్ప్బెర్రీ పైకి ఒక కాపాసిటివ్ సాయిల్ మాయిచర్ సెన్సర్ ను జత చేస్తారు, మరియు దానినుండి విలువలను చదువుతారు.

## హార్డ్‌వేర్

రాస్ప్బెర్రీ పైకి ఒక కాపాసిటివ్ సాయిల్ మాయిచర్ సెన్సర్ అవసరం.

మీరు ఉపయోగించబోయే సెన్సర్ ఒక [కాపాసిటివ్ సాయిల్ మాయిచర్ సెన్సర్](https://www.seeedstudio.com/Grove-Capacitive-Moisture-Sensor-Corrosion-Resistant.html), ఇది నేల యొక్క కాపాసిటెన్స్ ను గుర్తించి నేల తేమను కొలుస్తుంది, నేల తేమ మారిపోయినట్లు ఈ లక్షణం మారుతుంది. నేల తేమ పెరుగుతుండగా, వోల్టేజ్ తగ్గుతుంది.

ఇది ఒక అనలాగ్ సెన్సర్, కాబట్టి అనలాగ్ పిన్ ఉపయోగిస్తుంది, మరియు Pi పై ఉన్న Grove Base Hat లోని 10-బిట్ ADC ను వోల్టేజ్ ను 1-1,023 మధ్య డిజిటల్ సంకేతంగా మార్చడానికి ఉపయోగిస్తుంది. ఇది తర్వాత I<sup>2</sup>C మార్గంగా Pi పైని GPIO పిన్ల ద్వారా పంపబడుతుంది.

### నేల తేమ సెన్సర్ కనెక్ట్ చేయండి

Grove నేల తేమ సెన్సర్ ను రాస్ప్బెర్రీ పైకు కనెక్ట్ చేయవచ్చు.

#### పని - నేల తేమ సెన్సర్ కనెక్ట్ చేయండి

నేల తేమ సెన్సర్ ను కనెక్ట్ చేయండి.

![A grove soil moisture sensor](../../../../../translated_images/te/grove-capacitive-soil-moisture-sensor.e7f0776cce30e78b.png)

1. Grove కేబుల్ యొక్క ఒక చివరను నేల తేమ సెన్సర్‌పై ఉన్న సాకెట్‌కి పెట్టండి. ఇది ఒక దిశలో మాత్రమే సరిపోతుంది.

1. రాస్ప్బెర్రీ పై పవర్ ఆఫ్ ఉన్నప్పుడు, Grove కేబుల్ యొక్క మరొక చివరను Pi కు జతచేసిన Grove Base Hat పై **A0** అనే అనలాగ్ సాకెట్‌కు కనెక్ట్ చేయండి. ఈ సాకెట్ GPIO పిన్ల పక్కన ఉన్న సాకెట్ల వరుసలో రెండవది వెనుక నుండి.

![The grove soil moisture sensor connected to the A0 socket](../../../../../translated_images/te/pi-soil-moisture-sensor.fdd7eb2393792cf6.png)

1. నేల తేమ సెన్సర్ ను నేలలో చొప్పించండి. దానిపై 'highest position line' అనే గమనార్హమైన పుంత ఉంది - ఇది సెన్సర్ అంతటా ఒక తెలుపు రేఖ. ఈ రేఖ దాటకుండా సెన్సర్ ను చొప్పించండి.

![The grove soil moisture sensor in soil](../../../../../translated_images/te/soil-moisture-sensor-in-soil.bfad91002bda5e96.png)

## నేల తేమ సెన్సర్ ప్రోగ్రాం చేయండి

రాస్ప్బెర్రీ పై ఇప్పటికే జత చేసిన నేల తేమ సెన్సర్ ను ఉపయోగించి ప్రోగ్రాం చేయవచ్చు.

### పని - నేల తేమ సెన్సర్ ప్రోగ్రాం చేయండి

పరికరాన్ని ప్రోగ్రామ్ చేయండి.

1. Pi ని పవర్ ఆన్ చేసి ఓదార్చుకోండి

1. VS Code ను ప్రారంభించండి, నేరుగా Pi పై లేదా Remote SSH విస్తరణ ద్వారా కనెక్ట్ అవ్వండి.

    > ⚠️ అవసరమైతే [nightlight - పాఠం 1 లో VS Code సెట్ అప్లు మరియు ప్రారంభం పై సూచనలను](../../../1-getting-started/lessons/1-introduction-to-iot/pi.md) చూడవచ్చు.

1. టెర్మినల్ నుండి, `pi` యూజర్ హోమ్ డైరెక్టరీలో `soil-moisture-sensor` అనే కొత్త ఫోల్డర్ సృష్టించండి. ఈ ఫోల్డర్ లో `app.py` అనే ఫైల్ ని సృష్టించండి.

1. ఈ ఫోల్డర్ ను VS Code లో తెరవండి

1. కొన్ని అవసరమైన లైబ్రరీలు ఇంపోర్ట్ చేయడానికి `app.py` ఫైల్ లో క్రింది కోడ్ జోడించండి:

    ```python
    import time
    from grove.adc import ADC
    ```

    `import time` స్టేట్‌మెంట్ ఈ అసైన్మెంట్‌లో తర్వాత ఉపయోగించబడే `time` మాడ్యూల్ను ఇంపోర్ట్ చేస్తుంది.

    `from grove.adc import ADC` స్టేట్‌మెంట్ Grove పైథాన్ లైబ్రరీల నుండి `ADC` ను ఇంపోర్ట్ చేస్తుంది. ఈ లైబ్రరీ Pi బేస్ హాట్ పై అనలాగ్-టు-డిజిటల్ కన్వర్టర్‌తో ఇంటరాక్ట్ చేయడానికి మరియు అనలాగ్ సెన్సర్ల నుండి వోల్టేజ్‌లు చదవడానికి కోడ్ కలిగి ఉంటుంది.

1. ఈ క్రింద క్రింది కోడ్ జోడించి `ADC` క్లాస్ యొక్క ఒక ఇన్స్టాన్స్ సృష్టించండి:

    ```python
    adc = ADC()
    ```

1. A0 పిన్ పై ఈ ADC నుండి చదువుతో ముట్టడి లూప్ తయారు చేసి మెరుగైన console కు ఫలితాన్ని రాయండి. ఈ లూప్ 10 సెకన్ల అంతరాలుగా చదవటం తర్వాత నిద్రలో పడుతుంది.

    ```python
    while True:
        soil_moisture = adc.read(0)
        print("Soil moisture:", soil_moisture)

        time.sleep(10)
    ```

1. Python యాప్ నడిపించండి. మీరు సాయిల్ మాయిచర్ కొలతలు కన్సోల్‌లో లిఖితమయ్యేలా చూస్తారు. నేలకి కొంత నీరు పోసి లేదా సెన్సర్‌ను నేల నుండి తీసివేస్తే విలువ బదిలీ అవుతుందని చూడండి.

    ```output
    pi@raspberrypi:~/soil-moisture-sensor $ python3 app.py 
    Soil moisture: 615
    Soil moisture: 612
    Soil moisture: 498
    Soil moisture: 493
    Soil moisture: 490
    Soil Moisture: 388
    ```

    పై ఉదాహరణలలో, మీరు నీరు పోశాక వోల్టేజ్ తగ్గడం చూడవచ్చు.
