# రాత్రి దీపం రూపొందించండి - రాస్బెర్రీ పై

ఈ పాఠం భాగంలో, మీరు మీ రాస్బెర్రీ పైకి లైట్ సెన్సార్‌ను జోడించనున్నారు.

## హార్డ్వేర్

ఈ పాఠం కోసం ఉపయోగించే సెన్సార్ ఒక **లైట్ సెన్సార్** ఇది కాంతిని ఇలెక్ట్రికల్ సిగ్నల్‌గా మారుస్తుంది, దీని కోసం [photodiode](https://wikipedia.org/wiki/Photodiode) ను ఉపయోగిస్తారు. ఇది ఒక అనలాగ్ సెన్సార్, ఇది 0 నుండి 1,000 మధ్య ఒక పూర్తి సం��్యం మెప్పును పంపుతుంది, ఇది [lux](https://wikipedia.org/wiki/Lux) వంటి ఎటువంటి ప్రమాణ యూనిట్‌కు సరిపోలదు.

లైట్ సెన్సార్ ఒక బాహ్య Grove సెన్సార్ మరియు రాస్బెర్రీ పైపై Grove బేస్ హ్యాట్‌కు కనెక్ట్ చేయాలి.

### లైట్ సెన్సార్ జోడించండి

కాంతి స్థాయిలను గుర్తించడానికి ఉపయోగించే Grove లైట్ సెన్సార్ రాస్బెర్రీ పైకు జోడించాలి.

#### పనితీరు - లైట్ సెన్సార్‌ను జోడించండి

లైట్ సెన్సార్‌ను జోడించండి

![A grove light sensor](../../../../../translated_images/te/grove-light-sensor.b8127b7c434e632d.png)

1. Grove కేబుల్ ఒక చివరను లైట్ సెన్సార్ మాడ్యూల్ సాకెట్‌లో చేర్చండి. ఇది ఒక దిశలో మాత్రమే చేర్చబడుతుంది.

1. రాస్బెర్రీ పై పవర్ ఆఫ్ ఉన్నప్పుడు, Grove కేబుల్ యొక్క మరొక చివరను Pi కి సంలగ్నమైన Grove బేస్ హ్యాట్ పై **A0** గుర్తుతో ఉన్న అనలాగ్ సాకెట్‌కు కనెక్ట్ చేయండి. ఈ సాకెట్ రైట్ నుండి రెండోది, GPIO పిన్ల పక్కన ఉన్న సాకెట్స్ వరుసలో.

![The grove light sensor connected to socket A0](../../../../../translated_images/te/pi-light-sensor.66cc1e31fa48cd7d.png)

## లైట్ సెన్సార్ ప్రోగ్రామ్ చేయండి

గ్రోవ్ లైట్ సెన్సార్ ఉపయోగించి డివైస్‌ను ఇప్పుడు ప్రోగ్రామ్ చేయవచ్చు.

### పనితీరు - లైట్ సెన్సార్ ప్రోగ్రామ్ చేయండి

డివైస్‌ను ప్రోగ్రామ్ చేయండి.

1. పై పవర్ ఆన్ చేసి, అది బూట్ అవ్వటానికి వేచి ఉండండి

1. గత భాగంలో మీరు సృష్టించిన నైట్‌లైట్ ప్రాజెక్ట్‌ను Pi లో నేరుగా లేదా Remote SSH ఎక్స్‌టెన్షన్ ఉపయోగించి కనెక్ట్ అయి VS Code లో తెరవండి.

1. `app.py` ఫైల్‌ను తెరిచి అందులోని అన్ని కోడ్‌ను తొలగించండి

1. క్రింది కోడ్‌ను `app.py` లో జత చేసి కొన్ని అవసరమైన లైబ్రరీలను ఇంపోర్ట్ చేయండి:

    ```python
    import time
    from grove.grove_light_sensor_v1_2 import GroveLightSensor
    ```

    `import time` స్టేట్‌మెంట్ `time` మాడ్యూల్‌ను ఇంపోర్ట్ చేస్తుంది, దీన్ని ఈ అసైన్‌మెంట్‌లో తరువాత ఉపయోగిస్తారు.

    `from grove.grove_light_sensor_v1_2 import GroveLightSensor` స్టేట్‌మెంట్ Grove Python లైబ్రరీల నుండి `GroveLightSensor` ను ఇంపోర్ట్ చేస్తుంది. ఈ లైబ్రరీ Grove లైట్ సెన్సార్ తో ఇంటరాక్ట్ చేసే కోడ్ కలిగి ఉంటుంది మరియు Pi సెటప్ సమయంలో గ్లోబల్గా ఇన్‌స్టాల్ అయింది.

1. పై కోడ్‌ తర్వాత క్రింది కోడ్‌ను జత చేసి లైట్ సెన్సార్‌ను నిర్వహించే క్లాస్ యొక్క ఒక ఇన్స్టెన్స్‌ని సృష్టించు:

    ```python
    light_sensor = GroveLightSensor(0)
    ```

    `light_sensor = GroveLightSensor(0)` లైన్ అనేది **A0** - లైట్ సెన్సార్ కనెక్ట్ అయిన అనలాగ్ Grove పిన్‌కి కనెక్ట్ అయ్యే `GroveLightSensor` క్లాస్ ఇన్స్టెన్స్‌ను సృష్టిస్తుంది.

1. పై కింది కోడ్ తర్వాత ఒక అనంత లూప్ జత చేయండి, ఇది లైట్ సెన్సార్ విలువను పోల్చి కన్సోల్ లో ప్రింట్ చేస్తుంది:

    ```python
    while True:
        light = light_sensor.light
        print('Light level:', light)
    ```

    ఇది `GroveLightSensor` క్లాస్ యొక్క `light` ప్రాపర్టీ ఉపయోగించి 0-1,023 స్కేల్ లో ప్రస్తుత కాంతి స్థాయి ను చదివి, అనలాగ్ విలువను పిన్ నుండి పొందుతుంది. ఆ విలువను కన్సోల్ లో ప్రింట్ చేస్తుంది.

1. ఈ లూప్ చివరలో ఒక సెకను చిన్న నిద్ర ఉంచండి, ఎందుకంటే కాంతి స్థాయులు నిరంతరం తనిఖీ చేయాల్సిన అవసరం లేదు. నిద్ర ఉంచడముతో పరికరం పవర్ వినియోగం తగ్గుతుంది.

    ```python
    time.sleep(1)
    ```

1. VS Code టెర్మినల్ నుండి, మీ Python యాప్ ని ఎగ్జిక్యూట్ చేయడానికి క్రింది కమాండ్ నడిపించండి:

    ```sh
    python3 app.py
    ```

    లైట్ విలువలు కన్సోల్ కు అవుట్పుట్ అవుతుంటాయి. లైట్ సెన్సార్‌ను మూసి, తెరిచి చూస్తే విలువలు మారతాయి:

    ```output
    pi@raspberrypi:~/nightlight $ python3 app.py 
    Light level: 634
    Light level: 634
    Light level: 634
    Light level: 230
    Light level: 104
    Light level: 290
    ```
