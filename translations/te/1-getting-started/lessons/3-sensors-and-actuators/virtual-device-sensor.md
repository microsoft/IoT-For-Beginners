# రాత్రిపువ్వును నిర్మించండి - వర్చువల్ IoT హార్డ్వేర్

పాఠ్యభాగంలో, మీరు మీ వర్చువల్ IoT పరికరంలో ఒక లైట్ సెన్సార్‌ను జత చేస్తారు.

## వర్చువల్ హార్డ్వేర్

నైట్‌లైట్‌కు ఒక సెన్సార్ అవసరం, ఇది CounterFit యాప్‌లో సృష్టించబడింది.

ఆ సెన్సార్ **లైట్ సెన్సార్**. ఒక భౌతిక IoT పరికరంలో ఇది ఒక [ఫోటోడయోడ్](https://wikipedia.org/wiki/Photodiode) అయి, ఇది కాంతిని ఎలక్ట్రికల్ సిగ్నల్‌గా మారుస్తుంది. లైట్ సెన్సార్లు అనలాగ్ సెన్సార్లు, ఇవి ఒక ఇంటిజర్ విలువను పంపుతాయి, అది కాంతి యొక్క సంబంధిత పరిమాణాన్ని సూచిస్తుంది, ఇది [లక్స్](https://wikipedia.org/wiki/Lux) వంటి ఏ స్థాయి కొలమానం మాత్రం కాదు.

### సెన్సార్లను CounterFit లో జత చేయండి

వర్చువల్ లైట్ సెన్సార్‌ను ఉపయోగించాలంటే, దాన్ని CounterFit యాప్‌లో జత చేయాలి

#### పని - సెన్సార్లను CounterFit లో జత చేయండి

లైట్ సెన్సార్‌ను CounterFit యాప్‌లో జత చేయండి.

1. ఈ అప్పటివరకు జరిగిందని CounterFit వెబ్ యాప్ నడుస్తుందో లేదో చూసుకోండి. లేకపోతే, ప్రారంభించండి.

1. లైట్ సెన్సార్ సృష్టించండి:

    1. *Create sensor* పెట్టెలో, *Sensors* ప్యానెల్లో, *Sensor type* డ్రాప్‌డౌన్ బాక్సుకు పోయి *Light* ఎంచుకోండి.

    1. *Units* ను *NoUnits* గా ఉంచండి

    1. *Pin* 0 గా సెట్ చేయబడినదని నిర్ధారించండి

    1. పిన్ 0 లో లైట్ సెన్సార్ సృష్టించడానికి **Add** బటన్‌ను ఎంచుకోండి

    ![The light sensor settings](../../../../../translated_images/te/counterfit-create-light-sensor.9f36a5e0d4458d8d.png)

    లైట్ సెన్సార్ సృష్టించబడుతుంది మరియు సెన్సార్ల జాబితాలో కనిపిస్తుంది.

    ![The light sensor created](../../../../../translated_images/te/counterfit-light-sensor.5d0f5584df56b90f.png)

## లైట్ సెన్సార్‌ను ప్రోగ్రామ్ చేయండి

పరికరం ఇప్పుడు బిల్ట్-ఇన్ లైట్ సెన్సార్ ఉపయోగించటానికి ప్రోగ్రామ్ చేయబడొచ్చు.

### పని - లైట్ సెన్సార్‌ను ప్రోగ్రామ్ చేయండి

పరికరాన్ని ప్రోగ్రామ్ చేయండి.

1. మీరు ముందు భాగంలో సృష్టించిన నైట్‌లైట్ ప్రాజెక్ట్‌ను VS కోడ్‌లో తెరిచి, టర్మినల్‌ను పునఃప్రారంభించండి. అవసరమైతే వర్చువల్ వాతావరణం ఉపయోగించి నడిచేలా చేయండి.

1. `app.py` ఫైల్‌ను తెరిచి

1. `app.py` ఫైల్ టాప్‌లో, ఇతర `import` స్టేట్మెంట్లతో పాటు, క్రింది కోడ్ జత చేయండి, కొన్ని అవసరమైన లైబ్రరీలను కనెక్ట్ చేసేందుకు:

    ```python
    import time
    from counterfit_shims_grove.grove_light_sensor_v1_2 import GroveLightSensor
    ```

    `import time` స్టేట్మెంట్ పిథాన్ `time` మాడ్యుల్‌ను దిగుమతి చేస్తుంది, ఇది ఈ అసైన్‌మెంట్‌లో తర్వాత ఉపయోగించబడుతుంది.

    `from counterfit_shims_grove.grove_light_sensor_v1_2 import GroveLightSensor` స్టేట్మెంట్ CounterFit Grove షిమ్ పిథాన్ లైబ్రరీల నుండి `GroveLightSensor` ని దిగుమతి చేస్తుంది. ఈ లైబ్రరీ CounterFit యాప్‌లో సృష్టించిన లైట్ సెన్సార్‌తో ఇంటరాక్ట్ చేసే కోడ్‌ను కలిగి ఉంటుంది.

1. ఫైల్ దిగువకు, లైట్ సెన్సార్‌ని నిర్వహించే క్లాసుల ఇన్స్టాన్సులను క్రియేట్ చేయడానికి క్రింది కోడ్ జత చేయండి:

    ```python
    light_sensor = GroveLightSensor(0)
    ```

    `light_sensor = GroveLightSensor(0)` లైన్ `GroveLightSensor` క్లాస్‌ ఒక ఇన్స్టాన్స్‌ని సృష్టిస్తుంది, ఇది పిన్ **0** తో కనెక్ట్ అవుతుంది - ఇది లైట్ సెన్సార్ కనెక్ట్ అయ్యిన CounterFit Grove పిన్.

1. పై కోడ్ తర్వాత ఒక అనంతం లూప్ జత చేయండి, ఇది లైట్ సెన్సార్ విలువను పీడించడానికి మరియు కాన్సోల్‌లో ప్రింట్ చేయడానికి ఉపయోగిస్తుందని:

    ```python
    while True:
        light = light_sensor.light
        print('Light level:', light)
    ```

    ఇది `GroveLightSensor` క్లాస్‌లోని `light` ప్రాపర్టీ ఉపయోగించి ప్రస్తుత కాంతి స్థాయిని చదువుతుంది. ఈ ప్రాపర్టీ అనలాగ్ విలువను పిన్ నుంచి చదువుతుంది. ఆ విలువ తరువాత కాన్సోల్‌లో ప్రింట్ చేయబడుతుంది.

1. `while` లూప్ చివర ఒక సెకన్ చిన్న స్లీప్‌ను జత చేయండి ఎందుకంటే కాంతి స్థాయిలను నిరంతరంగా తనిఖీ చేయాల్సిన అవసరం లేదు. ఇది పరికరం శక్తి వినియోగాన్ని తగ్గిస్తుంది.

    ```python
    time.sleep(1)
    ```

1. VS కోడ్ టర్మినల్ నుండి, మీ పిథాన్ యాప్‌ని నడపడానికి క్రింది కమాండ్ నిర్వహించండి:

    ```sh
    python3 app.py
    ```

    కాంతి విలువలు కాన్సోల్‌కు అవుట్‌పుట్ అవుతాయి. ప్రారంభంలో ఈ విలువ 0 ఉంటుంది.

1. CounterFit యాప్ నుండి, యాప్ చదివే లైట్ సెన్సార్ యొక్క విలువను మార్చండి. మీరు దీన్ని రెండు విధాలుగా చేయవచ్చు:

    * లైట్ సెన్సార్ కోసం *Value* పెట్టెలో సంఖ్యను ఎంటర్ చేసి, ఆపై **Set** బటన్‌ను ఎంచుకోండి. మీరు ఎంటర్ చేసిన సంఖ్య సెన్సార్ ద్వారా తిరిగిచ్చే విలువ అవుతుంది.

    * *Random* చెక్బాక్స్‌ని టిక్ చేసి, ఒక *Min* మరియు *Max* విలువను ఎంటర్ చేసి, ఆపై **Set** బటన్‌ను ఎంచుకోండి. ప్రతి సారి సెన్సార్ విలువను చదవగానే, అది *Min* మరియు *Max* మధ్య ఒక యాదృచ్ఛిక సంఖ్యను చదువుతుంది.

    మీరు సెట్ చేసిన విలువలు కాన్సోల్‌కు అవుట్‌పుట్ అవుతాయి. విలువ లేదా రాండమ్ సెట్టింగ్స్ మార్చి విలువ మార్చండి.

    ```output
    (.venv) ➜  GroveTest python3 app.py 
    Light level: 143
    Light level: 244
    Light level: 246
    Light level: 253
    ```
