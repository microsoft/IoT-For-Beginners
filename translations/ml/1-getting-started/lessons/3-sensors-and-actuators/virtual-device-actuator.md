# ഒരു നൈറ്റ്‌ലൈറ്റ് നിർമ്മിക്കുക - വിർച്വൽ ഇന്റർനെറ്റ് ഓഫ് തിംഗ്‌സ് ഹാർഡ്‌വെയർ

പാഠത്തിന്റെ ഈ ഭാഗത്തിൽ, നിങ്ങൾക്ക് നിങ്ങളുടെ വിർച്വൽ IoT ഉപകരണത്തിൽ ഒരു LED ചേർക്കുകയും അതുപയോഗിച്ച് ഒരു നൈറ്റ്‌ലൈറ്റ് സൃഷ്ടിക്കുകയും ചെയ്യും.

## വിർച്വൽ ഹാർഡ്‌വെയർ

നൈറ്റ്‌ലൈറ്റിന് ഒരു ആക്ചുവേറ്റർ വേണം, അത് CounterFit ആപ്പിൽ സൃഷ്ടിക്കപ്പെട്ടതാണ്.

ആ ആക്ചുവേറ്റർ ഒരു **LED** ആണ്. ഫിസിക്കൽ IoT ഉപകരണത്തിൽ, ഇത് കറന്റ് ഒഴുക്കുമ്പോൾ പ്രകാശം പുറത്തുവിടുന്ന [ലൈറ്റ്-എമിറ്റിംഗ് ഡി ഒഡ്](https://wikipedia.org/wiki/Light-emitting_diode) ആയിരിക്കും. ഇത് രണ്ട് നിലകളുള്ള ഡിജിറ്റൽ ആക്ചുവേറ്ററാണ്, ഓണും ഓഫ് എന്നിവ. 1 എന്ന മൂല്യം അയച്ചാൽ LED ഓണാവുകയും, 0 അയച്ചാൽ ഓഫ് ആകുകയും ചെയ്യും.

നൈറ്റ്‌ലൈറ്റിന്റെ ലജിക് പseudo-കോഡിൽ:

```output
Check the light level.
If the light is less than 300
    Turn the LED on
Otherwise
    Turn the LED off
```

### ആക്ചുവേറ്റർ CounterFit-ലേക്ക് ചേർക്കുക

വിർച്വൽ LED ഉപയോഗിക്കാൻ, അത് CounterFit ആപ്പിൽ ചേർക്കേണ്ടതുണ്ട്

#### টാസ്ക് - ആക്ചുവേറ്റർ CounterFit-ലേക്ക് ചേർക്കുക

LED CounterFit ആപ്പിൽ ചേർക്കുക.

1. മുൻപത്തെ ഭാഗത്തെ ഈ അസൈൻമെന്റിന്റെ ഭാഗമായിട്ടുള്ള CounterFit വെബ് ആപ്പ് പ്രവർത്തിക്കുന്നുണ്ടെന്ന് ഉറപ്പാക്കുക. ഇല്ലെങ്കിൽ, ആപ് തുടങ്ങി ലൈറ്റ് സെൻസർ റീ-ആഡ് ചെയ്യുക.

1. ഒരു LED സൃഷ്ടിക്കുക:

    1. *Actuator* പെയ്നിൽ ഉള്ള *Create actuator* ബോക്സിൽ, *Actuator type* ബോക്സിൽ നിന്ന് താഴ്ച്ചയിൽ *LED* തിരഞ്ഞെടുക്കുക.

    1. *Pin* ആയിട്ടു *5* സെറ്റ് ചെയ്യുക

    1. Pin 5-ൽ LED സൃഷ്ടിക്കാൻ **Add** ബട്ടൺ ക്ലിക്ക് ചെയ്യുക

    ![LED സെറ്റിംഗുകൾ](../../../../../translated_images/ml/counterfit-create-led.ba9db1c9b8c622a6.png)

    LED സൃഷ്ടിച്ചപ്പോൾ, അത് ആക്ചുവേറ്ററുകളുടെ പട്ടികയിൽ തോന്നും.

    ![LED സൃഷ്ടിച്ചു](../../../../../translated_images/ml/counterfit-led.c0ab02de6d256ad8.png)

    LED സൃഷ്ടിച്ചതിന് ശേഷമുള്ള *Color* പിക്കർ ഉപയോഗിച്ച് ഫർണിച്ചറിന്റെ നിറം മാറ്റാം. തിരഞ്ഞെടുക്കildതിനു ശേഷം **Set** ബട്ടൺ അമർത്തുക.

### നൈറ്റ്‌ലൈറ്റ് പ്രോഗ്രാം ചെയ്യുക

നൈറ്റ്‌ലൈറ്റിനെ CounterFit ലൈറ്റ് സെൻസർ, LED എന്നിവ ഉപയോഗിച്ച് പ്രോഗ്രാം ചെയ്യാം.

#### ടാസ്ക് - നൈറ്റ്‌ലൈറ്റ് പ്രോഗ്രാം ചെയ്യുക

നൈറ്റ്‌ലൈറ്റ് പ്രോഗ്രാം ചെയ്യുക.

1. മുൻപുള്ള പകുതിയിൽ സൃഷ്ടിച്ച VS Code ലെ നൈറ്റ്‌ലൈറ്റ് പ്രോജക്ട് തുറക്കുക. ആവശ്യമെങ്കിൽ ടെർമിനൽ കഴിഞ്ഞ് വീണ്ടെടുക്കുക, വെർച്വൽ എൻവയോൺമെന്റ് ഉപയോഗിച്ച് പ്രവർത്തിക്കുന്നുവെന്ന് ഉറപ്പാക്കുക.

1. `app.py` ഫയൽ തുറക്കുക

1. വേണ്ട ലൈബ്രറി ഇറക്കുമതി ചെയ്യുന്നതിനുള്ള കോഡ് `app.py` ലെ മുകളിൽ, മറ്റു `import` വരികൾക്കു താഴെ ചേർക്കുക:

    ```python
    from counterfit_shims_grove.grove_led import GroveLed
    ```

    `from counterfit_shims_grove.grove_led import GroveLed` എന്ന സ്റ്റേറ്റ്‌മെന്റ് CounterFit Grove ഷിം പൈഥൺ ലൈബ്രറികളിൽ നിന്നുള്ള `GroveLed` ഇറക്കുമതി ചെയ്യുന്നു. ഈ ലൈബ്രറിയിൽ CounterFit ആപ്പിൽ സൃഷ്ടിച്ച LED-നൊപ്പം ഇടപഴകാനുള്ള കോഡ് ഉണ്ട്.

1. `light_sensor` ഡെക്ലറേഷനു ശേഷം LED നു മറുപുറത്തും നോക്കാനുള്ള ക്ലാസിന്റെ ഒരു ഇൻസ്റ്റൻസ് സൃഷ്ടിക്കാൻ താഴെ നൽകിയ കോഡ് ചേർക്കുക:

    ```python
    led = GroveLed(5)
    ```

    `led = GroveLed(5)` വരി, പിന് **5**-ൽ കണക്ട് ചെയ്ത CounterFit Grove LED നെ നിയന്ത്രിക്കുന്ന `GroveLed` ക്ലാസിന്റെ ഒരു ഇൻസ്റ്റൻസ് സൃഷ്ടിക്കുന്നു.

1. `while` ലൂപ്പിനകത്തെ, `time.sleep` മുൻപ്, ലൈറ്റ് നില നിയന്ത്രിച്ച് LED ഓണാക്കാനോ ഓഫ് ആക്കാനോ പരിശോധിക്കുന്ന ചോക്ക് ചേർക്കുക:

    ```python
    if light < 300:
        led.on()
    else:
        led.off()
    ```

    ഈ കോഡ് `light` മൂല്യം പരിശോധിക്കുന്നു. ഇത് 300-ൽ കുറഞ്ഞാൽ `GroveLed` ക്ലാസ്സിലെ `on` മെത്തോഡ് വിളിക്കുന്നു, ഇത് LED-ന് 1 എന്ന ഡിജിറ്റൽ മൂല്യം അയைத்து LED ഓണാക്കും. ലൈറ്റ് മൂല്യം 300-യെക്കാൾ തുല്യം അല്ലെങ്കിൽ കൂടുതലെങ്കിൽ, `off` മെത്തോഡ് വിളിക്കും, 0 മൂല്യം LED-ന് അയച്ച് ഓഫ് ചെയ്യും.

    > 💁 ഈ കോഡ് `print('Light level:', light)` എന്ന വരിയുടെ സമാനതലത്തിൽ ഇൻഡെന്റ് ചെയ്യണം, അതിനാൽ അത് while ലൂപ്പിനകത്താകും!

1. VS Code ടെർമിനലിൽ നിന്ന്, നിങ്ങളുടെ Python ആപ്പ് പ്രവർത്തിപ്പിക്കാൻ താഴെ കൊടുത്തത് റൺ ചെയ്യുക:

    ```sh
    python3 app.py
    ```

    ലൈറ്റ് മൂല്യങ്ങൾ കൺസോളിലേക്ക് പുറത്തുവരും.

    ```output
    (.venv) ➜  GroveTest python3 app.py 
    Light level: 143
    Light level: 244
    Light level: 246
    Light level: 253
    ```

1. ലൈറ്റ് നില 300നും മുകളിലും താഴെയും മാറുന്നതിനായി *Value* അല്ലെങ്കിൽ *Random* സെറ്റിംഗുകൾ മാറ്റുക. LED ഓൺ-ഓഫ് ആവുന്നതായി കാണാം.
