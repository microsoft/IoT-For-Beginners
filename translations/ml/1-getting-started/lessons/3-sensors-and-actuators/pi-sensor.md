# ഒരു നൈറ്റ്‌ലൈറ്റ് നിർമ്മിക്കുക - റാസ്പ്ബെറി പൈ

പാഠത്തിന്റെ ഈ ഭാഗത്തിൽ, നിങ്ങൾ റാസ്പ്ബെറി പൈയോട് ഒരു ലൈറ്റ് സെൻസർ ചേർക്കും.

## ഹാർഡ്‌വെയർ

ഈ പാഠത്തിനായുള്ള സെൻസർ ഒരു **ലൈറ്റ് സെൻസർ** ആണ്, ഇത് പ്രകാശത്തെ വൈദ്യുത സിഗ്നലായി മാറ്റാൻ [ഫോട്ടോഡയോഡ്](https://wikipedia.org/wiki/Photodiode) ഉപയോഗിക്കുന്നു. ഇത് ഒരു അനലോഗ് സെൻസർ ആണ്, ഇത് 0 മുതൽ 1,000 വരെയുള്ള പൂർണ്ണസംഖ്യ മൂല്യം അയയ്ക്കുന്നു, ഇത് ഒരു സാദാരണം അളവിന്റെ യൂണിറ്റായ [ലക്സ്](https://wikipedia.org/wiki/Lux) പോലുള്ള ഏതെങ്കിലും സ്റ്റാൻഡേർഡ് അളവിന്റെ മാനദണ്ഡങ്ങൾ ഉൾക്കൊള്ളുന്നില്ല.

ലൈറ്റ് സെൻസർ ഒരു എക്സ്റ്റേണൽ ഗ്രേവ് സെൻസറാണ്, ഇത് റാസ്പ്ബെറി പൈയിലെ ഗ്രേവ് ബേസ് ഹാറ്റിൽ കണക്ട് ചെയ്യേണ്ടതാണ്.

### ലൈറ്റ് സെൻസർ കണക്ട് ചെയ്യുക

പ്രകാശത്തിന്റെ നിലകൾ കണ്ടെത്താൻ ഉപയോഗിക്കുന്ന ഗ്രേവ് ലൈറ്റ് സെൻസർ റാസ്പ്ബെറി പൈയുമായി കണക്ട് ചെയ്യേണ്ടതാണ്.

#### ടാസ്ക് - ലൈറ്റ് സെൻസർ കണക്ട് ചെയ്യുക

ലൈറ്റ് സെൻസർ കണക്ട് ചെയ്യുക

![ഒരു ഗ്രേവ് ലൈറ്റ് സെൻസർ](../../../../../translated_images/ml/grove-light-sensor.b8127b7c434e632d.png)

1. ഗ്രേവ് കേബിളിന്റെ ഒരു അറ്റം ലൈറ്റ് സെൻസർ മോഡ്യൂളിലെ സോക്കറ്റിലേക്ക് ഏർപ്പെടുത്തുക. ഇത് ഒരു ദിശയിൽ മാത്രമേ പ്രവേശിക്കുകയുള്ളൂ.

1. റാസ്പ്ബെറി പൈ ഓഫായിരിക്കുമ്പോൾ, ഗ്രേവ് കേബിളിന്റെ മിന്ന് അറ്റം Pi-യിൽ ലഗിപ്പിച്ചിരിക്കുന്ന ഗ്രേവ് ബേസ് ഹാറ്റിലെ **A0** എന്ന് അടയാളപ്പെടുത്തിയ അനലോഗ് സോക്കറ്റിൽ കണക്ട് ചെയ്യുക. ഈ സോക്കറ്റ് GPIO പിനുകളോട് അടുത്തുള്ള സോക്കറ്റുകളുടെ വരിയിൽ മ രാജ്യത്തെ സർക്കാർ.

![ഗ്രോവ് ലൈറ്റ് സെൻസർ A0 സോക്കറ്റിൽ കണക്ട് ചെയ്തിരിക്കുന്നു](../../../../../translated_images/ml/pi-light-sensor.66cc1e31fa48cd7d.png)

## ലൈറ്റ് സെൻസർ പ്രോഗ്രാം ചെയ്യുക

ഇപ്പോൾ ഗ്രേവ് ലൈറ്റ് സെൻസർ ഉപയോഗിച്ച് ഉപകരണം പ്രോഗ്രാം ചെയ്യാൻ സാധിക്കും.

### ടാസ്ക് - ലൈറ്റ് സെൻസർ പ്രോഗ്രാം ചെയ്യുക

ഉപകരണം പ്രോഗ്രാം ചെയ്യുക.

1. പൈ പവർ ഓണാക്കി ബൂട്ട്അപ്പ് വരെ കാത്തിരിക്കുക

1. മുമ്പത്തെ ഭാഗത്തിൽ നിങ്ങൾ ഒരുക്കിയ നൈറ്റ്‌ലൈറ്റ് പ്രോജക്റ്റ് VS Code-ൽ തുറക്കുക, ഇത് പൈയിൽ നേരിട്ട് ഓടിക്കോ അല്ലെങ്കിൽ റിമോട്ട് SSH എക്സ്റ്റെൻഷൻ ഉപയോഗിച്ച് കണക്ട് ചെയ്തിരിക്കാം.

1. `app.py` ഫയൽ തുറന്ന് അതിലെ എല്ലാ കോഡ് നീക്കം ചെയ്യുക

1. ആവശ്യമായ ലൈബ്രറികൾ ഇറക്കുമതി ചെയ്യാൻ താഴെയുള്ള കോഡ് `app.py` ൽ ചേർക്കുക:

    ```python
    import time
    from grove.grove_light_sensor_v1_2 import GroveLightSensor
    ```

    `import time` സ്റ്റേറ്റ്മെന്റ് പിന്നീട് ഈ അസൈൻമെന്റിൽ ഉപയോഗിക്കുന്ന `time` മോഡ്യൂൾ ഇറക്കുമതി ചെയ്യുന്നു.

    `from grove.grove_light_sensor_v1_2 import GroveLightSensor` സ്റ്റേറ്റ്മെന്റ് Grove Python ലൈബ്രറികളിൽ നിന്നുള്ള `GroveLightSensor` ഇറക്കുമതി ചെയ്യുന്നു. ഈ ലൈബ്രറിയിൽ ഗ്രേവ് ലൈറ്റ് സെൻസറുമായുള്ള ഇടപെടലുകൾക്കുള്ള കോഡ് ഉൾക്കൊള്ളുന്നു, ഇത് പൈ സജ്ജീകരണത്തിനിടയിൽ ഗ്ലോബലായി ഇൻസ്റ്റാൾ ചെയ്തു.

1. ലൈറ്റ് സെൻസർ നിയന്ത്രിക്കുന്ന ക്ലാസിന്റ انس്ടൻസ് സൃഷ്ടിക്കാൻ മുകളിലുള്ള കോഡിന് ശേഷം താഴെയുള്ള കോഡ് ചേർക്കുക:

    ```python
    light_sensor = GroveLightSensor(0)
    ```

    `light_sensor = GroveLightSensor(0)` എന്ന വരി ക്ലാസ് `GroveLightSensor` യുടെ انس്ടൻസ് സൃഷ്ടിച്ചു, അതിൽ പിനായി **A0** ഉപയോഗിക്കുന്നു - ഇത് അനലോഗ് ഗ്രേവ് പിനാണ് ലൈറ്റ് സെൻസർ കണക്ട് ചെയ്തിരിക്കുന്നത്.

1. ലൈറ്റ് സെൻസർ മൂല്യം പൊള്ള് ചെയ്ത് കൺസോളിൽ പ്രിന്റ് ചെയ്യാൻ മുകളിലുള്ള കോഡിന് ശേഷം ഒരു അനന്ത ലൂപ് ചേർക്കുക:

    ```python
    while True:
        light = light_sensor.light
        print('Light level:', light)
    ```

    ഇത് `GroveLightSensor` ക്ലാസിന്റെ `light` പ്രൊപ്പർട്ടി ഉപയോഗിച്ച് 0-1,023 സ്കെയിലിൽ നിലവിലെ ലൈറ്റ് ലെവൽ വായിക്കും. ഈ പ്രൊപ്പർട്ടി പിനിൽ നിന്നുള്ള അനലോഗ് മൂല്യം വായിക്കുന്നു. തുടർന്ന് ഈ മൂല്യം കൺസോളിൽ പ്രിണ്ട് ചെയ്യും.

1. `loop` ന്റെ അവസാനം ഒരു ചെറിയ ഒരുനിലവാരമുള്ള ഒരു സെക്കൻഡ് സ്ലീപ് ചേർക്കുക, കാരണം ലൈറ്റ് ലെവലുകൾ തുടർച്ചയായി പരിശോധിക്കേണ്ടതില്ല. സ്ലീപ് ഉപകരണത്തിന്റെ വൈദ്യുതി ഉപയോഗം കുറയ്ക്കാൻ സഹായിക്കുന്നു.

    ```python
    time.sleep(1)
    ```

1. VS Code ടെർമിനലിൽ നിന്നു് നിങ്ങളുടെ Python ആപ്പ് പ്രവർത്തിപ്പിക്കാനായി താഴെ കൊടുത്ത കമാൻഡ് ഓടിക്കുക:

    ```sh
    python3 app.py
    ```

    ലൈറ്റ് മൂല്യങ്ങൾ കൺസോളിലേക്ക് ഔട്ട്പുട്ടായി വരും. ലൈറ്റ് സെൻസർ മൂടി തുറന്ന് നോക്കൂ, മൂല്യങ്ങൾ മാറുന്നതായി കാണും:

    ```output
    pi@raspberrypi:~/nightlight $ python3 app.py 
    Light level: 634
    Light level: 634
    Light level: 634
    Light level: 230
    Light level: 104
    Light level: 290
    ```
