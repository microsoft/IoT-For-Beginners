# ഒരു നൈറ്റ്‌ലൈറ്റ് നിർമ്മിക്കുക - റാസ്‌പ്ബെറി പൈ

ഈ പാഠഭാഗത്തില്‍, നിങ്ങൾ നിങ്ങളുടെ റാസ്‌പ്ബെറി പൈയിൽ ഒരു LED ചേർക്കുകയും അതുപയോഗിച്ച് ഒരു നൈറ്റ്‌ലൈറ്റ് സൃഷ്ടിക്കുകയും ചെയ്യും.

## ഹാർഡ്‌വെയർ

നൈറ്റ്‌ലൈറ്റിന് ഇപ്പോൾ ഒരു ആക്ച്വേറ്റർ ആവശ്യമാണ്.

ആക്ച്വേറ്റർ എന്നത് ഒരു **LED** ആണ്, കറന്റ് ഒഴുകുമ്പോൾ വിളക്കിടുന്ന [ലോട്-എമിറ്റിങ്ങ് ഡയോഡ്](https://wikipedia.org/wiki/Light-emitting_diode). ഇത് on, off എന്ന 2 സംസ്ഥാനങ്ങളുള്ള ഡിജിറ്റൽ ആക്ച്വേറ്ററാണ്. 1 എന്ന മൂല്യം അയച്ചാൽ LED ഓൺ ആകുകയും, 0 അയച്ചാൽ ഓഫായും പോകും. LED ഒരു ബാഹ്യ Grove ആക്ച്വേറ്ററാണ്, ഇത് Grove ബേസ് ഹാറ്റിൽ റാസ്‌പ്ബെറി പൈയിൽ കണക്ട് ചെയ്യണം.

നൈറ്റ്‌ലൈറ്റ് ലജിക് ചുരുക്കത്തിൽ ഇങ്ങനെ ആണ്:

```output
Check the light level.
If the light is less than 300
    Turn the LED on
Otherwise
    Turn the LED off
```

### LED കണക്ട് ചെയ്യുക

Grove LED ലെഡുകൾ തിരഞ്ഞെടുക്കാനാകുന്ന LED സെലക്ഷനോടെ ഒരു മോഡ്യൂളായി ലഭിക്കുന്നതാണ്.

#### ടാസ്‌ക് - LED കണക്ട് ചെയ്യുക

LED കണക്ട് ചെയ്യുക.

![A grove LED](../../../../../translated_images/ml/grove-led.6c853be93f473cf2.png)

1. നിങ്ങൾ ഇഷ്ടമുള്ള LED തിരഞ്ഞെടുക്കുക, LED മോഡ്യൂളിലെ രണ്ട് തുളസുകളിലേക്കാണ് കാൽ സ്ക്രൂവുകൾ ചേർക്കുക.

    LEDs ലൈറ്റ്-എമിറ്റിങ്ങ് ഡയോഡുകൾ ആണ്, ഡയോഡുകൾ ഒരു ദിശയിൽ മാത്രം കറന്റ് ഒഴുക്കാൻ കഴിയുന്ന ഇലക്ട്രോണിക് ഉപകരണങ്ങളാണ്. അത്തരം കാരണത്താൽ, LED ശരിയായ ദിശയിൽ കണക്ട് ചെയ്യേണ്ടതുണ്ട്, അല്ലെങ്കിൽ അത് പ്രവർത്തിക്കില്ല.

    LEDയുടെ രണ്ടിൽ ഒന്ന് പോസിറ്റീവ് പിനാണ്, മറ്റൊന്ന് നെഗറ്റീവ് പിൻ ആണ്. LED പൂർണ്ണമായും ഗോളാകൃതിയിലുള്ളതല്ല, ഒറ്റവശത്ത് കുറച്ച് എണ്ണമറ്റതാണ്. ഈ കുറച്ച് എണ്ണമറ്റ വശം നെഗറ്റീവ് പിനാണ്. LED മോഡ്യൂളിലേക്ക് കണക്ട് ചെയ്യുമ്പോൾ, വലക്കിണക്കുള്ള വശം മോഡ്യൂളിൽ **+** എന്ന് അടയാളപ്പെടുത്തിയ സോക്കറ്റിലേക്ക് കണക്ട് ചെയ്യണം, എണ്ണമറ്റ വശം മോഡ്യൂളിന്റെ നടുവിലുള്ള സോക്കറ്റിന് അടുത്തുള്ള ഭാഗത്തേക്ക് കണക്ട് ചെയ്യുക.

1. LED മോഡ്യൂളിന് ഒരു സ്‌പിൻ ബട്ടൺ ഉണ്ട്, ഇതിലൂടെ മിനുങ്ങിനെ നിയന്ത്രിക്കാം. ചെറിയ ഒരു ഫിലിപ്സ് ഹെഡ് സ്ക്രൂഡ്രൈവറിൽ ഉപയോഗിച്ച് അത് ആന്റി-ക്ലോക്ക്വൈസ്  തിരിയിച്ച് മുഴുകുത്തുന്നത് ആരംഭിക്കുക.

1. Grove കേബിളിന്റെ ഒരു അടുക്കൽ LED മോഡ്യൂളിലെ സോക്കറ്റിൽ ചേർക്കുക. ഇത് ഒരു ദിശയിൽ മാത്രമേ കയറുകയുള്ളൂ.

1. റാസ്‌പ്ബെറി പൈ ഓഫായിരിക്കുമ്പോൾ, Grove കേബിളിന്റെ മറ്റു ഒരു അറ്റം Grove Base ഹാറ്റിലെ **D5** എന്ന് അടയാളപ്പെടുത്തിയ ഡിജിറ്റൽ സോക്കറ്റിലേക്ക് കണക്ട് ചെയ്യുക. GPIO പിനുകളുടെ അടുത്തുള്ള സോക്കറ്റിന്റെ ഇടത്തരം രണ്ടാം സോക്കറ്റാണ് ഇത്.

![The grove LED connected to socket D5](../../../../../translated_images/ml/pi-led.97f1d474981dc35d.png)

## നൈറ്റ്‌ലൈറ്റ് പ്രോഗ്രാം ചെയ്യുക

ഇപ്പോൾ നൈറ്റ്‌ലൈറ്റ് Grove ലൈറ്റ് സെൻസറും Grove LED ഉം ഉപയോഗിച്ച് പ്രോഗ്രാം ചെയ്യാം.

### ടാസ്‌ക് - നൈറ്റ്‌ലൈറ്റ് പ്രോഗ്രാം ചെയ്യുക

നൈറ്റ്‌ലൈറ്റ് പ്രോഗ്രാം ചെയ്യുക.

1. പൈ പവർ ഓൺ ചെയ്ത് ബൂട്ടിന് വേണ്ടി കാത്തിരിക്കുക

1. മുമ്പ് ഈ അസൈൻമെന്റിന്റെ ഭാഗമായിട്ടുണ്ടാക്കിയ നൈറ്റ്‌ലൈറ്റ് പ്രോജക്ട് VS Code ൽ തുറക്കുക. ഇത് പൈയില്‍ നേരിട്ട് ഓടിയാലും അല്ലെങ്കിൽ Remote SSH എക്സ്റ്റൻഷൻ ഉപയോഗിച്ച് കണക്ട് ചെയ്താലും 됩니다.

1. ആവശ്യമായ ലൈബ്രറി ഇമ്പോർട്ട് ചെയ്യാൻ താഴെ കൊടുത്തിരിക്കുന്ന കോഡ് `app.py` ഫയലിൽ അതിലെ import ലൈനുകളുടെ താഴെ ചേർക്കുക.

    ```python
    from grove.grove_led import GroveLed
    ```

    `from grove.grove_led import GroveLed` എന്ന സ്റ്റേറ്റ്‌മെന്റ് Grove Python ലൈബ്രറികളിൽ നിന്നുള്ള `GroveLed` ക്ലാസ് ഇംപോർട്ട് ചെയ്യുന്നു. ഈ ലൈബ്രറി Grove LED യുമായി ഇടപഴകാൻ ആവശ്യമായ കോഡ് ഉൾക്കൊള്ളുന്നു.

1. LED നിയന്ത്രിക്കുന്ന ക്ലാസ് ഇൻസ്റ്റൻസ് സൃഷ്ടിക്കാൻ `light_sensor` ഡെക്ലറേഷനിന് ശേഷം താഴെ കൊടുത്തിരിക്കുന്ന കോഡ് ചേർക്കുക:

    ```python
    led = GroveLed(5)
    ```

    `led = GroveLed(5)` എന്ന വരി പിൻ **D5** - ഡിജിറ്റൽ Grove പിനിൽ കണക്ട് ചെയ്യുന്ന `GroveLed` ക്ലാസ് ഇൻസ്റ്റൻസ് സൃഷ്ടിക്കുന്നു.

    > 💁 എല്ലാ സോക്കറ്റുകൾക്കും പ്രത്യേകമായ പിന് നമ്പറുകളുണ്ട്. പിന് 0, 2, 4, 6 അനലോഗ് pins ആണ്; 5, 16, 18, 22, 24, 26 ഡിജിറ്റൽ പിനുകൾ ആണ്.

1. `while` ലൂപ്പിനുള്ളിൽ, `time.sleep` മുൻപ് ലൈറ്റ് ലെവലുകൾ പരിശോധിച്ച് LED ഓണോ ഓഫോ ആക്കാൻ ചെക്ക് ചേർക്കുക:

    ```python
    if light < 300:
        led.on()
    else:
        led.off()
    ```

    ഈ കോഡ് `light` വാല്യു പരിശോധിക്കുന്നു. ഇത് 300-ലധികം അല്ലെങ്കിൽ തുല്യമായാൽ, LED-ന്റെ `off` method പ്രയോഗിച്ച് 0 ഡിജിറ്റൽ മൂല്യം LED-ക്ക് അയയ്‌ക്കുന്നു, LED ഓഫ് ആക്കുന്നു. 300-ലെക്കാൾ കുറവാണെങ്കിൽ `on` method ഉപയോഗിച്ച് 1 ഡിജിറ്റൽ മൂല്യം LED-ക്ക് അയയ്‌ക്കുന്നു, LED ഓണാക്കിയിരിക്കുന്നത്.

    > 💁 ഈ കോഡ് `print('Light level:', light)` ലൈനിന്റെ സമക്ഷത്തിൽ ഇൻഡെന്റ് ചെയ്തിരിക്കണം, അതായത് while ലൂപ്പിനുള്ളിൽ!

    > 💁 ആക്ച്വേറ്ററുകൾക്ക് ഡിജിറ്റൽ മൂല്യങ്ങൾ അയയ്ക്കുമ്പോൾ, 0 മൂല്യം 0V ആണ്, 1 മൂല്യം ഉപകരണത്തിന് മാക്സ് വോൾട്ടേജ് ആണ്. റാസ്‌പ്ബെറി പൈ Grove സെൻസറുകളും ആക്ച്വേറ്ററുകളും ഉപയോഗുമ്പോൾ, 1 വോൾട്ടേജ് 3.3V ആണ്.

1. VS Code ടർമിനലിൽ താഴെ കൊടുത്തിരിക്കുന്ന കമാൻഡ് റൺ ചെയ്ത് നിങ്ങളുടെ പൈത്തൺ ആപ്പ് ഓടിക്കുക:

    ```sh
    python3 app.py
    ```

    ലൈറ്റ് മൂല്യങ്ങൾ കോൺസോളിൽ ഔട്ട്‌പുട്ടാകും.

    ```output
    pi@raspberrypi:~/nightlight $ python3 app.py 
    Light level: 634
    Light level: 634
    Light level: 634
    Light level: 230
    Light level: 104
    Light level: 290
    ```

1. ലൈറ്റ് സെൻസർ അടയ്ക്കാനും തുറക്കാനും ശ്രമിക്കുക. ലൈറ്റ് ലെവൽ 300 അല്ലെങ്കിൽ കുറവായാൽ LED ലൈറ്റ് ഓണാകുമെന്ന്, 300-ലധികമായാൽ ഓഫ് ആയും മാറുമെന്ന് ശ്രദ്ധിക്കുക.

    > 💁 LED ഓണാകുന്നില്ലെങ്കിൽ, അത് ശരിയായ ദിശയിലാണ് കണക്ട് ചെയ്തിട്ടുണ്ടെന്ന് ഉറപ്പാക്കുക, സ്‌പിൻ ബട്ടൺ പൂർണ്ണമായും ഓണായി സെറ്റ് ചെയ്തിട്ടുണ്ടെന്ന് പരിശോധിക്കുക.
