# രാത്രികൊളിപ്പ് നിർമ്മിക്കുക - വെര്‍ച്വല്‍ ഐഒടി ഹാര്‍ഡ്‌വെയര്‍

ഈ പാഠത്തിലെ ഭാഗത്തിൽ, നിങ്ങൾ നിങ്ങളുടെ വെര്‍ച്വല്‍ ഐഒടി ഉപകരണത്തിൽ ഒരു ലൈറ്റ് സെൻസർ ചേർക്കും.

## വെര്‍ച്വല്‍ ഹാര്‍ഡ്‌വെയര്‍

രാത്രികൊളിപ്പിന് ഒരു സെന്‍സർ ആവശ്യമാണ്, അത് CounterFit ആപ്പിൽ സൃഷ്ടിച്ചിരുന്നു.

സെന്‍സർ ഒരു **ലൈറ്റ് സെൻസർ** ആണ്. ഭൗതിക ഐഒടി ഉപകരണത്തിൽ, ഇത് [photodiode](https://wikipedia.org/wiki/Photodiode) ആയിരിക്കും, അത് വെളിച്ചത്തെ വൈദ്യുത സിഗ്നലായി പരിവർത്തനം ചെയ്യും. ലൈറ്റ് സെൻസറുകൾ അനലോഗ് സെൻസറുകളാണ്, അവ ഇന്റിജർ മൂല്യം അയയ്ക്കുന്നു, വെളിച്ചത്തിന്റെ ബന്ധപ്പെട്ട തോതിനെ സൂചിപ്പിക്കുന്നത്, ഇത് [lux](https://wikipedia.org/wiki/Lux) പോലുള്ള ഏതൊരു സ്റ്റാൻഡേർഡ് അളവിലെ യൂണിറ്റിനും അനുയോജ്യമല്ല.

### സെന്‍സറുകൾ CounterFit-ൽ ചേർക്കുക

ഒരു വെർച്വൽ ലൈറ്റ് സെൻസർ ഉപയോഗിക്കാൻ, അത് CounterFit ആപ്പിലേക്ക് ചേർക്കണം.

#### ടാസ്‌ക് - സെൻസറുകൾ CounterFit-ൽ ചേർക്കുക

ലൈറ്റ് സെൻസർ CounterFit ആപ്പിലിൽ ചേർക്കുക.

1. മുൻപത്തെ ഏൽപ്പിന്റെ ഭാഗത്തു നിന്നുള്ള CounterFit വെബ് ആപ്പ് പ്രവർത്തന സജ്ജമാണ് എന്ന് ഉറപ്പാക്കുക. അല്ലെങ്കിൽ, തുടങ്ങുക.

1. ഒരു ലൈറ്റ് സെൻസർ സൃഷ്ടിക്കുക:

    1. *Sensors* പാനലിൽ ഉള്ള *Create sensor* ബോക്സിൽ, *Sensor type* ബോക്സിൽ നിന്ന് *Light* തിരഞ്ഞെടുക്കുക.

    1. *Units* *NoUnits* ആയി വിടുക.

    1. *Pin* *0* ആയി സജ്ജീകരിച്ചു എന്ന് ഉറപ്പാക്കുക.

    1. Pin 0-ൽ ലൈറ്റ് സെൻസർ സൃഷ്ടിക്കാൻ **Add** ബട്ടൺ ക്ലിക്ക് ചെയ്യുക.

    ![The light sensor settings](../../../../../translated_images/ml/counterfit-create-light-sensor.9f36a5e0d4458d8d.png)

    ലൈറ്റ് സെൻസർ സൃഷ്ടിച്ച് സെൻസറുകളുടെ പട്ടികയിൽ കാണിക്കും.

    ![The light sensor created](../../../../../translated_images/ml/counterfit-light-sensor.5d0f5584df56b90f.png)

## ലൈറ്റ് സെൻസർ പ്രോഗ്രാം ചെയ്യുക

ഉപകരണം ഇപ്പോൾ ഉൾപ്പെടുത്തിയ ലൈറ്റ് സെൻസർ ഉപയോഗിക്കാൻ പ്രോഗ്രാം ചെയ്യാം.

### ടാസ്‌ക് - ലൈറ്റ് സെൻസർ പ്രോഗ്രാം ചെയ്യുക

ഉപകരണം പ്രോഗ്രാം ചെയ്യുക.

1. ഈ ഏൽപ്പിന്റെ മുൻപത്തെ ഭാഗത്തിൽ സൃഷ്ടിച്ച nuitlight പ്രോജക്ട് VS Code-ൽ തുറക്കുക. വേണ്ടെങ്കിൽ, വിർച്വൽ എന്വയോൺമെന്റ് ഉപയോഗിച്ച് പ്രവർത്തിക്കുന്നുണ്ടെന്ന് ഉറപ്പാക്കാൻ ടെർമിനൽ നശിപ്പിച്ച് വീണ്ടും സൃഷ്ടിക്കുക.

1. `app.py` ഫയൽ തുറക്കുക

1. `app.py` ഫയലിന്റെ മുകളിൽ മറ്റുള്ള `import` സ്റ്റേറ്റ്മെന്റുകളുമായി ചേർത്ത് ആവശ്യമായ ലൈബ്രറികൾ import ചെയ്യാൻ താഴെയുള്ള കോഡ് ചേർക്കുക:

    ```python
    import time
    from counterfit_shims_grove.grove_light_sensor_v1_2 import GroveLightSensor
    ```

    `import time` സ്റ്റേറ്റ്മെന്റ് Python-ന്റെ `time` മോഡ്യൂൾ ഇറക്കുമതി ചെയ്യുന്നു, ഇത് ഈ ഏൽപ്പിൽ പിന്നീട് ഉപയോഗിക്കും.

    `from counterfit_shims_grove.grove_light_sensor_v1_2 import GroveLightSensor` അപേക്ഷ CounterFit Grove ഷിം Python ലൈബ്രറികളിൽ നിന്നുള്ള `GroveLightSensor`അറിയിപ്പാണ്. ഈ ലൈബ്രറി CounterFit ആപ്പിൽ സൃഷ്ടിച്ച ലൈറ്റ് സെൻസറുമായി പ്രവർത്തിക്കാൻ കോഡ് ഉൾപ്പെടുന്നു.

1. ലൈറ്റ് സെൻസർ മാനേജു ചെയ്യുന്ന ക്ലാസ്സുകളുടെ ഇൻസ്റ്റൻസുകൾ സൃഷ്ടിക്കാൻ ഫയലിന്റെ താഴത്തെ ഭാഗത്ത് താഴെ കാണുന്ന കോഡ് ചേർക്കുക:

    ```python
    light_sensor = GroveLightSensor(0)
    ```

    `light_sensor = GroveLightSensor(0)` എന്ന വരി GroveLightSensor ക്ലാസിന്റെ ഒരു ഇൻസ്റ്റൻസ് സൃഷ്ടിക്കുന്നു, Pin **0**-ല്‍ കണക്ട് ചെയ്യുന്നു - ഇത് CounterFit Grove Pin ആണ്, ലൈറ്റ് സെൻസർക്ക് കണക്ട് ചെയ്തിരിക്കുന്നത്.

1. മുകളിൽ കൊടുത്ത കോഡിന് ശേഷം ഒരു അനന്ത ലൂപ് ചേർക്കുക, അത് ലൈറ്റ് സെൻസർ മൂല്യം വായിച്ച് കണ്‍സോളിൽ പ്രിന്റ് ചെയ്യും:

    ```python
    while True:
        light = light_sensor.light
        print('Light level:', light)
    ```

    ഇതിലൂടെ `GroveLightSensor` ക്ലാസിന്റെ `light` പ്രോപർട്ടി ഉപയോഗിച്ച് നിലവിലെ ലൈറ്റ് ലെവൽ വായിക്കും. ഈ പ്രൊപ്പർട്ടി പിന്‍ നിന്നും അനലോഗ് മൂല്യം വായിക്കുന്നു. ഈ മൂല്യം കണ്‍സോളിൽ പ്രിന്റ് ചെയ്യും.

1. `while` ലൂപിന്റെ അവസാനം ചെറിയ ഒരു സ്ലീപ്പ് (ஒരെ സെക്കന്റ്) ചേർക്കുക, കാരണം ലൈറ്റ് ലെവലുകൾ തുടർച്ചയായി പരിശോധിക്കേണ്ടതില്ല. സ്ലീപ്പ് ഉപകരണം പേവർ ഉപഭോഗം കുറയ്ക്കും.

    ```python
    time.sleep(1)
    ```

1. VS Code Terminal-ൽ നിന്ന് Python ആപ്പ് പ്രവർത്തിപ്പിക്കാൻ താഴെ കാണുന്ന കമാൻഡ് റൺ ചെയ്യുക:

    ```sh
    python3 app.py
    ```

    ലൈറ്റ് മൂല്യങ്ങൾ കണ്‍സോളിൽ പുറപ്പെടുവിക്കപ്പെടുന്നുണ്ട്. തുടക്കത്തിൽ ഈ മൂല്യം 0 ആയിരിക്കും.

1. CounterFit ആപ്പിൽ നിന്നുള്ള ലൈറ്റ് സെൻസർ മൂല്യം മാറ്റുക, ആ മൂല്യം ആപ്പ് വായിക്കും. ഇത് രണ്ട് വഴികളിലൊന്നിൽ ചെയ്യാം:

    * ലൈറ്റ് സെൻസറിന് *Value* ബോക്സിൽ ഒരു സംഖ്യ നൽകുക, ശേഷം **Set** ബട്ടൺ തിരഞ്ഞെടുക്കുക. നിങ്ങൾ നൽകുന്ന സംഖ്യ സെൻസർ നൽകുന്ന മൂല്യം ആയിരിക്കും.

    * *Random* ചെക്ക്ബോക്സ് സജ്ജമാക്കി, *Min* ഉം *Max* ഉം മൂല്യങ്ങൾ നൽകുക, തുടർന്ന് **Set** ബട്ടൺ ക്ലിക്ക് ചെയ്യുക. സെൻസർ ഓരോവട്ടവും *Min*നും *Max*നും ഇടയിലുള്ള ഒരു യാദൃച്ഛിക സംഖ്യ വായിക്കും.

    നിങ്ങൾ സജ്ജമാക്കിയ മൂല്യങ്ങൾ കണ്‍സോളിൽ പ്രിന്റ് ചെയ്യും. *Value* അല്ലെങ്കിൽ *Random* ക്രമീകരണങ്ങൾ മാറ്റി മൂല്യം മാറ്റാം.

    ```output
    (.venv) ➜  GroveTest python3 app.py 
    Light level: 143
    Light level: 244
    Light level: 246
    Light level: 253
    ```
