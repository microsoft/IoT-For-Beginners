# Wio Terminal

[Seeed Studios ൽ നിന്നും Wio Terminal](https://www.seeedstudio.com/Wio-Terminal-p-4509.html) WiFi ഉള്ള, ചില സെൻസറുകളും ആക്‌ചുവേറ്ററുകളും ഉൾപ്പെടുത്തിയ, Arduino-ഉം പൊരുത്തപ്പെടുന്ന ഒരു മൈക്രോ കണ്ട്രോളറാണ്, കൂടാതെ [Grove](https://www.seeedstudio.com/category/Grove-c-1003.html) എന്നു പേരായ ഒരു ഹാർഡ്‌വെയർ ഇക്കോസിസ്റ്റം ഉപയോഗിച്ച് കൂടുതൽ സെൻസറുകളും ആക്‌ചുവേറ്ററുകളും ചേർക്കാനുള്ള പോർട്ടുകളും ഇതിൽ ഉണ്ട്.

![A Seeed studios Wio Terminal](../../../../../translated_images/ml/wio-terminal.b8299ee16587db9a.png)

## ക്രമീകരണം

നിങ്ങളുടെ Wio Terminal ഉപയോഗിക്കാൻ, നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ ചില സൗജന്യ സോഫ്റ്റ്‌വെയർ ഇൻസ്റ്റാൾ ചെയ്യേണ്ടതുണ്ട്. Wio Terminal ഫിർമ്മ്വെയർ അപ്‌ഡേറ്റ് ചെയ്യാൻ കൂടിയും വെച്ച് ശേഷം മാത്രമേ അത് WiFi-യുമായി ബന്ധിപ്പിക്കാനാകൂ.

### ടാസ്ക് - ക്രമീകരണം

ആവശ്യമായ സോഫ്റ്റ്‌വെയർ ഇൻസ്റ്റാൾ ചെയ്യുകയും ഫിർമ്മ്വെയർ അപ്‌ഡേറ്റ് ചെയ്യുകയും ചെയ്യുക.

1. Visual Studio Code (VS Code) ഇൻസ്റ്റാൾ ചെയ്യുക. C/C++ ഉപയോഗിച്ച് നിങ്ങളുടെ ഉപകരണ കോഡ് എഴുതാൻ നിങ്ങൾ ഇതാണ് എഡിറ്റർ ആയി ഉപയോഗിക്കുന്നത്. VS Code ഇൻസ്റ്റാൾ ചെയ്യാനുള്ള നിർദ്ദേശങ്ങൾക്കായി [VS Code ഡോക്യുമെന്റേഷന്](https://code.visualstudio.com?WT.mc_id=academic-17441-jabenn) കാണുക.

    > 💁 Arduino ഡെവലപ്മെന്റിന് മറ്റൊരു പ്രശസ്തമായ IDE [Arduino IDE](https://www.arduino.cc/en/software) ആണ്. നിങ്ങൾക്ക് ഈ ടൂൾ പണ്ടേറിയിരിക്കുകയാണെങ്കിൽ, VS Code, PlatformIO ഉപയോഗിക്കുന്നതിന് പകരം ഇത് ഉപയോഗിക്കാം, പക്ഷേ പാഠങ്ങൾ VS Code അടിസ്ഥാനമാക്കി നിർദ്ദേശങ്ങൾ നൽകും.

1. VS Code PlatformIO എക്സ്റ്റൻഷൻ ഇൻസ്റ്റാൾ ചെയ്യുക. C/C++ ഭാഷയിൽ മൈക്രോ കൺട്രോളറുകൾ പ്രോഗ്രാം ചെയ്യാൻ ഇത് സഹായിക്കുന്ന VS Code എക്സ്റ്റൻഷൻ ആണ്. VS Code-യിൽ ഈ എക്സ്റ്റൻഷൻ ഇൻസ്റ്റാൾ ചെയ്യാനുള്ള നിർദ്ദേശങ്ങൾക്ക് [PlatformIO എക്സ്റ്റൻഷൻ ഡോക്യുമെന്റേഷൻ](https://marketplace.visualstudio.com/items?WT.mc_id=academic-17441-jabenn&itemName=platformio.platformio-ide) കാണുക. ഈ എക്സ്റ്റൻഷൻ പ്രവർത്തിക്കാൻ Microsoft C/C++ എക്സ്റ്റൻഷൻ ആവശ്യമാണ്, PlatformIO ഇൻസ്റ്റാൾ ചെയ്‌തപ്പോൾ അത് സ്വയം ഇൻസ്റ്റാൾ ചെയ്യും.

1. നിങ്ങളുടെ Wio Terminal നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ കണക്റ്റ് ചെയ്യുക. Wio Terminal-ന്റെ ബോട്ടത്തിൽ USB-C പോർട്ട് ഉണ്ട്, ഇത് നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ USB പോർക്കും കണക്റ്റ് ചെയ്യണം. Wio Terminal-ക്ക് USB-C മുതൽ USB-A കേബിള്‍ ഉണ്ടാകും, എന്നാൽ നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ USB-C മാത്രമേ പോർട്ടുകൾ ഉണ്ടായിരിക്കുകയാണെങ്കിൽ, USB-C കേബിൾ അല്ലെങ്കിൽ USB-A മുതൽ USB-C യിലേക്ക് അഡാപ്ടർ വേണം.

1. [Wio Terminal Wiki WiFi Overview ഡോക്യുമെന്റേഷൻ](https://wiki.seeedstudio.com/Wio-Terminal-Network-Overview/)ൽ നൽകിയ നിർദ്ദേശങ്ങൾ പാലിച്ച് നിങ്ങളുടെ Wio Terminal ക്രമീകരിക്കുകയും ഫിർമ്മ്വെയർ അപ്ഡേറ്റ് ചെയ്യുകയും ചെയ്യുക.

## ഹലോ വേൾഡ്

ഒരു പുതിയ പ്രോഗ്രമിംഗ് ഭാഷയോ സാങ്കേതികവിദ്യയോ തുടങ്ങുമ്പോൾ റിവ ആരോഗ്യാവസ്ഥയെന്ന് പറയുന്ന ഒരു ചെറിയ ആപ്പ് സൃഷ്ടിക്കുകയാണ് 'ഹലോ വേൾഡ്' - "Hello World" എന്ന എഴുത്ത് പോലുള്ള എന്തെങ്കിലും പ്രിന്‍റ് ചെയ്യുന്നത്, എല്ലാ ടൂളുകളും ശരിയായി ക്രമീകരിച്ചിരിക്കുന്നുവെന്ന് കാണിക്കാൻ.

Wio Terminal-ക്കായി ഹലോ വേൾഡ് ആപ്പ് Visual Studio code ശരിയായി ഇൻസ്റ്റാൾ ചെയ്യുകയും PlatformIO ഉപയോഗിച്ച് മൈക്രോ കൺട്രോളർ ഡെവലപ്പോർമെന്റ് ക്രമീകരിക്കുകയും ചെയ്തിരിക്കുകയാണെന്ന് ഉറപ്പാക്കും.

### PlatformIO പ്രോജക്‌ട് സൃഷ്ടിക്കുക

ആദ്യ ഘട്ടം എന്നത് Wio Terminal ഉപയോഗിക്കാൻ ക്രമീകരിക്കപ്പെട്ട PlatformIO ഉപയോഗിച്ച് ഒരു പുതിയ പ്രോജക്‌ട് സൃഷ്ടിക്കുകയാണ്.

#### ടാസ്ക് - PlatformIO പ്രോജക്‌ട് സൃഷ്ടിക്കുക

PlatformIO പ്രോജക്‌ട് സൃഷ്ടിക്കുക.

1. Wio Terminal നിങ്ങളുടെ കമ്പ്യൂട്ടറുമായി കണക്റ്റ് ചെയ്യുക

1. VS Code ആരംഭിക്കുക

1. PlatformIO ഐകോൺ സൈഡ് മെനു ബാറിൽ കാണും:

    ![The Platform IO menu option](../../../../../translated_images/ml/vscode-platformio-menu.297be26b9733e5c4.png)

    ഈ മെനു ഐറ്റം തിരഞ്ഞെടുക്കുക, പിന്നീട് *PIO Home -> Open* തിരഞ്ഞെടുക്കുക

    ![The Platform IO open option](../../../../../translated_images/ml/vscode-platformio-home-open.3f9a41bfd3f4da1c.png)

1. വരവിന്റെ സ്ക്രീനിൽ നിന്നു **+ New Project** ബട്ടൺ തിരഞ്ഞെടുക്കുക

    1. *Board* ഡ്രോപ്ഡൗണിൽ `WIO` എന്ന് ടൈപ്പ് ചെയ്ത് ബോർഡുകൾ ഫിൽട്ടർ ചെയ്ത് *Seeeduino Wio Terminal* തിരഞ്ഞെടുക്കുക

### PlatformIO പ്രോജക്‌ട്ടിൽ പരിശോധിക്കുക

VS Code എക്സ്പ്ലോറർ PlatformIO വിസാർഡ് സൃഷ്ടിച്ച നിരവധി ഫയലുകളും ഫോൾഡറുകളും കാണിക്കും.

#### ഫോൾഡറുകൾ

* `.pio` - PlatformIO ന് ആവശ്യമായ താൽക്കാലിക ഡാറ്റ ഉൾക്കൊള്ളുന്ന ഫോൾഡർ, ലൈബ്രറികളും കോമ്പൈൽ ചെയ്ത കോഡും ഉൾപ്പെടും. ഇത് ഇല്ലാതായാൽ സ്വയം പുനഃസൃഷ്ടിക്കും, GitHub പോലുള്ള സൈറ്റ്‌കളിൽ പ്രോജക്‌ട് പങ്കിടുമ്പോൾ ഈ ഫോൾഡർ സോഴ്‌സ് കോഡ് കോൺട്രോളിൽ ചേർക്കേണ്ടതില്ല.
* `.vscode` - PlatformIO, VS Code-ന്റെ കൺഫിഗറേഷൻ ഉള്ള ഫോൾഡർ. ഇത് പോലും ഇല്ലാതായാൽ സ്വയം പുനഃസൃഷ്ടിക്കും, GitHub പോലുള്ള സൈറ്റുകളിൽ ഈ ഫോൾഡർ അടക്കം ചെയ്യേണ്ടതില്ല.
* `include` - കൂടുതൽ ലൈബ്രറികൾ ഉൾപ്പെടുത്തുമ്പോൾ ആവശ്യമായ ഒഴിവുള്ള ഹെഡർ ഫയലുകൾക്കുള്ള ഫോൾഡർ. ഈ പാഠങ്ങളിൽ ഉപയോഗിക്കാനിരുന്നില്ല.
* `lib` - കോഡിൽ നിന്ന് വിളിക്കേണ്ട പുറത്തുള്ള ലൈബ്രറികൾക്കുള്ള ഫോൾഡർ. ഈ പാഠങ്ങളിൽ ഇതുപയോഗിക്കില്ല.
* `src` - ഇതിനകം മെയിൻ സോഴ്‌സ് കോഡ് ഉള്ള ഫോൾഡർ. ആദ്യം `main.cpp` എന്ന ഒരു ഫയൽ മാത്രമേ ഉണ്ടാകൂ.
* `test` - കോഡിനുള്ള യുണിറ്റ് ടെസ്റ്റുകൾ ഇതിലിടും.

#### ഫയലുകൾ

* `main.cpp` - `src` ഫോൾഡറിൽ ഉള്ള ഈ ഫയൽ ആപ്പിന്റെ എൻട്രി പോയിന്റ് ആയി പ്രവർത്തിക്കും. ഇതിൽ താഴെ കാണുന്ന കോഡ് ഉണ്ടായിരിക്കും:

    ```cpp
    #include <Arduino.h>
    
    void setup() {
      // ഇവിടെ നിങ്ങളുടെ സെറ്റപ്പ് കോഡ് ഇടുക, ഒരിക്കൽ പ്രവർത്തിക്കാൻ:
    }
    
    void loop() {
      // ഇവിടെ നിങ്ങളുടെ പ്രധാന കോഡ് ഇടുക, അനേകം തവണ പ്രവർത്തിക്കാൻ:
    }
    ```

    ഉപകരണം ആരംഭിക്കുമ്പോൾ, Arduino ഫ്രെയിംവർക്ക് `setup` ഫങ്ഷൻ ഒരിക്കൽ പ്രവർത്തിപ്പിക്കുകയും, തുടർന്ന് `loop` ഫങ്ഷൻ നിരന്തരമായി പ്രവർത്തിപ്പിക്കുകയും ചെയ്യും, ഉപകരണം ഓഫ് ചെയ്യപ്പെടുന്നത് വരെ.

* `.gitignore` - Git സോഴ്സ് കോഡ് കോൺട്രോളിൽ ചേർക്കേണ്ടതില്ലായ്മയായ ഫയലുകളും ഡയറക്ടറികളും പ്രത്യേകം ലിസ്റ്റ് ചെയ്തിരിക്കുന്ന ഫയൽ.

* `platformio.ini` - ഉപകരണം, ആപ്പ് ക്രമീകരണങ്ങൾ അടങ്ങിയ ഫയൽ. ഇതിൽ താഴെ കാണുന്ന കോഡ് ഉണ്ടായിരിക്കും:

    ```ini
    [env:seeed_wio_terminal]
    platform = atmelsam
    board = seeed_wio_terminal
    framework = arduino
    ```

    `[env:seeed_wio_terminal]` സെക്ഷനിൽ Wio Terminal-ന് വേണ്ട ക്രമീകരണങ്ങൾ ഉൾപ്പെടുത്തിയിട്ടുണ്ട്. ബോർഡുകളെ അടിസ്ഥാനമാക്കി ഒരേ പ്രോജക്‌ട് പല വേർഷനുകളിലും കോമ്പൈൽ ചെയ്യാൻ multiple `env` സെക്ഷനുകൾ ഉണ്ടായിരിക്കാം.

    മറ്റ് മൂല്യങ്ങൾ പ്രോജക്‌ട് വിചാർഡ് ക്രമീകരണങ്ങളെ അനുയോജ്യമായിരിക്കും:

  * `platform = atmelsam` Wio Terminal ഉപയോഗിക്കുന്ന ഹാർഡ്‌വെയർ നിർവചിക്കുന്നു (ATSAMD51-ആധാരമായ മൈക്രോ കൺട്രോളർ)
  * `board = seeed_wio_terminal` മൈക്രോ കൺട്രോളർ ബോർഡിന്റെ തരം നിർവചിക്കുന്നു (Wio Terminal)
  * `framework = arduino` ഈ പ്രോജക്‌ട് Arduino ഫ്രെയിംവർക്ക് ഉപയോഗിക്കുന്നു എന്ന് സൂചിപ്പിക്കുന്നു.

### ഹലോ വേൾഡ് ആപ്പ് എഴുതുക

ഇപ്പോൾ നിങ്ങൾ ഹലോ വേൾഡ് ആപ് എഴുതാൻ സജ്ജമാണ്.

#### ടാസ്ക് - ഹലോ വേൾഡ് ആപ്പ് എഴുതുക

ഹലോ വേൾഡ് ആപ്പ് എഴുതുക.

1. VS Code-ൽ `main.cpp` ഫയൽ തുറക്കുക

1. താഴെ കാണിക്കുന്ന കോഡ് മാറ്റുക:

    ```cpp
    #include <Arduino.h>

    void setup()
    {
        Serial.begin(9600);

        while (!Serial)
            ; // സീരിയൽ റെഡി ആകാനുള്ള പ്രാതീക്ഷിക്കുക
    
        delay(1000);
    }
    
    void loop()
    {
        Serial.println("Hello World");
        delay(5000);
    }
    ```

    `setup` ഫങ്ഷൻ സീരിയൽ പോർട്ട് – ഈ കേസ് USB പോർട്ട്, Wio Terminal കമ്പ്യൂട്ടറുമായി കണക്റ്റ് ചെയ്യാൻ ഉപയോഗിക്കുന്നത് - കണക്റ്റ് ചെയ്യുന്നു. `9600` ആണ് [baud rate](https://wikipedia.org/wiki/Symbol_rate) (സംഖ്യാനിരക്ക്) അല്ലെങ്കിൽ സീരിയൽ പോർട്ടിലൂടെ ബിറ്റ് പ്രതിവർഷം അയയ്ക്കുന്ന വേഗത. ഇത് 9,600 ബിറ്റ് ഡാറ്റ ഓരോ സെക്കന്റിലും അയയ്ക്കുന്നു എന്ന് അർത്ഥമാക്കുന്നു. അത് സീരിയൽ പോർട്ട് റെഡി ആകാൻ കാത്തിരിക്കുന്നു.

    `loop` ഫങ്ഷൻ സീരിയൽ പോർട്ടിലേക്ക് `Hello World!` എന്ന വരി അയയ്ക്കുന്നു, അതായത് `Hello World!` അക്ഷരങ്ങൾ ഒരു പുതിയ ലൈൻ കരക്റ്റർ ഒപ്പം. തുടർന്ന് 5,000 മില്ലിസെക്കൻഡ് (5 സെക്കൻഡ്) ഉറങ്ങുന്നു. `loop` അവസാനിച്ചതിനു ശേഷം വീണ്ടും വീണ്ടും തുടരും, മൈക്രോ കൺട്രോളറിന്റെ പവർ ഓണായിരിക്കുന്ന സമയത്ത്.

1. നിങ്ങളുടെ Wio Terminal അപ്‌ലോഡ് മോഡിലാക്കുക. ഓരോ പ്രോഗ്രാം അപ്‌ലോഡിന് മുമ്പും ഇത് ആവശ്യമുണ്ട്:

    1. ബലാൽക്കുക (pull down) പവർ സ്വിച്ച് രണ്ട് തവണ പെട്ടെന്ന് ഉള്ളിൽ - ഓരോ തവണ സ്വിച്ച് ഓൺ സ്ഥിതിയിലേക്ക് പിന്‍വരികയാകും.

    1. USB പോർട്ട് വലത് വശത്തുള്ള നീല സ്റ്റാറ്റസ് LED ഒളിമ്പിക്കാൻ തുടങ്ങും എന്ന് പരിശോധിക്കുക.
    
    [![Wio Terminal അപ്‌ലോഡ് മോഡ് വരെ എത്തിക്കുന്ന വീഡിയോ](https://img.youtube.com/vi/LeKU_7zLRrQ/0.jpg)](https://youtu.be/LeKU_7zLRrQ)
    
    മുകളിൽ ചിത്രം ക്ലിക്ക് ചെയ്ത് ഇതുംപ്പുറമേ എങ്ങനെയെന്ന് കാണുന്ന വീഡിയോ കാണാം.

1. കോഡ് ബിൽഡ് ചെയ്ത് Wio Terminal-ലേക്ക് അപ്‌ലോഡ് ചെയ്യുക

    1. VS Code കമാൻഡ് പാലറ്റ് തുറക്കുക

    1. `PlatformIO Upload` ടൈപ്പ് ചെയ്ത് അപ്‌ലോഡ് ഓപ്ഷൻ തിരയുക, പിന്നെ *PlatformIO: Upload* തിരഞ്ഞെടുക്കുക

        ![The PlatformIO upload option in the command palette](../../../../../translated_images/ml/vscode-platformio-upload-command-palette.9e0f49cf80d1f1c3.png)

        ആവശ്യമായാൽ PlatformIO സ്വയം കോഡ് ബിൽഡ് ചെയ്യും, പിന്നീട് അപ്‌ലോഡ് ചെയ്യും.

    1. കോഡ് Wio Terminal-ലേക്ക് കോമ്പൈൽ ചെയ്ത് അപ്‌ലോഡ് ചെയ്യും

        > 💁 macOS ഉപയോഗിക്കുന്നവർക്ക് *DISK NOT EJECTED PROPERLY* എന്ന അറിയിപ്പ് കാണാം. Wio Terminal ഫ്‌ളാഷ് ചെയ്യുമ്പോൾ ഡ്രൈവ് പോലെ മൗണ്ടാകുന്നത്, കോഡ് എഴുതിയ ശേഷം ഡ്രൈവ് അൺമൗണ്ട് ആകുന്നതിന്റെ കാരണമാണ്. ഇത് അവഗണിക്കാം.

    ⚠️ അപ്‌ലോഡ് പോർട്ട് ലഭ്യമല്ല എന്ന എറർ ഉണ്ടായാൽ ആദ്യം Wio Terminal കമ്പ്യൂട്ടറോടൊപ്പം കണക്‌ടഡ് കാണുക, സ്ക്രീൻ വലത് വശത്തുള്ള സ്വിച്ച് ഓണാക്കിയതാണെന്ന് ഉറപ്പാക്കുക, അപ്‌ലോഡ് മോഡിലാകുന്നുവെന്ന് ഉറപ്പുവരുത്തുക. താഴെയുണ്ടായിട്ടുള്ള ഹരിത വെളിച്ചം ഓണായിരിക്കണം, നീല വെളിച്ചം പൾസ് ആയി നിലകൊള്ളണം. എറർ തുടരുമെങ്കിൽ പൊവ്മാറ്റം പവർ സ്വിച്ച് വീണ്ടും രണ്ട് തവണ പെട്ടെന്ന് താഴേക്ക് പിടിച്ച് വീണ്ടും അപ്‌ലോഡ് ശ്രമിക്കുക.

PlatformIO-യ്ക്ക് സീരിയൽ മോണിറ്റർ ഉണ്ട്, Wio Terminal USB കേബിള്‍ വഴി അയക്കുന്ന ഡാറ്റ നിരീക്ഷിക്കാൻ. ഇത് `Serial.println("Hello World");` കമാൻഡ് അയക്കുന്ന ഡാറ്റ കാണിക്കാൻ സഹായിക്കുന്നു.

1. VS Code കമാൻഡ് പാലറ്റ് തുറക്കുക

1. `PlatformIO Serial` ടൈപ്പ് ചെയ്ത് സീരിയൽ മോണിറ്റർ ഓപ്ഷൻ തെരഞ്ഞെടുക്കുക, *PlatformIO: Serial Monitor* തിരഞ്ഞെടുക്കുക

    ![The PlatformIO Serial Monitor option in the command palette](../../../../../translated_images/ml/vscode-platformio-serial-monitor-command-palette.b348ec841b8a1c14.png)

    പുതിയ ടർമിനൽ തുറക്കും, സീരിയൽ പോർട്ട് വഴി അയക്കുന്ന ഡാറ്റ ഇവിടെ സ്ട്രീംചെയ്യുന്നു:

    ```output
    > Executing task: platformio device monitor <
    
    --- Available filters and text transformations: colorize, debug, default, direct, hexlify, log2file, nocontrol, printable, send_on_enter, time
    --- More details at http://bit.ly/pio-monitor-filters
    --- Miniterm on /dev/cu.usbmodem101  9600,8,N,1 ---
    --- Quit: Ctrl+C | Menu: Ctrl+T | Help: Ctrl+T followed by Ctrl+H ---
    Hello World
    Hello World
    ```

    `Hello World` സീരിയൽ മോണിറ്ററിൽ ഓരോ 5 സെക്കന്റിലും പ്രിൻറ് ചെയ്യും.

> 💁 ഈ കോഡ് നിങ്ങൾക്ക് [code/wio-terminal](../../../../../1-getting-started/lessons/1-introduction-to-iot/code/wio-terminal) ഫോളഡറിൽ കാണാം.
