# മണ്ണിലെ ഈർപ്പം അളക്കുക - വിർച്വൽ IoT ഹാർഡ്‌വെയർ

പാഠത്തിന്റെ ഈ ഭാഗത്തിൽ, നിങ്ങൾക്ക് നിങ്ങളുടെ വിർച്വൽ IoT ഉപകരണത്തിൽ ഒരു കപ്പാസിറ്റീവ് മൺമാവ് ഈർപ്പം സെൻസർ ചേർക്കുകയും അതിൽ നിന്നുള്ള വാലുകൾ വായിക്കുകയുമാണ്.

## വിർച്വൽ ഹാർഡ്‌വെയർ

വിർച്വൽ IoT ഉപകരണം സിമുലേറ്റഡ് ഗ്രേവ് കപ്പാസിറ്റീവ് മൺമാവ് ഈർപ്പം സെൻസർ ഉപയോഗിക്കും. ഇത് ഈ ലാബ് റാസ്ബെറി പൈ ഉപയോഗിച്ച് ഫിസിക്കൽ ഗ്രേവ് കപ്പാസിറ്റീവ് മൺമാവ് ഈർപ്പം സെൻസർ ഉപയോഗിക്കുന്നതിനോടൊപ്പം സമന്വയിപ്പിക്കുന്നു.

ഫിസിക്കൽ IoT ഉപകരണത്തിൽ, മൺമാവ് ഈർപ്പം സെൻസർ മൺമാവിന്റെ കപ്പാസിറ്റൻസിനെ കണ്ടെത്തി മണ്ണിലെ ഈർപ്പ് അളക്കുന്ന കപ്പാസിറ്റീവ് സെൻസറായിരിക്കും. മൺമാവ് ഈർപ്പം വർദ്ധിച്ചതോടെ വോൾട്ടേജ് കുറയുന്നു.

ഇത് ഒരു അനലോഗ് സെൻസർ ആയി, 1-1,023 വരെ മൂല്യം റിപ്പോർട്ട് ചെയ്യാൻ സിമുലേറ്റ് ചെയ്ത 10-ബിറ്റ് ADC ഉപയോഗിക്കുന്നു.

### മൺമാവ് ഈർപ്പം സെൻസർ CounterFit-ൽ ചേർക്കുക

വിർച്വൽ മൺമാവ് ഈർപ്പം സെൻസർ ഉപയോഗിക്കാൻ, അത് CounterFit ആപ്ലിക്കേഷനിൽ ചേർക്കേണ്ടതുണ്ട്.

#### ടാസ്‌ക് - CounterFit-ൽ മൺമാവ് ഈർപ്പം സെൻസർ ചേർക്കുക

മൺമാവ് ഈർപ്പം സെൻസർ CounterFit ആപ്പിൽ ചേർക്കുക.

1. `soil-moisture-sensor` എന്ന ഫോൾഡറിൽ ഒരു പുതിയ പൈത്തൺ ആപ്പ് സൃഷ്ടിക്കുക, അതിലെ ഒറ്റ ഫയൽ `app.py` ആയും ഒരു പൈത്തൺ വിചുവൽ എൻവയോൺമെന്റ് ക്രമീകരിക്കുകയും CounterFit പിപ്പ് പാക്കേജുകൾ ചേർക്കുകയും ചെയ്യുക.

    > ⚠️ ആവശ്യമുണ്ടെങ്കിൽ [ലെസൻ 1-ൽ CounterFit പൈത്തൺ പ്രോജക്റ്റ് സൃഷ്ടിക്കുകയും ക്രമീകരിക്കുകയും ചെയ്യാനുള്ള നിർദേശങ്ങൾ കാണുക](../../../1-getting-started/lessons/1-introduction-to-iot/virtual-device.md).

1. CounterFit വെബ് ആപ്പ് പ്രവർത്തിക്കുന്നുണ്ടെന്ന് ഉറപ്പാക്കുക

1. മൺമാവ് ഈർപ്പം സെൻസർ സൃഷ്ടിക്കുക:

    1. *Sensors* പെയ്ൻൽയിലുള്ള *Create sensor* ബോക്സിൽ, *Sensor type* ബോക്സ് തുറന്ന് *Soil Moisture* തെരഞ്ഞെടുക്കുക.

    1. *Units* *NoUnits* ആയി സൂക്ഷിക്കുക

    1. *Pin* *0* ആയി ഉറപ്പാക്കുക

    1. *Add* ബട്ടൺ സെലക്റ്റ് ചെയ്ത് Pin 0-ൽ *Soil Moisture* സെൻസർ സൃഷ്ടിക്കുക

    ![The soil moisture sensor settings](../../../../../translated_images/ml/counterfit-create-soil-moisture-sensor.35266135a5e0ae68.png)

    മൺമാവ് ഈർപ്പം സെൻസർ സൃഷ്ടിക്കപ്പെട്ട് സെൻസറുകളുടെ പട്ടികയിൽ പ്രത്യക്ഷപ്പെടും.

    ![The soil moisture sensor created](../../../../../translated_images/ml/counterfit-soil-moisture-sensor.81742b2de0e9de60.png)

## മൺമാവ് ഈർപ്പം സെൻസർ ആപ്പ് പ്രോഗ്രാം ചെയ്യുക

ഇപ്പോൾ മൺമാവ് ഈർപ്പം സെൻസർ ആപ്പ് CounterFit സെൻസറുകൾ ഉപയോഗിച്ച് പ്രോഗ്രാം ചെയ്‌യാം.

### ടാസ്‌ക് - മൺമാവ് ഈർപ്പം സെൻസർ ആപ്പ് പ്രോഗ്രാം ചെയ്യുക

മൺമാവ് ഈർപ്പം സെൻസർ ആപ്പ് പ്രോഗ്രാം ചെയ്യുക.

1. VS Code-ൽ `soil-moisture-sensor` ആപ്പ് തുറക്കുക

1. `app.py` ഫയൽ തുറക്കുക

1. CounterFit-hez ആപ്പ് കണക്റ്റ് ചെയ്യാൻ `app.py`-യുടെ മുകളിലായി താഴെയുള്ള കോഡ് ചേർക്കുക:

    ```python
    from counterfit_connection import CounterFitConnection
    CounterFitConnection.init('127.0.0.1', 5000)
    ```

1. ആവശ്യമായ ലൈബ്രറികൾ ഇറക്കുമതി ചെയ്യാൻ `app.py` ഫയലിൽ താഴെയുള്ള കോഡ് ചേർക്കുക:

    ```python
    import time
    from counterfit_shims_grove.adc import ADC
    ```

    `import time` പ്രസ്താവന ഈ അസൈൻമെന്റിൽ അതിന് ശേഷം ഉപയോഗിക്കുന്ന `time` മോdule ഇംപോർട്ട് ചെയ്യുന്നു.

    `from counterfit_shims_grove.adc import ADC` പ്രസ്താവന ഒരു വിർച്വൽ അനലോഗ് ടു ഡിജിറ്റൽ കോൺവേർട്ടർ (ADC) ഉപയോഗിച്ച് CounterFit സെൻസറുമായി ഇടപഴകാൻ `ADC` ക്ലാസ് ഇറക്കുമതി ചെയ്യുന്നു.

1. ഇതിനു താഴെ കൊടുത്തിരിക്കുന്ന കോഡ് `ADC` ക്ലാസ് ഉദാഹരണം സൃഷ്ടിക്കാൻ ചേർക്കുക:

    ```python
    adc = ADC()
    ```

1. പിന് 0-ൽ നിന്നുള്ള ഈ ADC വായിച്ച് ഫലം കോൺസോളിൽ എഴുതുന്ന അനന്ത ലൂപ് ചേർക്കുക. വായനകൾക്കിടയിൽ ഈ ലൂപ് 10 സെക്കന്റ് ഉറങ്ങും.

    ```python
    while True:
        soil_moisture = adc.read(0)
        print("Soil moisture:", soil_moisture)
    
        time.sleep(10)
    ```

1. CounterFit ആപ്പിൽ നിന്നും ആപ്പ് വായിക്കാനിരിക്കുന്ന മൺമാവ് ഈർപ്പം സെൻസറിന്റെ മൂല്യം മാറ്റുക. ഇത് രണ്ട് മാർഗ്ഗത്തിൽ ചെയ്യാം:

    * മൺമാവ് ഈർപ്പം സെൻസറിന്റെ *Value* ബോക്സിൽ ഒരു എണ്ണം നൽകിയ ശേഷം **Set** ബട്ടൺ ഞെക്കുക. നിങ്ങൾ നൽകുന്ന നമ്പർ സെൻസർ നൽകുന്ന മൂല്യമായിരിക്കും.

    * *Random* ചെക്ക് ബോക്സ് അടയാളപ്പെടുത്തി, *Min* ഒപ്പം *Max* മൂല്യങ്ങൾ നൽകുക, പിന്നീട് **Set** ബട്ടൺ അമർത്തുക. സെൻസർ ഓരോ തവണ വായിക്കുമ്പോഴും *Min* ഉം *Max* ഉം ഇടയിലുള്ള യാദൃശ്ചിക സംഖ്യ വായിക്കും.

1. പൈത്തൺ ആപ്പ് റൺ ചെയ്യുക. മൺമാവ് ഈർപ്പം അളവുകൾ കോൺസോളിൽ എഴുതുന്നതായിരിക്കും കാണുക. *Value* അല്ലെങ്കിൽ *Random* ക്രമീകരണങ്ങൾ മാറ്റി മൂല്യം മാറുന്നത് കാണുക.

    ```output
    (.venv) ➜ soil-moisture-sensor $ python app.py 
    Soil moisture: 615
    Soil moisture: 612
    Soil moisture: 498
    Soil moisture: 493
    Soil moisture: 490
    Soil Moisture: 388
    ```
