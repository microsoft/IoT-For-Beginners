# ഒരു റീലം നിയന്ത്രിക്കുക - Raspberry Pi

പാഠപുസ്തകത്തിന്റെ ഈ ഭാഗത്തിൽ, നിങ്ങൾക്ക് മണ്ണിന്റെ ഈര്‍പ്പം സെൻസറിനൊപ്പം Raspberry Pi-ലേക്ക് ഒരു റീലം ചേർക്കാനും മണ്ണിന്റെ ഈര്‍പ്പത്തിന്റെ അടിസ്ഥാനത്തിൽ അത് നിയന്ത്രിക്കാനുമാകും.

## ഹാർഡ്‌വെയർ

Raspberry Pi-യ്ക്ക് ഒരു റീലം ആവശ്യമാണ്.

നിങ്ങൾ ഉപയോഗിക്കുന്നത് ഒരു [Grove relay](https://www.seeedstudio.com/Grove-Relay.html) ആണ്, സാധാരണയായി തുറന്ന റീലം (അഥവാ സിഗ്നൽ ലഭിക്കാതിരിക്കുന്നപ്പോൾ ഔട്ട്പുട്ട് സർക്ക്യൂട്ട് തുറന്നോ, ബന്ധം നിലക്കുന്നതിനോ പറ്റുന്ന) 250V 10A വരെ ഔട്ട്പുട്ട് സർക്ക്യൂട്ടുകൾ കൈകാര്യം ചെയ്യാന്‍ കഴിവുള്ളത്.

ഇത് ഒരു ഡിജിറ്റൽ ആക്ട്യുവേറ്റർ ആണ്, അതിനാൽ Grove Base Hat-ൽ ഒരു ഡിജിറ്റൽ പിനുമായി കണക്റ്റ് ചെയ്യുന്നു.

### റീലമconnect ് കറ്റ് ചെയ്യുക

Grove relay Raspberry Pi-യുമായി കണക്റ്റ് ചെയ്യാം.

#### ടാസ്‌ക്

റിലേ കണക്റ്റ് ചെയ്യുക.

![ഒരു Grove relay](../../../../../translated_images/ml/grove-relay.d426958ca210fbd0.png)

1. Grove കേബിളിന്റെ ഒരു അറ്റം റിലേയിലെ സോക്കറ്റിൽ ചേർക്കുക. ഇത് ഒരെ വഴി മാത്രമേ പോകൂ.

1. Raspberry Pi ഓഫ് ആകെയുള്ളപ്പോൾ, Grove കേബിളിന്റെ മറുവശം Grove Base Hat-ൽ Pi-യ്ക്ക് ചേർത്തിരിക്കുന്ന **D5** എന്നാണ് സംഘട്ടിച്ച ഡിജിറ്റൽ സോകറ്റ് കണക്റ്റ് ചെയ്യുക. GPIO പിനുകളുടെ അടുത്തുള്ള സോക്കറ്റുകളുടെ വരിയിൽ രണ്ടാമത്തേതാണ് ഇത്. മണ്ണിന്റെ ഈര്‍പ്പം സെൻസർ **A0** സോകറ്റിൽ കൂടി കണക്റ്റ് ചെയ്തിരിക്കണം.

![Grove relay D5 സോകട്ടിൽ കണക്റ്റ് ചെയ്തതും, മണ്ണിന്റെ ഈര്‍പ്പം സെൻസർ A0 സോകറ്റിൽ കണക്റ്റ് ചെയ്തതും](../../../../../translated_images/ml/pi-relay-and-soil-moisture-sensor.02f3198975b8c53e.png)

1. മുമ്പത്തെ പാഠത്തിൽ നിന്നും ഇല്ലെങ്കിൽ, മണ്ണിന്റെ ഈര്‍പ്പം സെൻസർ മണ്ണിൽ നിക്ഷേപിക്കുക.

## റീലേ പ്രോഗ്രാം ചെയ്യുക

Raspberry Pi ഇപ്പോൾ അനുബന്ധിച്ചിരിക്കുന്ന റീലേ പ്രോഗ്രാം ചെയ്തുകൊണ്ടിരിക്കാം.

### ടാസ്‌ക്

യന്ത്രം പ്രോഗ്രാം ചെയ്യുക.

1. Pi പവർ ഓഫ് ആക്കിയ ഹൈബ്രിഡ് ചെയ്യുക

1. അവസാന പാഠത്തിലെ `soil-moisture-sensor` പ്രോജക്റ്റ് VS Code-ൽ തുറക്കുക, തുറന്നിട്ടില്ലെങ്കിൽ. നിങ്ങൾ ഈ പ്രോജക്റ്റിലേക്ക് ചേർക്കും.

1. നിലവിലുള്ള ഇംപോർട്ടുകളുടെ താഴെ `app.py` ഫയലിൽ താഴെ നൽകിയിരിക്കുന്ന കോഡ് ചേർക്കുക:

    ```python
    from grove.grove_relay import GroveRelay
    ```

    Grove Python ലൈബ്രറികളിൽ നിന്നുള്ള `GroveRelay` ഇറക്കുമതി ചെയ്യുന്നതാണ്, Grove റിലേയ്‌ക്ക് ഇന്ററാക്ഷൻ ചെയ്യാനായി.

1. `ADC` ക്ലാസിന്റെ പ്രഖ്യാപനത്തിന്റെ താഴെ താഴെ നൽകിയിരിക്കുന്ന കോഡ് ചേർക്കുക `GroveRelay` ഉദാഹരണം ഉണ്ടാക്കാൻ:

    ```python
    relay = GroveRelay(5)
    ```

    ഇത് **D5** പിനായി റിലേ സൃഷ്ടിക്കുന്നു, നിങ്ങൾ റിലേ കണക്റ്റ് ചെയ്ത ഡിജിറ്റൽ പിന്.

1. റിലേ ധൃതിയാണെന്ന് പരിശോധിക്കാൻ, `while True:` ലൂപ്പിൽ താഴെ ചേർക്കുക:

    ```python
    relay.on()
    time.sleep(.5)
    relay.off()
    ```

    കോഡ് റിലേ ഓണാക്കി, 0.5 സെക്കൻഡ് കഴിയാതെ, തുടർന്ന് റിലേ ഓഫാക്കുന്നു.

1. Python ആപ്പ് റൺ ചെയ്യുക. റിലേ ഓരോ 10 സെക്കന്റിലും ഓണായി ഓഫായി മാറും, ഓണാകാനും ഓഫ് ആകാനും ഇടയിൽ അർധ സെക്കൻഡ് ഇടവേളയുണ്ട്. റിലേ ക്ലിക്ക് ഓണായി, ക്ലിക്ക് ഓഫ് ആയി എന്നൊരു ശബ്‌ദം നിങ്ങൾ കേൾക്കും. Grove ബോർഡിലുള്ള LED റിലേ ഓണായപ്പോൾ കൂടെ തെളിയും, ഓഫ് ആയപ്പോൾ മങ്ങിയിരിക്കും.

    ![റിലേ യന്ത്രം ഓണാക്കി ഓഫ് ആക്കുന്നത്](../../../../../images/relay-turn-on-off.gif)

## മണ്ണിന്റെ ഈർപ്പം മൂലം റീലേ നിയന്ത്രിക്കുക

ഇപ്പോൾ റീലേ പ്രവർത്തിക്കുന്നതിനാൽ, മണ്ണിന്റെ ഈർപ്പത്തെ അനുഗമിച്ച് അത് നിയന്ത്രിക്കാം.

### ടാസ്‌ക്

റീലേ നിയന്ത്രിക്കുക.

1. റിലേ പരിശോധനയ്ക്കായി ചേർത്ത 3 ലൈനുകൾ നീക്കം ചെയ്യുക. അവയുടെ പകരം താഴെ കാണിക്കുന്ന കോഡ് ഉപയോഗിക്കുക:

    ```python
    if soil_moisture > 450:
        print("Soil Moisture is too low, turning relay on.")
        relay.on()
    else:
        print("Soil Moisture is ok, turning relay off.")
        relay.off()
    ```

    ഈ കോഡ് മണ്ണിന്റെ ഈർപ്പ് സെൻസറിൽ നിന്ന് മണ്ണിന്റെ ഈർപ്പ് നില പരിശോധിക്കുന്നു. 450-ലധികമെങ്കിൽ റിലേ ഓണാക്കും, 450-ക്കു താഴെയായാൽ റിലേ ഓഫ് ചെയ്യും.

    > 💁 ഓർമ്മിക്കുക, കാപാസിറ്റീവിൻ മണ്ണിന്റെ ഈർപ്പം സെൻസർ താഴ്ന്ന ഉള്ളടക്കമുള്ള മണ്ണിന്റെ ഈർപ്പം കൂടുതൽ ആണെന്ന് വായിക്കുന്നു, അതിനാൽ കൂടുതൽ ഈർപ്പം കൂടുതലാണെന്ന് മനസ്സിലാക്കാം.

1. Python ആപ്പ് റൺ ചെയ്യുക. മണ്ണിന്റെ ഈർപ്പ് നില അനുസരിച്ച് റീലേ ഓണോ ഓഫ് ആണോ എന്ന് നിങ്ങൾ കാണും. വരണ്ട മണ്ണിൽ പരീക്ഷിച്ച്, പിന്നീട് വെള്ളം ചേർക്കുക.

    ```output
    Soil Moisture: 638
    Soil Moisture is too low, turning relay on.
    Soil Moisture: 452
    Soil Moisture is too low, turning relay on.
    Soil Moisture: 347
    Soil Moisture is ok, turning relay off.
    ```
