# വാചകം പരിഭാഷപ്പെടുത്തുക - വിർച്വൽ IoT ഉപകരണം

പാഠത്തിന്റെ ഈ ഭാഗത്തിൽ, വാഗ് മൊഴിവിളക്ക് ഉപയോഗിച്ച് സംസാരിച്ച വാചകത്തെ ആക്ഷരരൂപത്തിൽ മാറ്റുമ്പോൾ സംസാരിച്ചുoവാചകത്തെ പരിഭാഷപ്പെടുത്തുന്നതിനും പിന്നീട് വിവർത്തകസേവനം ഉപയോഗിച്ച് വാചകം പരിഭാഷപ്പെടുത്തി, സംസാരിച്ച മറുപടി സൃഷ്ടിക്കുന്നതിനും നിങ്ങൾ കോഡ് എഴുതും.

## വാചകം പരിഭാഷപ്പെടുത്താൻ വാഗ് മൊഴിവിളക്ക് സേവനം ഉപയോഗിക്കുക

വാഗ് മൊഴിവിളക്ക് സേവനം സംസാരിച്ച വാചകം കൈക്കൊണ്ട് അതേ ഭാഷയിൽ ആക്ഷരരൂപത്തിലേക്ക് മാത്രമല്ല, മറ്റു ഭാഷകളിലേക്കും പരിഭാഷപ്പെടുത്താൻ കഴിയും.

### ദൗത്യം - വാചകം പരിഭാഷപ്പെടുത്താൻ വാഗ് മൊഴിവിളക്ക് സേവനം ഉപയോഗിക്കുക

1. VS Code ൽ `smart-timer` പ്രോജക്ട് പുതിയതായി തുറക്കുക, ടെർമിനലിൽ വിർച്വൽ എൻവയരൺമെന്റ് ലോഡ് ചെയ്തിട്ടുണ്ടെന്ന് ഉറപ്പു വരുത്തുക.

1. നിലവിലുള്ള ഇറക്കുമതി നിർദേശങ്ങളുടെ താഴെ താഴെ നൽകിയിരിക്കുന്ന ഇറക്കുമതി നിർദേശങ്ങൾ ചേർക്കുക:

    ```python
    from azure.cognitiveservices import speech
    from azure.cognitiveservices.speech.translation import SpeechTranslationConfig, TranslationRecognizer
    import requests
    ```

    ഇത് സംസാരിച്ച വാചകം പരിഭാഷപ്പെടുത്താൻ ഉപയോഗിക്കുന്ന ക്ലാസ്സുകളും, പിന്നീട് ഈ പാഠത്തിൽ വിവർത്തക സേവനത്തിലേക്ക് കോളു ചെയ്യുന്നതിനായി ഉപയോഗിക്കുന്ന `requests` ലൈബ്രറിയും ഇറക്കുമതി ചെയ്യുന്നു.

1. നിങ്ങളുടെ സ്മാർട്ട് ടൈമറിന് 2 ഭാഷകൾ സജ്ജീകരിച്ചിരുന്നു - LUIS പരിശീലിപ്പിക്കാൻ ഉപയോഗിച്ച സെർവറിന്റെ ഭാഷ (അതേ ഭാഷ ഉപയോക്താവുമായി സംസാരിക്കാനോ സന്ദേശങ്ങൾ സൃഷ്ടിക്കാൻ ഉപയോഗിക്കുന്നു), കൂടാതെ ഉപയോക്താവ് സംസാരിക്കുന്ന ഭാഷ. ഉപയോക്താവ് സംസാരിക്കുന്ന ഭാഷയായ `language` വ്യവസ്ഥ പുതുക്കുക, കൂടാതെ LUIS പരിശീലിപ്പിക്കാൻ ഉപയോഗിച്ച ഭാഷയായ `server_language` എന്ന പുതിയ വ്യവസ്ഥ ചേർക്കുക:

    ```python
    language = '<user language>'
    server_language = '<server language>'
    ```

    `<user language>` നെ നിങ്ങൾ സംസാരിക്കുന്ന ഭാഷയുടെയും ഭാഷാ ലൊക്കേൽ പേരിലായി മാറ്റുക, ഉദാഹരണത്തിന് ഫ്രഞ്ച് ഭാഷക്കായി `fr-FR` അല്ലെങ്കിൽ കാന്തോനീസ് ഭാഷക്കായി `zn-HK`.

    `<server language>` നെ LUIS പരിശീലിപ്പിക്കാൻ ഉപയോഗിച്ച ഭാഷയുടെ ലൊക്കേൽ പേരിലായി മാറ്റുക.

    പിന്തുണയുള്ള ഭാഷകളും അവയുടെ ലൊക്കേൽ പേരുകളും [Language and voice support documentation on Microsoft docs](https://docs.microsoft.com/azure/cognitive-services/speech-service/language-support?WT.mc_id=academic-17441-jabenn#speech-to-text) എന്ന ദസ്താവേസിലെ പട്ടികയിൽ കാണാൻ കഴിയും.

    > 💁 നിങ്ങൾക്ക് ഏറെയുള്ള ഭാഷകൾ സംസാരിക്കാത്ത പക്ഷം [Bing Translate](https://www.bing.com/translator) അല്ലെങ്കിൽ [Google Translate](https://translate.google.com) പോലുള്ള സേവനം ഉപയോഗിച്ച് നിങ്ങളുടെ അറിവിലോ ഇഷ്ടഭാഷയിലോ നിന്നു ഏതെങ്കിലും ഒരു ഭാഷയിലേക്ക് പരിഭാഷപ്പെടുത്താം. ഈ സേവനങ്ങൾ വിവർത്തനം ചെയ്ത വാചകത്തിന്റെ ഓഡിയോ പ്ലേ ചെയ്യാനും കഴിയുന്നു. എന്നാൽ, വാചക പരിചയപ്പെടുത്തുന്ന സംവിധാനത്തിൽ നിങ്ങളുടെ ഉപകരണത്തിന്റെ ചില ഓഡിയോ ഔട്ട്പുട്ട് ശ്രദ്ധിക്കില്ലെന്ന് ശ്രദ്ധിക്കുക, അതിനാൽ വിവർത്തനം ചെയ്ത വാചകത്തിന് പകരം മറ്റൊരു ഉപകരണം ഓഡിയോ പ്ലേ ചെയ്യേണ്ടി വരാം.
    >
    > ഉദാഹരണത്തിന്, നിങ്ങൾ LUIS ഇംഗ്ലീഷിൽ പരിശീലിപ്പിച്ചുവെങ്കിൽ, ഉപയോക്താവിന്റെ ഭാഷയാകാൻ ഫ്രഞ്ച് തിരഞ്ഞെടുക്കുമെങ്കിൽ, Bing Translate ഉപയോഗിച്ച് "set a 2 minute and 27 second timer" എന്ന വാചകത്തെ ഇംഗ്ലീഷിൽ നിന്ന് ഫ്രഞ്ചിലേക്ക് പരിഭാഷപ്പെടുത്തി, പിന്നീട് **Listen translation** ബട്ടൺ ഉപയോഗിച്ച് വിവർത്തനം മൈക്രോഫോണിൽ സംസാരിക്കാം.
    >
    > ![ബിംഗ് ട്രാൻസ്ലേറ്റ്-ൽ ഉള്ള ലിസൺ ട്രാൻസ്ലേഷൻ ബട്ടൺ](../../../../../translated_images/ml/bing-translate.348aa796d6efe2a9.png)

1. `recognizer_config` ഉം `recognizer` ഉം സ്ഥാപിക്കുന്ന നിർദേശങ്ങൾ താഴെ കൊടുത്തതുപോലെ മാറ്റുക:

    ```python
    translation_config = SpeechTranslationConfig(subscription=speech_api_key,
                                                 region=location,
                                                 speech_recognition_language=language,
                                                 target_languages=(language, server_language))
    
    recognizer = TranslationRecognizer(translation_config=translation_config)
    ```

    ഇത് ഉപയോക്താവിന്റെ ഭാഷയിൽ സംസാരമുള്ള വാചകം തിരിച്ചറിയാനും ഉപയോക്താവിന്റെ ഭാഷയിലും സെർവർ ഭാഷയിലും വിവർത്തനം സൃഷ്ടിക്കാനും ട്രാൻസ്ലേഷൻ കോൺഫിഗ്റേഷൻ സൃഷ്ടിക്കുന്നു. തുടർന്ന്, ഇത് ഉപയോഗിച്ച് ഒരു ട്രാൻസ്ലേഷൻ തിരിച്ചറിയുന്ന ഉപകരണം സൃഷ്ടിക്കുന്നു - സംസാരിച്ച വാചകത്തെ പരിഭാഷപ്പെടുത്താൻ കഴിയും വാഗ് തിരിച്ചറിയുന്ന ഉപകരണം.

    > 💁 `target_languages` ല്‍ പ്രാഥമിക ഭാഷ വ്യക്തമാക്കേണ്ടതാണ്, അല്ലെങ്കിൽ വിവർത്തനങ്ങൾ ലഭിക്കില്ല.

1. `recognized` ഫങ്ഷൻ അപ്ഡേറ്റ് ചെയ്ത് ഫങ്ഷനിലെ എല്ലാ ഉള്ളടക്കവും താഴെയുള്ള രീതിയിൽ മാറ്റുക:

    ```python
    if args.result.reason == speech.ResultReason.TranslatedSpeech:
        language_match = next(l for l in args.result.translations if server_language.lower().startswith(l.lower()))
        text = args.result.translations[language_match]
        if (len(text) > 0):
            print(f'Translated text: {text}')
    
            message = Message(json.dumps({ 'speech': text }))
            device_client.send_message(message)
    ```

    ഇവിടെ ആദ്യത്തേത് വാചക പരിഭാഷപ്പെടുത്തിയതിനാൽ തിരിച്ചറിയല്‍ സംഭവം ഉണർത്തിയോ എന്നത് പരിശോധിക്കുന്നു (ഇവെന്റ് മറ്റു സമയങ്ങളിലും ഉണ്ടാകാം, ഉദാഹരണത്തിന് വാചകം തിരിച്ചറിഞ്ഞെങ്കിലും പരിഭാഷയില്ല). വാചകം പരിഭാഷപ്പെടുത്തിയെങ്കിൽ, `args.result.translations` ഡിക്ഷണറിയിൽ സെർവർ ഭാഷയെ അനുയോജ്യമായ പരിഭാഷ കണ്ടെത്തുന്നു.

    `args.result.translations` ഡിക്ഷണറിയിൽ ഭാഷയുടെ ലൊക്കേൽ സെറ്റിങ്ങിന്റെ ഭാഷ ഭാഗം കീ ആയി ഉപയോഗിക്കുന്നു, പൂർണ്ണ സെറ്റിംഗ് അല്ല. ഉദാഹരണത്തിന്, ഫ്രഞ്ചിന് `fr-FR` എന്ന പരിഭാഷ ആവശ്യപ്പെട്ടാൽ, ഡിക്ഷണറിയിൽ `fr` എൻട്രി ഉണ്ടായിരിക്കും, `fr-FR` അല്ല.

    പരിഭാഷപ്പെടുത്തിയ വാചകം പിന്നീട് IoT ഹബിലേക്ക് അയയ്ക്കുന്നു.

1. ഈ കോഡ് പരീക്ഷിച്ച് പരിഭാഷകൾ പരിശോധിക്കുക. നിങ്ങളുടെ ഫങ്ഷൻ ആപ്പ് പ്രവർത്തനത്തിലാണ് എന്ന് ഉറപ്പാക്കുക, ഉപയോക്താവ് സംസാരിക്കുന്ന ഭാഷയിൽ ടൈമർ ആവശ്യപ്പെടുക, അതോ നിങ്ങളേ സംസാരിക്കുകയോ മറ്റൊരു പരിഭാഷ ആപ്പ് ഉപയോഗിക്കുകയോ ചെയ്യുക.

    ```output
    (.venv) ➜  smart-timer python app.py
    Connecting
    Connected
    Translated text: Set a timer of 2 minutes and 27 seconds.
    ```

## വിവർത്തകസേവനം ഉപയോഗിച്ച് വാചകം പരിഭാഷപ്പെടുത്തുക

വാഗ് മൊഴിവിളക്ക് സേവനം വാചകം തിരിച്ചറിയുന്നതിലും പരിഭാഷ ചെയ്യുന്നതിലും സഹായിക്കുമ്പോൾ, വാചകം തിരിച്ചടി സംസാരത്തിലേക്ക് മാറ്റാനുള്ള സവിശേഷത നൽകുന്നില്ല. എന്നാൽ, വാചകം പരിഭാഷപ്പെടുത്താൻ നിങ്ങൾക്ക് വിവർത്തക സേവനം ഉപയോഗിക്കാം. ഈ സേവനം ഒരു REST API ഉണ്ട്, അത് ഈ വാചകം പരിഭാഷയ്ക്ക് ഉപയോഗിക്കാം.

### ദൗത്യം - വിവർത്തകൻറെ വിമുഖം ഉപയോഗിച്ച് വാചകം പരിഭാഷപ്പെടുത്തുക

1. `speech_api_key` മുകളിൽ വിവർത്തക API കീ ചേർക്കുക:

    ```python
    translator_api_key = '<key>'
    ```

    `<key>` എന്നിടത്ത് നിങ്ങളുടെ വിവർത്തകൻറെ സേവനം ലഭിക്കുന്ന API കീ ചേർക്കുക.

1. `say` ഫങ്ഷനിന് മുകളിൽ, സർവർ ഭാഷയിൽ നിന്നു ഉപയോക്താവിന്റെ ഭാഷയിലേക്ക് വാചകം പരിഭാഷപ്പെടുത്തുന്ന `translate_text` ഫങ്ഷൻ നിർവ്വചിക്കുക:

    ```python
    def translate_text(text):
    ```

1. ഈ ഫങ്ഷനിൽ REST API വിളിക്കാനുള്ള URL ഉം ഹെഡറുകളും നിർവ്വചിക്കുക:

    ```python
    url = f'https://api.cognitive.microsofttranslator.com/translate?api-version=3.0'

    headers = {
        'Ocp-Apim-Subscription-Key': translator_api_key,
        'Ocp-Apim-Subscription-Region': location,
        'Content-type': 'application/json'
    }
    ```

    ഈ APIയുടെ URL സ്ഥലം-പ്രധാനമല്ല, അതിനാൽ സ്ഥലം ഹെഡറുകളിൽ നൽകുന്നു. API കീ നേരിട്ട് ഉപയോഗിക്കുന്നു, അതിനാൽ വാഗ് മൊഴിവിളക്ക് സേവനത്തോട് സമാനമായി ടോക്കൺ പ്രാപിക്കുന്ന ആവശ്യമില്ല.

1. താഴെ ക്ലാസ് വിപരീതമായ പാരാമീറ്ററുകളും ബോഡിയും നിർവചിക്കുക:

    ```python
    params = {
        'from': server_language,
        'to': language
    }

    body = [{
        'text' : text
    }]
    ```

    `params` API വിളിക്കുമ്പോൾ നൽകേണ്ട പാരാമീറ്ററുകൾ നിർവചിക്കുന്നു: പരിഭാഷ ചെയ്യേണ്ട ഭാഷകളും. ഈ വിളിയിൽ `from` ഭാഷയിൽ ഉള്ള വാചകം `to` ഭാഷയിലേക്കു പരിഭാഷ ചെയ്യും.

    `body` പരിഭാഷിക്കേണ്ട വാചകമാണ്. ഇത് ഒരു പട്ടികയാണ്, ഒരേസമയം അംഗങ്ങൾ പല വാചക ശേഖരവും പരിഭാഷാക്കാം.

1. REST API വിളിയ്ക്കുക, പ്രതികരണം ലഭിക്കുക:

    ```python
    response = requests.post(url, headers=headers, params=params, json=body)
    ```

    തിരിച്ചറിയുന്ന പ്രതികരണം JSON പട്ടികയാണു, ഒന്നാമത്തെ ഐറ്റം വാചക പരിഭാഷകളടങ്ങിയതാണ്. ഈ ഐറ്റത്തിൽ ശരീരത്തിൽ ചേർക്കപ്പെട്ട എല്ലാ വാചകത്തിന്റെയും വിവർത്തനങ്ങൾ അടങ്ങിയ പട്ടിക ഉണ്ട്.

    ```json
    [
        {
            "translations": [
                {
                    "text": "Chronométrant votre minuterie de 2 minutes 27 secondes.",
                    "to": "fr"
                }
            ]
        }
    ]
    ```

1. പട്ടികയിലെ ആദ്യം ഐറ്റത്തിലെ ആദ്യപരിഭാഷയുടെ `text` പ്രോപർട്ടി തിരിച്ചുവെക്കുക:

    ```python
    return response.json()[0]['translations'][0]['text']
    ```

1. SSML സൃഷ്ടിക്കുന്നതിന് മുമ്പ്, സംസാരിക്കാനുള്ള വാചകം പരിഭാഷ ചെയ്യുന്നതായി `say` ഫങ്ഷൻ പുതുക്കുക:

    ```python
    print('Original:', text)
    text = translate_text(text)
    print('Translated:', text)
    ```

    ഈ കോഡ് മുതൽ വാചകത്തിന്റെ യഥാർത്ഥവും പരിഭാഷിച്ച പതിപ്പും കൺസോളിൽ പ്രിന്റ് ചെയ്യും.

1. കോഡ് പരീക്ഷിക്കുക. നിങ്ങളുടെ ഫങ്ഷൻ ആപ്പ് പ്രവർത്തനത്തിലാണ് എന്ന് ഉറപ്പാക്കുക, ഉപയോക്താവിന്റെ ഭാഷയിൽ ടൈമർ ആവശ്യപ്പെടുക, താങ്കൾ തന്നെ ആ ഭാഷ സംസാരിക്കുകയോ വിവർത്തക ആപ്പ് ഉപയോഗിക്കുകയോ ചെയ്യുക.

    ```output
    (.venv) ➜  smart-timer python app.py
    Connecting
    Connected
    Translated text: Set a timer of 2 minutes and 27 seconds.
    Original: 2 minute 27 second timer started.
    Translated: 2 minute 27 seconde minute a commencé.
    Original: Times up on your 2 minute 27 second timer.
    Translated: Chronométrant votre minuterie de 2 minutes 27 secondes.
    ```

    > 💁 വ്യത്യസ്ത ഭാഷകളിൽ പറയുന്ന രീതികളുടെ വ്യത്യാസം കാരണം, LUIS-ന് നൽകിയ ഉദാഹരണങ്ങളേക്കാൾ വ്യത്യസ്തമായ പരിഭാഷകൾ ലഭിക്കാം. അങ്ങനെ ആണെങ്കിൽ, LUIS-ൽ കൂടുതൽ ഉദാഹരണങ്ങൾ ചേർത്ത് വീണ്ടും പരിശീലിപ്പിക്കുക, ശേഷം മോഡൽ പുനഃപ്രസിദ്ധീകരിക്കുക.
