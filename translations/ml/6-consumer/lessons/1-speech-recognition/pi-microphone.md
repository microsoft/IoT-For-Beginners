# മൈക്രോഫോൺയും സ്‌പീക്കറുകളും ക്രമീകരിക്കുക - റാസ്ബെറി പൈ

പാഠത്തിന്റെ ഈ ഭാഗത്തിൽ, നിങ്ങൾ നിങ്ങളുടെ റാസ്ബെറി പൈയിൽ ഒരു മൈക്രോഫോൺയും സ്‌പീക്കറുകളും ചേർക്കും.

## ഹാർഡ്‌വെയർ

റാസ്ബെറി പൈയ്ക്ക് ഒരു മൈക്രോഫോൺ വേണം.

പൈയിൽ മൈക്രോഫോൺ ഉൾപ്പെടുത്തിയിട്ടില്ല, നിങ്ങൾക്ക് ഒരു ബാഹ്യ മൈക്രോഫോൺ ചേർക്കേണ്ടതുണ്ട്. ഇത് ചെയ്യാനുള്ള വിവിധ മാർഗ്ഗങ്ങൾ ഉണ്ട്:

* USB മൈക്രോഫോൺ
* USB ഹെഡ്‌സെറ്റ്
* USB ഓൾ ഇൻ വൺ സ്‌പീക്കർഫോൺ
* USB ഓഡിയോ അഡാപ്റ്ററും 3.5mm ജാക്കുള്ള മൈക്രോഫോൺ
* [ReSpeaker 2-Mics Pi HAT](https://www.seeedstudio.com/ReSpeaker-2-Mics-Pi-HAT.html)

> 💁 ബ്ളൂടൂത്ത് മൈക്രോഫോണുകൾ റാസ്ബെറി പൈയിൽ എല്ലാമ_SUPPORTED_UNSUPPORTED അല്ല, അതിനാൽ ബ്ളൂടൂത്ത് മൈക്രോഫോൺ അല്ലെങ്കിൽ ഹെഡ്‌സെറ്റ് ഉണ്ടെങ്കിൽ, നിങ്ങളക്ക് ജോഡിച്ചേക്കൽ അല്ലെങ്കിൽ ഓഡിയോ പിടിക്കുന്നതിൽ പ്രശ്നങ്ങൾ ഉണ്ടാകാൻ സാധ്യതയുണ്ട്.

റാസ്ബെറി പൈകൾ 3.5mm ഹെഡ്‌ഫോൺ ജാക്കുള്ളതാണ്. ഇതുപയോഗിച്ച് നിങ്ങൾ ഹെഡ്‌ഫോൺ, ഹെഡ്‌സെറ്റ് അല്ലെങ്കിൽ സ്‌പീക്കർ ബന്ധിപ്പിക്കാം. കൂടാതെ, സ്‌പീക്കറുകൾ ചേർക്കാൻ നിങ്ങൾക്ക് സാധിക്കും:

* മോണിറ്റർ അല്ലെങ്കിൽ ടിവി വഴി HDMI ഓഡിയോ
* USB സ്‌പീക്കറുകൾ
* USB ഹെഡ്‌സെറ്റ്
* USB ഓൾ ഇൻ വൺ സ്‌പീക്കർഫോൺ
* [ReSpeaker 2-Mics Pi HAT](https://www.seeedstudio.com/ReSpeaker-2-Mics-Pi-HAT.html) 3.5mm ജാക്ക് അല്ലെങ്കിൽ JST പോർട്ടിലേക്ക് speaker അറ്റാച്ച് ചെയ്തുള്ളത്

## മൈക്രോഫോൺയും സ്‌പീക്കറുകളും ബന്ധിപ്പിച്ച് ക്രമീകരിക്കുക

മൈക്രോഫോൺും സ്‌പീക്കറുകളും ബന്ധിപ്പിച്ച് ക്രമീകരിക്കേണ്ടതാണ്.

### ടാസ്‌ക് - മൈക്രോഫോൺ ബന്ധിപ്പിച്ച് ക്രമീകരിക്കുക

1. അനുയോജ്യമായ മാർഗ്ഗം ഉപയോഗിച്ച് മൈക്രോഫോൺ ബന്ധിപ്പിക്കുക. ഉദാഹരണത്തിന്, USB പോർട്ടുകളിൽ ഒന്നിലൂടെ ഇത് ബന്ധിപ്പിക്കുക.

1. നിങ്ങൾ ReSpeaker 2-Mics Pi HAT ഉപയോഗിക്കുന്നുവെങ്കിൽ, Grove ബേസ്സ് ഹാറ്റ് നീക്കം ചെയ്ത് ReSpeaker ഹാറ്റ് അതിന്റെ സ്ഥാനത്ത് സജ്ജീകരിക്കാം.

    ![A raspberry pi with a ReSpeaker hat](../../../../../translated_images/ml/pi-respeaker-hat.f00fabe7dd039a93.png)

    ഈ പാഠത്തിൽ ശേഷം Grove ബട്ടൺ നിങ്ങൾക്കാവണം, എന്നാൽ ഇത് ഈ ഹാറ്റിൽ തന്നെ ഉൾപ്പെടുത്തിയിട്ടുള്ളതിനാൽ Grove ബേസ്സ് ഹാറ്റ് വേണ്ട.

    ഹാറ്റ് ഇൻസ്റ്റാൾ ചെയ്തശേഷം ഡ്രൈവർകൾ ഇൻസ്റ്റാൾ ചെയ്യേണ്ടതാണ്. ഡ്രൈവർ ഇൻസ്റ്റാൾ നിർദ്ദേശങ്ങൾക്കായി [Seeed getting started instructions](https://wiki.seeedstudio.com/ReSpeaker_2_Mics_Pi_HAT_Raspberry/#getting-started) കാണുക.

    > ⚠️ നിർദ്ദേശങ്ങൾ `git` ഉപയോഗിച്ച് ഒരു റെപ്പോസ് ക്ലോൺ ചെയ്യാൻ പറയുന്നു. നിങ്ങളുടെ പൈയിൽ `git` ഇൻസ്റ്റാൾ ചെയ്തിട്ടില്ലെങ്കിൽ, താഴെക്കൊടുത്തിരിക്കുന്ന കമാൻഡു റൺ ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്യാം:
    >
    > ```sh
    > sudo apt install git --yes
    > ```

1. പോതിയെയുള്ള മൈക്രോഫോണിനെക്കുറിച്ചുള്ള വിവരങ്ങൾ കാണാൻ, പൈയിൽ അല്ലെങ്കിൽ VS Code ഉപയോഗിച്ച് ഒരു റിമോട്ട് SSH സെഷൻ വഴി കണക്റ്റ് ചെയ്തുകൊണ്ടുള്ള ടെർമിനലിൽ താഴെക്കൊടുത്ത കമാൻഡ് തള്ളുക:

    ```sh
    arecord -l
    ```

    കണക്റ്റ് ചെയ്ത മൈക്രോഫോണുകളുടെ പട്ടികคุณ കാണും. ഇത് താഴെപറയുന്ന പോലെ ആയി ഉണ്ടാകാം:

    ```output
    pi@raspberrypi:~ $ arecord -l
    **** List of CAPTURE Hardware Devices ****
    card 1: M0 [eMeet M0], device 0: USB Audio [USB Audio]
      Subdevices: 1/1
      Subdevice #0: subdevice #0
    ```

    ധരിച്ചു നിങ്ങൾക്കൊരു മൈക്രോഫോൺ മാത്രമേ ഉള്ളൂ എങ്കിൽ, ഒരു എൻട്രി മാത്രം കാണാം. ലിനക്സിൽ മൈക്രോഫോണുകളുടെ ക്രമീകരണം പ്രയാസകരമാണ്, അതുകൊണ്ടു് ഒരു മൈക്രോഫോണും മാത്രം ഉപയോഗിച്ച് വെള്ളയ്‌ക്കുക ബest ആണ്.

    കാർഡ് നമ്പർ ശ്രദ്ധിക്കുക, നിങ്ങൾക്ക് ഇതിനോട് തുടർന്നും ആവശ്യമായിരിക്കും. മുകളിൽ കാണുന്ന ഔട്ട്പുട്ടിൽ കാർഡ് നമ്പർ 1 ആണ്.

### ടാസ്‌ക് - സ്‌പീക്കർ ബന്ധിപ്പിച്ച് ക്രമീകരിക്കുക

1. അനുയോജ്യമായ മാർഗ്ഗം ഉപയോഗിച്ച് സ്‌പീക്കറുകൾ ബന്ധിപ്പിക്കുക.

1. കണക്റ്റ് ചെയ്ത സ്‌പീക്കറുകളെക്കുറിച്ചുള്ള വിവരങ്ങൾ കാണാൻ, പൈയിൽ അല്ലെങ്കിൽ VS Code ഉപയോഗിച്ച് ഒരു റിമോട്ട് SSH സെഷൻ വഴി കണക്റ്റ് ചെയ്തുകൊണ്ടുള്ള ടെർമിനലിൽ താഴെക്കൊടുത്ത കമാൻഡ് തള്ളുക:

    ```sh
    aplay -l
    ```

    കണക്റ്റ് ചെയ്ത സ്‌പീക്കറുകളുടെ പട്ടിക കാണാൻ കഴിയും. ഇത് താഴെപ്പറയുന്ന പോലെ ആയിരിക്കും:

    ```output
    pi@raspberrypi:~ $ aplay -l
    **** List of PLAYBACK Hardware Devices ****
    card 0: Headphones [bcm2835 Headphones], device 0: bcm2835 Headphones [bcm2835 Headphones]
      Subdevices: 8/8
      Subdevice #0: subdevice #0
      Subdevice #1: subdevice #1
      Subdevice #2: subdevice #2
      Subdevice #3: subdevice #3
      Subdevice #4: subdevice #4
      Subdevice #5: subdevice #5
      Subdevice #6: subdevice #6
      Subdevice #7: subdevice #7
    card 1: M0 [eMeet M0], device 0: USB Audio [USB Audio]
      Subdevices: 1/1
      Subdevice #0: subdevice #0
    ```

    എല്ലാ സമയത്തും `card 0: Headphones` എന്ന് കാണും, ഇത് നെേറ്റിവ് ഹെഡ്‌ഫോൺ ജാക്ക് ആണ്. നിങ്ങൾ USB സ്പീക്കർ പോലുള്ള ഇൻക്രീമെന്റൽ സ്പീക്കറുകൾ ചേർത്തിട്ടുണ്ടെങ്കിൽ, അവയും പട്ടികയിൽ കാണും.

1. നിങ്ങൾ ഇൻക്രീമെന്റൽ സ്‌പീക്കർ ഉപയോഗിക്കുന്നുവെങ്കിൽ, മേൽപ്പറഞ്ഞ നെേറ്റിവ് ഹെഡ്‌ഫോൺ ജാക്കിൽ അല്ലാതെ, അതിനെ ഡിഫോൾട്ടായി ക്രമീകരിക്കേണ്ടതുണ്ട്. അതിന് താഴെ കൊടുത്ത കമാൻഡ് നടത്തുക:

    ```sh
    sudo nano /usr/share/alsa/alsa.conf
    ```

    ഇത് `nano` എന്ന ടെർമിനൽ അധിഷ്ഠിത ടെക്സ്റ്റ് എഡിറ്റർ തുറക്കും. കീബോർഡിലെ അപ്‌റോ അല്ലെങ്കിൽ ഡൗൺ ആറോ കീകൾ ഉപയോഗിച്ച് ചുവടെ കിടക്കുന്ന വര ഗ്രാമം വരെ സ്ക്രോൾ ചെയ്യുക:

    ```output
    defaults.pcm.card 0
    ```

    മൂല്യം `0` ൽ നിന്ന് നിങ്ങൾ ഉപയോഗിക്കാനുള്ള കാർഡ് നമ്പറിലേക്ക് മാറ്റുക, `aplay -l` കമാൻഡ് റൺ ചെയ്തപ്പോൾ കിട്ടിയ പട്ടികയിൽ നിന്നുള്ള കാർഡ് നമ്പർ. ഉദാഹരണത്തിന്, മുകളിൽ നൽകിയ ഔട്ട്പുട്ടിൽ രണ്ടാമത്തെ സൗണ്ട് കാർഡ് "`card 1: M0 [eMeet M0], device 0: USB Audio [USB Audio]`" ആണ്, കാർഡ് 1 ഉപയോഗിക്കുക. ഇത് ഉപയോഗിക്കാനായി, ഞാൻ വരി ഇങ്ങനെ മാറ്റും:

    ```output
    defaults.pcm.card 1
    ```

    ഈ മൂല്യം അനുയോജ്യമായ കാർഡ് നമ്പറായി സെറ്റ് ചെയ്യുക. കീബോർഡിലെ ആറോ കീകൾ ഉപയോഗിച്ച് നമ്പറിനു പോകാം, പിന്നീട് ഡിലീറ്റ് ചെയ്ത് പുതിയ നമ്പർ ടൈപ്പ് ചെയ്യാം സാധാരണ ടെക്സ്റ്റ് ഫയൽ എഡിറ്റിങ്ങിന്റെ പോലെ.

1. മാറ്റങ്ങൾ സേവ് ചെയ്ത് ഫയൽ അടയ്ക്കാൻ `Ctrl+x` അമർത്തുക. ഫയൽ സേവ് ചെയ്യാൻ `y` അമർത്തുക, തുടർന്ന് ഫയൽ നാമം തിരഞ്ഞെടുക്കുന്നതിനു റിട്ടേൺ അമർത്തുക.

### ടാസ്‌ക് - മൈക്രോഫോൺയും സ്‌പീക്കറിനും ടെസ്റ്റ് നടത്തുക

1. മൈക്രോഫോണിലൂടെ 5 സെക്കൻഡ് ഓഡിയോ റെക്കോർഡ് ചെയ്യാൻ താഴെ കൊടുത്ത കമാൻഡ് ഓടിക്കുക:

    ```sh
    arecord --format=S16_LE --duration=5 --rate=16000 --file-type=wav out.wav
    ```

    ഈ കമാൻഡ് chạy ചെയ്യുമ്പോൾ, മൈക്രോഫോണിലേക്ക് ശബ്ദമുണ്ടാക്കൂ – സംസാരിച്ചാലോ, പാടിക്കൊണ്ടായാലോ, ബീറ്റ് ബോക്സിംഗ് ചെയ്താലോ, യന്ത്രം വായിച്ചാലോ, എന്തായാലും.

1. 5 സെക്കൻഡ് കഴിഞ്ഞ്, റെക്കോർഡിങ് നിർത്തും. ഓഡിയോ പ്ലേ ചെയ്യാൻ താഴെക്കൊടുത്ത കമാൻഡ് റൺ ചെയ്യുക:

    ```sh
    aplay --format=S16_LE --rate=16000 out.wav
    ```

    ഓഡിയോ സ്‌പീക്കറുകളിൽ നിന്നും ബാക്ക് പ്ലേ ആണ് കേൾക്കുന്നത്. ആവശ്യമുള്ളത്ര ഐച്ച്ച്ച കളിക്ക് സ്പീക്കർ വോളിയം ക്രമീകരിക്കുക.

1. ബിൽറ്റ്-ഇൻ മൈക്രോഫോൺ പോർട്ട് വോളിയം ക്രമീകരിക്കേണ്ടെങ്കിൽ, അല്ലെങ്കിൽ മൈക്രോഫോണിന്റെ ഗെയിൻ ക്രമീകരിക്കേണ്ടെങ്കിൽ, `alsamixer` utility ഉപയോഗിക്കാം. ഇവിടെ കുറച്ചു വായിക്കാം [Linux alsamixer man page](https://linux.die.net/man/1/alsamixer)

1. ഓഡിയോ പ്ലേ ബാക്ക് ചെയ്യുമ്പോൾ എററുകൾ ഉണ്ടാകുന്നതെങ്കിൽ, നിങ്ങൾ `alsa.conf` ഫയലിൽ `defaults.pcm.card` ആയി സജ്ജമാക്കിയ കാർഡ് പരിശോധിക്കുക.
