# ಹಾರ್ಡ್‌ವೇರ್

IoT ನಲ್ಲಿ **T** ಅಂದರೆ **Things** ಮತ್ತು ಅದು ನಮ್ಮ ಸುತ್ತಲಿನ ಪ್ರಪಂಚದೊಂದಿಗೆ ಸಂವಹನ ಮಾಡುವ ಸಾಧನಗಳನ್ನು ಸೂಚಿಸುತ್ತದೆ. ಪ್ರತಿ ಪ್ರಾಜೆಕ್ಟ್ ನಿದ್ದರನ್ನು ಮತ್ತು ಹವ್ಯಾಸಿಗಳನ್ನು ಉಪಲಭ್ಯವಿರುವ ವಾಸ್ತವಿಕ ಹಾರ್ಡ್‌ವೇರ್ ಆಧಾರಿತವಾಗಿದೆ. ವೈಯಕ್ತಿಕ ಮೆಚ್ಚುಗೆಯು, ಪ್ರೋಗ್ರಾಮ್ಮಿಂಗ್ ಭಾಷಾ ಜ್ಞಾನ ಅಥವಾ ಅಭಿಪ್ರಾಯಗಳು, ಅಧ್ಯಯನ ಗುರಿಗಳು ಮತ್ತು ಲಭ್ಯತೆಯ ಮೇಲೆ ಅವಲಂಬಿಸಿ ಬಳಸಬೇಕಾದ IoT ಹಾರ್ಡ್‌ವೇರ್‌ಗೆ ನಮಗೆ ಎರಡು ಆಯ್ಕೆಗಳಿದ್ದು, ನಾವು ಹಾರ್ಡ್‌ವೇರ್‌ಗೆ ಪ್ರವೇಶವಿಲ್ಲದೆ ಇರುವವರಿಗೆ ಅಥವಾ ಖರೀದಿಸಲು ನಿರ್ಣಯಿಸುವ ಮೊದಲು ಹೆಚ್ಚಾಗಿ ತಿಳಿದುಕೊಳ್ಳಲು ಬಯಸುವವರಿಗೆ 'ವರ್ಚುವಲ್ ಹಾರ್ಡ್‌ವೇರ್' ಆವೃತ್ತಿ ಕೂಡ ಒದಗಿಸಿದ್ದೇವೆ.

> 💁 ನಿಮಗೆ ಕಾರ್ಯಗಳನ್ನು ಪೂರ್ಣಗೊಳಿಸಲು ಯಾವುದೇ IoT ಹಾರ್ಡ್‌ವೇರ್ ಖರೀದಿಸುವ ಅಗತ್ಯವಿಲ್ಲ. ನೀವು ವರ್ಚುವಲ್ IoT ಹಾರ್ಡ್‌ವೇರ್ ಬಳಸಿ ಎಲ್ಲವನ್ನೂ ಮಾಡಬಹುದು.

ವಾಸ್ತವ ಹಾರ್ಡ್‌ವೇರ್ ಆಯ್ಕೆಗಳು ಅರುಡಿನೋ ಅಥವಾ ರಾಸ್ಪ್ಬೆರಿ ಪೈ ಆಗಿವೆ. ಪ್ರತಿ ವೇದಿಕೆಗೆ ತನ್ನ ಸ್ವಂತ ಪ್ರಯೋಜನಗಳು ಮತ್ತು ಅಪಾಯಗಳಿವೆ, ಮತ್ತು ಇವುಗಳೆಲ್ಲವು ಆರಂಭಿಕ ಪಾಠಗಳಲ್ಲಿ ಒಂದರಲ್ಲಿ ಒಳಗೊಂಡಿವೆ. ನೀವು ಇನ್ನೂ ಯಾವುದೇ ಹಾರ್ಡ್‌ವೇರ್ ವೇದಿಕೆಯನ್ನು ಆಯ್ಕೆಮಾಡಿಲ್ಲದಿದ್ದರೆ, ನೀವು ಯಾವ ಹಾರ್ಡ್‌ವೇರ್ ವೇದಿಕೆಯನ್ನು ಅಧ್ಯಯನ ಮಾಡಲು ಹೆಚ್ಚು ಆಸಕ್ತರಾಗಿದ್ದೀರೋ ತಿಳಿದುಕೊಳ್ಳಲು [ಮೊದಲ ಪ್ರಾಜೆಕ್ಟ್‌ನ ಎರಡನೇ ಪಾಠ](./1-getting-started/lessons/2-deeper-dive/README.md) ಅನ್ನು ಪರಿಶೀಲಿಸಬಹುದು.

ನಿರ್ದಿಷ್ಟ ಹಾರ್ಡ್‌ವೇರ್ ಪಾಠಗಳು ಮತ್ತು ಕಾರ್ಯಗಳನ್ನು ಸರಳಗೊಳಿಸಲು ಆಯ್ಕೆಮಾಡಲಾಗಿದೆ. ಬೇರೆಯ ಹಾರ್ಡ್‌ವೇರ್ ಚಾಲನೆಯಲ್ಲಿರಬಹುದು, ಆದರೆ ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಎಲ್ಲಾ ಕಾರ್ಯಗಳನ್ನು ಬೆಂಬಲಿಸುವುದಾಗಿಯೂ ಗ್ಯಾರಂಟಿ ನೀಡಲಾಗುವುದಿಲ್ಲ. ಉದಾಹರಣೆಗೆ, ಬಹುತೇಕ ಅರುಡಿನೋ ಸಾಧನಗಳಿಗೆ WiFi ಇರುವುದಿಲ್ಲ, ಅದು ಕ್ಲೌಡ್‌ಗೆ ಸಂಪರ್ಕಿಸಲು ಬೇಕಾಗುತ್ತದೆ - Wio ಟರ್ಮಿನಲ್ ಅನ್ನು WiFi ಒಳಗೊಂಡಿರುವುದರಿಂದ ಆಯ್ಕೆ ಮಾಡಲಾಗಿದೆ.

ನಿಮಗೆ ಕೆಲವು ಅತಂತ್ರಜ್ಞಾನಿಕ ವಸ್ತುಗಳು ಸಹ ಬೇಕಾಗುತ್ತವೆ, ಉದಾಹರಣೆಗೆ ಮಣ್ಣು ಅಥವಾ ಸಸ್ಯದಟ್ಟಿಗೆ, ಮತ್ತು ಹಣ್ಣು ಅಥವಾ ತರಕಾರಿಗಳು.

## ರಾಸ್ಪ್ಬೆರಿ ಪೈ

ರಾಸ್ಪ್ಬೆರಿ ಪೈಗೆ ಸಂಯಂತ್ರ ಸಂಕೇತಗಳು Python ನಲ್ಲಿ ಇವೆ. ಎಲ್ಲಾ ಕಾರ್ಯಗಳನ್ನು ಪೂರ್ಣಗೊಳಿಸಲು ನೀವು ಕೆಳಕಂಡವು ಬೇಕಾಗುತ್ತವೆ:

* [ರಾಸ್ಪ್ಬೆರಿ ಪೈ](https://www.raspberrypi.org/products/raspberry-pi-4-model-b/)
  > 💁 Pi 2B ಮತ್ತು ಮೇಲ್ಮಟ್ಟದ ಮಾದರಿಗಳು ಈ ಪಾಠಗಳಲ್ಲಿ ಇರುವ ಕಾರ್ಯಗಳಿಗೆ ಮರೆತು ನಿರ್ವಹಿಸುವುದಕ್ಕೆ ಸಾಧಾರಣ. ನೀವು ಪೈ ಮೇಲೆ ನೇರವಾಗಿ VS ಕೋಡ್ ಚಲಾಯಿಸಲು ಬಯಸಿದರೆ, Pi 4 ಮತ್ತು 2GB ಅಥವಾ ಹೆಚ್ಚು RAM ಬೇಕಾಗುತ್ತದೆ. ನೀವು ಪೈಗೆ ದೂರದಿಂದ ಪ್ರವೇಶ ಪಡೆಯುತ್ತೀರಾದರೆ ಯಾವುದೇ Pi 2B ಮತ್ತು ಮೇಲ್ಮಟ್ಟದ ಮಾದರಿಗಳು ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ.
* microSD ಕಾರ್ಡ್ (ರಾಸ್ಪ್ಬೆರಿ ಪೈ ಕಿಟ್‌ಗಳಲ್ಲಿ microSD ಕಾರ್ಡ್ ಒದಗಿಸಲಾಗುತ್ತದೆ), ಮತ್ತು ನೀವು ಹೊಂದಿಲ್ಲದಿದ್ದರೆ SD ಕಾರ್ಡ್ ಅನ್ನು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಉಪಯೋಗಿಸಲು ಕನಕ್ಟರ್.
* USB ಪವರ್ ಸರಬರಾಜು (ರಾಸ್ಪ್ಬೆರಿ ಪೈ 4 ಕಿಟ್‌ಗಳಲ್ಲಿ ಪವರ್ ಸರಬರಾಜು ಇದ್ದು ಬರುತ್ತದೆ). ರಾಸ್ಪ್ಬೆರಿ ಪೈ 4 ಬಳಸಿದರೆ USB-C ಪವರ್ ಸರಬರಾಜು ಬೇಕಾಗುತ್ತದೆ, ಹಳೆಯ ಸಾಧನಗಳು ಮೈಕ್ರೋ-USB ಪವರ್ ಸರಬರಾಜು ಹೊಂದಿರಬೇಕು.
