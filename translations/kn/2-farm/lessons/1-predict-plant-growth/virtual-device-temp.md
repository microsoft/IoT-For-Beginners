# ತಾಪಮಾನವನ್ನು ಅಳೆಯಿರಿ - ವರ್ಚುವಲ್ ಐಒಟಿ ಹಾರ್ಡ್ವೇರ್

ಪಾಠದ ಈ ಭಾಗದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ವರ್ಚುವಲ್ ಐಒಟಿ ಸಾಧನಕ್ಕೆ ತಾಪಮಾನ ಸೆನ್ಸಾರನ್ನು ಸೇರಿಸುತ್ತೀರಿ.

## ವರ್ಚುವಲ್ ಹಾರ್ಡ್ವೇರ್

ವರ್ಚುವಲ್ ಐಒಟಿ ಸಾಧನವು ಅನುಕರಿಸಿದ Grove ಡಿಜಿಟಲ್ ಹ್ಯೂಮಿಡಿಟಿ ಮತ್ತು ತಾಪಮಾನ ಸೆನ್ಸಾರನ್ನು ಬಳಸುತ್ತದೆ. ಇದು ಈ ಪ್ರಯೋಗಶಾಲೆಯನ್ನು ಒಂದು ಭೌತಿಕ Grove DHT11 ಸೆನ್ಸಾರನ್ನು ಹೊಂದಿರುವ ರಾಸ್ಬೆರ್ರಿ ಪೈ ಬಳಕೆಯಾಗಿ ಇತ್ಯಥಾವತ್ತಾಗಿಸುತ್ತದೆ.

ಸೆನ್ಸಾರವು **ತಾಪಮಾನ ಸೆನ್ಸಾರ** ಮತ್ತು **ಈರುಳ್ಳಿ ಸೆನ್ಸಾರ** ಎರಡುಗಳನ್ನು ಮಿಶ್ರಿಸುತ್ತದೆ, ಆದರೆ ಈ ಪ್ರಯೋಗಶಾಲೆಯಲ್ಲಿ ನೀವು ಕೇವಲ ತಾಪಮಾನ ಸೆನ್ಸಾರ ಘಟಕದಲ್ಲಿ ಮಾತ್ರ ಆಸಕ್ತಿ ಹೊಂದಿದ್ದೀರಿ. ಭೌತಿಕ ಐಒಟಿ ಸಾಧನದಲ್ಲಿ, ತಾಪಮಾನ ಸೆನ್ಸಾರವು ತಾಪಮಾನವಾಗಿ ಪ್ರತಿರೋಧದ ಬದಲಾವಣೆಯನ್ನು ಸಂವೇದಿಸುವ ಮೂಲಕ ತಾಪಮಾನವನ್ನು ಅಳೆಯುವ [ಥರ್ಮಿಸ್ಟರ್](https://wikipedia.org/wiki/Thermistor) ಆಗಿರುತ್ತದೆ. ತಾಪಮಾನ ಸೆನ್ಸಾರಗಳು ಸಾಮಾನ್ಯವಾಗಿ ಡಿಜಿಟಲ್ ಸೆನ್ಸಾರ್ಗಳು ಆಗಿದ್ದು, ಅವು ಒಳಗಾಗಿಯೇ ಅಳೆಯಲಾದ ಪ್ರತಿರೋಧವನ್ನು ಸೆಲ್ಸಿಯಸ್ (ಅಥವಾ ಕೆಲ್ವಿನ್ ಅಥವಾ ಫಾರೆನ್ಹೀಟ್) ದರ್ಜೆಯಲ್ಲಿ ತಾಪಮಾನಕ್ಕೆ ಪರಿವರ್ತಿಸುತ್ತವೆ.

### CounterFit ಗೆ ಸೆನ್ಸಾರ್ ಗಳನ್ನು ಸೇರಿಸಿ

ವರ್ಚುವಲ್ ಹ್ಯೂಮಿಡಿಟಿ ಮತ್ತು ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಬಳಸಲು ನೀವು ಎರಡು ಸೆನ್ಸಾರ್ ಗಳನ್ನು CounterFit ಅಪ್ಲಿಕೇಶನ್ ಗೆ ಸೇರಿಸುವ ಅಗತ್ಯವಿದೆ

## ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಅಪ್ಲಿಕೇಶನ್ ಪ್ರೋಗ್ರಾಂ ಮಾಡಿ

ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಅಪ್ಲಿಕೇಶನ್ ಈಗ CounterFit ಸೆನ್ಸಾರ್ ಗಳನ್ನು ಬಳಸಿಕೊಂಡು ಪ್ರೋಗ್ರಾಂ ಮಾಡಬಹುದು.

### ಕಾರ್ಯ - ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಅಪ್ಲಿಕೇಶನ್ ಪ್ರೋಗ್ರಾಂ ಮಾಡಿ

ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಅಪ್ಲಿಕೇಶನ್ನನ್ನು ಪ್ರೋಗ್ರಾಂ ಮಾಡಿ.

1. `temperature-sensor` ಅಪ್ಲಿಕೇಶನ್ VS Code ನಲ್ಲಿ ತೆರೆಯಿರಿ

1. `app.py` ಫೈಲ್ ತೆಗೆಯಿರಿ

1. ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು CounterFit ಗೆ ಸಂಪರ್ಕಿಸಲು `app.py` ಪ್ರಾರಂಭದಲ್ಲಿ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    from counterfit_connection import CounterFitConnection
    CounterFitConnection.init('127.0.0.1', 5000)
    ```

1. ಅಗತ್ಯವಿರುವ ಗ್ರಂಥಾಲಯಗಳನ್ನು ಆಮದು ಮಾಡಲು `app.py` ಗೆ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    import time
    from counterfit_shims_seeed_python_dht import DHT
    ```

    `from seeed_dht import DHT` ಹೇಳಿಕೆ `DHT` ಸೆನ್ಸಾರ್ ಕ್ಲಾಸ್ ಅನ್ನು ಆಮದುಮಾಡುತ್ತದೆ, ಇದು virtual Grove ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಜೊತೆಗೆ ಆಂತರಿಕವಾಗಿ CounterFit Shim ಬಳಸಿ ಸಂವಹನ ಮಾಡುವುದಕ್ಕೆ.

1. ವರ್ಚುವಲ್ ಹ್ಯೂಮಿಡಿಟಿ ಮತ್ತು ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ನ್ನು ನಿರ್ವಹಿಸುವ ಕ್ಲಾಸ್ ನ ಉದಾಹರಣೆ ಸೃಷ್ಟಿಸಲು ಮೇಲಿನ ಕೋಡ್ ನಂತರ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    sensor = DHT("11", 5)
    ```

    ಇದು ವರ್ಚುವಲ್ **D**igital **H**umidity ಮತ್ತು **T**emperature ಸೆನ್ಸಾರ್ ನ್ನು ನಿರ್ವಹಿಸುವ `DHT` ಕ್ಲಾಸ್ ನೋಡಿಕೆ ಅನ್ನು ಘೋಷಿಸುತ್ತದೆ. ಮೊದಲ ಪ್ಯಾರಮೀಟರ್ ಮೂಲಕ ಕೋಡ್ ಗೆ ಸೆನ್ಸಾರ್ ಒಂದು ವರ್ಚುವಲ್ *DHT11* ಎಂದು ತಿಳಿಸಲಾಗುತ್ತದೆ. ಎರಡನೇ ಪ್ಯಾರಮೀಟರ್ ಮೂಲಕ ಸೆನ್ಸಾರ್ ಪೋರ್ಟ್ `5` ಗೆ ಸಂಪರ್ಕಿತವಾಗಿದೆ ಎಂದು ತಿಳಿಸಲಾಗುತ್ತದೆ.

    > 💁 CounterFit ಈ ಸಂಯುಕ್ತ ಹ್ಯೂಮಿಡಿಟಿ ಮತ್ತು ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಅನ್ನು 2 ಸೆನ್ಸಾರ್ ಗಳಿಗೆ ಸಂಪರ್ಕಮಾಡಿ ಅನುಕರಿಸುತ್ತದೆ, ಒಂದು ಹ್ಯೂಮಿಡಿಟಿ ಸೆನ್ಸಾರ್ `DHT` ಕ್ಲಾಸ್ ಸೃಷ್ಟಿಸಿದಾಗ ಪಿನ್ ನಲ್ಲಿ ಇರುತ್ತದೆ, ಮತ್ತು ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಮುಂದಿನ ಪಿನ್ ರನ್ ಮಾಡುತ್ತದೆ. ಹ್ಯೂಮಿಡಿಟಿ ಸೆನ್ಸಾರ್ ಪಿನ್ 5 ನಲ್ಲಿ ಇದ್ದರೆ, ಶಿಮ್ ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಅನ್ನು ಪಿನ್ 6 ನಲ್ಲಿ ನಿರೀಕ್ಷಿಸುತ್ತದೆ.

1. ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಮೌಲ್ಯವನ್ನು ಪೋಲಿಂಗ್ ಮಾಡಿ ಮತ್ತು ಕಾನ್ಸೋಲ್ ಗೆ ಅದನ್ನು ಮುದ್ರಿಸಲು ಅನಂತ ಲೂಫ್ ಹಾಕಿ:

    ```python
    while True:
        _, temp = sensor.read()
        print(f'Temperature {temp}°C')
    ```

    `sensor.read()` ಕರೆ ಹ್ಯೂಮಿಡಿಟಿ ಮತ್ತು ತಾಪಮಾನದಿಂದ ಕೂಡಿದ ಅರ್ಧ ದ್ವಯವನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ. ನೀವು ತಾಪಮಾನ ಮೌಲ್ಯವೇ ಬೇಕಾಗಿರುವುದರಿಂದ ಹ್ಯೂಮಿಡಿಟಿ ಮೌಲ್ಯವನ್ನು ಬೇಡಿಕೆಯಿಂದ ಹೊರತುಪಡಿಸಲಾಗುತ್ತದೆ. ನಂತರ, ತಾಪಮಾನ ಮೌಲ್ಯವನ್ನು ಕಾನ್ಸೋಲ್‌ಗೆ ಮುದ್ರಿಸಲಾಗುತ್ತದೆ.

1. `loop` ಕೊನೆಯಲ್ಲಿ ಹತ್ತು ಸೆಕೆಂಡುಗಳ ಸಣ್ಣ ನಿದ್ರೆ ಸೇರಿಸಿ, ಏಕೆಂದರೆ ತಾಪಮಾನ ಮಟ್ಟಗಳನ್ನು ನಿರಂತರವಾಗಿ ತಪಾಸಣೆಯನ್ನಾಡಬೇಕಾಗಿಲ್ಲ. ನಿದ್ರೆ ಸಾಧನದ ವಿದ್ಯುತ್ ಬಳಕೆಯನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ.

    ```python
    time.sleep(10)
    ```

1. ವರ್ಚುವಲ್ ಪರಿಸರ ಸಕ್ರಿಯಗೊಂಡ VS Code ಟರ್ಮಿನಲ್ ನಿಂದ Python ಅಪ್ಲಿಕೇಶನ್ ಓಡಿಸಿ:

    ```sh
    python app.py
    ```

1. CounterFit ಅಪ್ಲಿಕೇಶನ್ ನಿಂದ, ಅಪ್ಲಿಕೇಶನ್ ಓದುವ ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಮೌಲ್ಯವನ್ನು ಬದಲಿಸಿ. ನೀವು ಇದನ್ನು ಎರಡು ರೀತಿಗಳಲ್ಲಿ ಮಾಡಬಹುದು:

    * ತಾಪಮಾನ ಸೆನ್ಸಾರ್ ಯಲ್ಲಿ *Value* ಬಾಕ್ಸ್ ನಲ್ಲಿ ಸಂಖ್ಯೆಯನ್ನು ನಮೂದಿಸಿ, ನಂತರ **Set** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ. ನೀವು ನಮೂದಿಸಿದ ಸಂಖ್ಯೆ ಸೆನ್ಸಾರ್ ಥಿಂದ ಹಿಂದಿರುಗಿಸುವ ಮೌಲ್ಯವಾಗಿರುತ್ತದೆ.

    * *Random* ಚೆಕ್ ಬಾಕ್ಸ್ ಪರಿಶೀಲಿಸಿ, ನಂತರ *Min* ಮತ್ತು *Max* ಮೌಲ್ಯಗಳನ್ನು ನಮೂದಿಸಿ, ನಂತರ **Set** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ. ಪ್ರತ timestep ನಲ್ಲೂ ಸೆನ್ಸಾರ್ ಒಂದು ಯಾದೃಚ್ಛಿಕ ಸಂಖ್ಯೆ *Min* ಮತ್ತು *Max* ನಡುವೆ ಓದುವಿರುತ್ತದೆ.

    ನೀವು ಇದ್ದ ಮೌಲ್ಯಗಳು ಕಾನ್ಸೋಲ್ ನಲ್ಲಿ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತವೆ. ಮೌಲ್ಯ ಅಥವಾ *Random* ಸೆಟ್ಟಿಂಗ್ ಗಳನ್ನು ಬದಲಿಸಿ ಮೌಲ್ಯ ಬದಲಾವಣೆ ನೋಡಿರಿ.

    ```output
    (.venv) ➜  temperature-sensor python app.py
    Temperature 28.25°C
    Temperature 30.71°C
    Temperature 25.17°C
    ```
