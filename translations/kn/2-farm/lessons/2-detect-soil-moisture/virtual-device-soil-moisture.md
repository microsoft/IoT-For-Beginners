# ಮಣ್ಣು ತೇವಾಂಶವನ್ನು ಅಳೆ - ವರ್ಚುವಲ್ ಐಒಟಿ 하드웨어

ಪಾಠದ ಈ ಭಾಗದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ವರ್ಚುವಲ್ ಐಒಟಿ ಸಾಧನಕ್ಕೆ ಕ್ಯಾಪಾಸಿಟಿವ್ ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರನ್ನು ಸೇರಿಸಲು ಮತ್ತು ಅದರಿಂದ ಮೌಲ್ಯಗಳನ್ನು ಓದಲು ಹೋಗುತ್ತೀರಿ.

## ವರ್ಚುವಲ್ 하드웨어

ವರ್ಚುವಲ್ ಐಒಟಿ ಸಾಧನವು ಅನುಕರಿಸಿದ ಗ್ರೋವ್ ಕ್ಯಾಪಾಸಿಟಿವ್ ಮಣ್ಣು ತೇವಾಂಶ ಸನ್ನಿವೇಶವನ್ನು ಬಳಸುತ್ತದೆ. ಇದರಿಂದ ಈ ಪ್ರಯೋಗಾಲಯವು ರಾಸ್ಪ್ಬೆರ್ರಿ 파이ಯೊಂದಿಗೆ ಭೌತಿಕ ಗ್ರೋವ್ ಕ್ಯಾಪಾಸಿಟಿವ್ ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಬಳಸುವುದರಂತೆ ಇರುತ್ತದೆ.

ಭೌತಿಕ ಐಒಟಿ ಸಾಧನದಲ್ಲಿ, ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಒಂದು ಕ್ಯಾಪಾಸಿಟಿವ್ ಸೆನ್ಸರ್ ಆಗಿದ್ದು, ಮಣ್ಣಿನ ಕ್ಯಾಪಾಸಿಟೆನ್ಸನ್ನು ಪತ್ತೆಹಚ್ಚಿ ಮಣ್ಣು ತೇವಾಂಶವನ್ನು ಅಳೆಯುತ್ತದೆ, ಇದು ಮಣ್ಣು ತೇವಾಂಶ ಬದಲಾಗುವಂತೆ ಗುಣಲಕ್ಷಣವಲ್ಲಿದೆ. ಮಣ್ಣು ತೇವಾಂಶ ಹೆಚ್ಚಾದಂತೆ ವೋಲ್ಟೇಜ್ ಕಡಿಮೆಯಾಗುತ್ತದೆ.

ಇದು ಅನಲಾಗ್ ಸೆನ್ಸರ್ ಆಗಿದ್ದು, 1-1,023 ರೊಳಗಿನ ಮೌಲ್ಯವನ್ನು ವರದಿ ಮಾಡಲು ಅನುಕರಿಸಿದ 10-ಬಿಟ್ ADC ಅನ್ನು ಬಳಸುತ್ತದೆ.

### ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರನ್ನು ಕೌಂಟರ್ಫಿಟ್‌ಗೆ ಸೇರಿಸಿ

ವರ್ಚುವಲ್ ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಅನ್ನು ಬಳಸಲು, ಅದನ್ನು ಕೌಂಟರ್ಫಿಟ್ ಆಪ್‌ಗೆ ಸೇರಿಸುವ ಅಗತ್ಯವಿದೆ

#### ಕಾರ್ಯ - ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಅನ್ನು ಕೌಂಟರ್ಫಿಟ್‌ಗೆ ಸೇರಿಸಿ

ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಅನ್ನು ಕೌಂಟರ್ಫಿಟ್ ಆಪ್‌ಗೆ ಸೇರಿಸಿ.

1. ನಿಮ್ಮ ಕಂಪ್ಯೂಟರಿನಲ್ಲಿ `soil-moisture-sensor` ಎಂದು ಕರೆಯಲ್ಪಡುವ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಒಂದು ಹೊಸ Python ಆಪ್ ನಿರ್ಮಿಸಿ, ಇದರಲ್ಲಿ `app.py` ಎಂಬ ಒಂದು ಫೈಲ್ ಮತ್ತುPython ವರ್ಚುವಲ್ ಪರಿಸರವಿರಲಿ, ಮತ್ತು ಕೌಂಟರ್ಫಿಟ್ ಪಿಪ್ ಪ್ಯಾಕೇಜ್‌ಗಳನ್ನು ಸೇರಿಸಿ.

    > ⚠️ ಅಗತ್ಯವಿದ್ದರೆ [ಪಾಠ 1 ರಲ್ಲಿ ಕೌಂಟರ್ಫಿಟ್ Python ಯೋಜನೆಯನ್ನು ನಿರ್ಮಿಸುವ ಮತ್ತು ಸೆಟ್ ಅಪ್ ಮಾಡುವ ಸೂಚನೆಗಳನ್ನು ನೋಡಿ](../../../1-getting-started/lessons/1-introduction-to-iot/virtual-device.md).

1. ಕೌಂಟರ್ಫಿಟ್ ವೆಬ್ ಆಪ್ ಚಲಿಸುತ್ತಿರುವುದನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ

1. ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಅನ್ನು ರಚಿಸಿ:

    1. *Create sensor* ಬಾಕ್ಸ್‌ನಲ್ಲಿ, *Sensors* ಪ್ಯಾನೆಲ್ಲಿನಲ್ಲಿ, *Sensor type* ಬಾಕ್ಸ್ನ್ನು ಡ್ರಾಪ್ ಡೌನ್ ಮಾಡಿ ಮತ್ತು *Soil Moisture* ಆಯ್ಕೆ ಮಾಡಿ.

    1. *Units* ಅನ್ನು *NoUnits* ಆಗಿ ಉಳಿಸಿ

    1. *Pin* ಅನ್ನು *0* ಗೆ ಹೊಂದಿಸಿ

    1. ಪಿನ್ 0 ನಲ್ಲಿ *Soil Moisture* ಸೆನ್ಸರ್ ರಚಿಸಲು **Add** ಬಟನ್ ಚುನಸಿ

    ![The soil moisture sensor settings](../../../../../translated_images/kn/counterfit-create-soil-moisture-sensor.35266135a5e0ae68.png)

    ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ರಚನೆಗೊಂಡು ಸೆನ್ಸರ್ ಗಳ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣಿಸಿಕೊಳ್ಳಲಿರುತ್ತದೆ.

    ![The soil moisture sensor created](../../../../../translated_images/kn/counterfit-soil-moisture-sensor.81742b2de0e9de60.png)

## ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಆಪ್ ಕಾರ್ಯಕ್ರಮ ಬರೆ

ಈಗ ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಆಪ್ ಅನ್ನು ಕೌಂಟರ್ಫಿಟ್ ಸೆನ್ಸರ್‌ಗಳನ್ನು ಬಳಸಿ ಕಾರ್ಯಕ್ರಮ ಬರೆಯಬಹುದು.

### ಕಾರ್ಯ - ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಆಪ್ ಕಾರ್ಯಕ್ರಮ ಬರೆ

ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್ ಆಪ್ ಕಾರ್ಯಕ್ರಮ ಬರೆಯಿರಿ.

1. `soil-moisture-sensor` ಆಪ್ VS Code ನಲ್ಲಿ ತೆರೆಯಲಾಗಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ

1. `app.py` ಫೈಲ್ ತೆರೆಯಿರಿ

1. ಆಪ್ ಅನ್ನು ಕೌಂಟರ್ಫಿಟ್‌ಗೆ ಸಂಪರ್ಕಿಸುವಂತೆ `app.py` ಮೇಲ್ಭಾಗಕ್ಕೆ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    from counterfit_connection import CounterFitConnection
    CounterFitConnection.init('127.0.0.1', 5000)
    ```

1. ಕೆಲವು ಅಗತ್ಯ ಗ್ರಂಥಸಂಪನ್ನಗಳನ್ನು ಆಮದುಮಾಡಲು `app.py` ಗೆ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    import time
    from counterfit_shims_grove.adc import ADC
    ```

    `import time` ಹೇಳಿಕೆ ಈ ಕಾರ್ಯದಲ್ಲಿ ಬಳಕೆಯಾಗುವ `time` ಮೋಡ್ಯೂಲ್ ಅನ್ನು ಆಮದುಮಾಡುತ್ತದೆ.

    `from counterfit_shims_grove.adc import ADC` ಹೇಳಿಕೆ ಕೌಂಟರ್ಫಿಟ್ ಸೆನ್ಸರ್‌ಗೆ ಸಂಪರ್ಕವಾಗುವ ವರ್ಚುವಲ್ ಅನಲಾಗ್ ಗೆ ಡಿಜಿಟಲ್ ಪರಿವರ್ತಕ ಅನ್ವಯಿಸುವ `ADC` ಕ್ಲಾಸ್ ಅನ್ನು ಆಮದುಮಾಡುತ್ತದೆ.

1. `ADC` ಕ್ಲಾಸ್‌ನ ಒಂದು ಪ್ರತಿಕೃತಿಯನ್ನು ಸೃಷ್ಠಿಸಲು ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    adc = ADC()
    ```

1. ಪಿನ್ 0 ನಲ್ಲಿ ಈ ADC ನಿಂದ ಓದುವ ಮತ್ತು ಫಲಿತಾಂಶವನ್ನು ಕಾನ್ಸೋಲ್‌ಗೆ ಬರೆಯುವ ಅನಂತ ಲೂಪ್ ಸೇರಿಸಿ. ಈ ಲೂಪ್ ನಂತರ ಓದುವ ನಡುವೆ 10 ಸೆಕೆಂಡುಗಳವರೆಗೆ ನಿದ್ರೆ ಮಾಡಬಹುದು.

    ```python
    while True:
        soil_moisture = adc.read(0)
        print("Soil moisture:", soil_moisture)
    
        time.sleep(10)
    ```

1. ಕೌಂಟರ್ಫಿಟ್ ಆಪ್‌ನಿಂದ, ಆಪ್‌ ಓದುವ ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್‌ನ ಮೌಲ್ಯವನ್ನು ಬದಲಾಯಿಸಿ. ನೀವು ಇದನ್ನು ಎರಡು ವಿಧಗಳಲ್ಲಿ ಮಾಡಬಹುದು:

    * ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸರ್‌ನ *Value* ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಸಂಖ್ಯೆ ನಮೂದಿಸಿ, ನಂತರ **Set** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ. ನೀವು ನಮೂದಿಸಿದ ಸಂಖ್ಯೆ ಸೆನ್ಸರ್‌ನಿಂದ ಹಿಂತಿರುಗಿಸುವ ಮೌಲ್ಯವಾಗಿರುತ್ತದೆ.

    * *Random* ಚೆಕ್ ಬಾಕ್ಸ್ ಆಯ್ಕೆ ಮಾಡಿ ಮತ್ತು *Min* ಮತ್ತು *Max* ಮೌಲ್ಯಗಳನ್ನು ನಮೂದಿಸಿ, ನಂತರ **Set** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ. ಪ್ರತಿಸಾರಿಗೆ ಸೆನ್ಸರ್ ಮೌಲ್ಯ ಓದಿದಾಗ, ಅದು *Min* ಮತ್ತು *Max* ಮಧ್ಯೆ ಯಾದೃಚ್ಛಿಕ ಸಂಖ್ಯೆಯನ್ನು ಓದುತ್ತದೆ.

1. Python ಆಪ್ ಚಾಲನೆ ಮಾಡಿ. ನೀವು ಕಾನ್ಸೋಲ್‌ನಲ್ಲಿ ಮಣ್ಣು ತೇವಾಂಶ ಅಳತೆಗಳನ್ನು ನೋಡುತ್ತೀರಿ. ಮೌಲ್ಯ ಅಥವಾ *Random* ಸೆಟ್ಟಿಂಗ್ಗಳನ್ನು ಬದಲಾಯಿಸಿ ಮೌಲ್ಯ ಬದಲಾವಣೆ ನೋಡಬಹುದು.

    ```output
    (.venv) ➜ soil-moisture-sensor $ python app.py 
    Soil moisture: 615
    Soil moisture: 612
    Soil moisture: 498
    Soil moisture: 493
    Soil moisture: 490
    Soil Moisture: 388
    ```
