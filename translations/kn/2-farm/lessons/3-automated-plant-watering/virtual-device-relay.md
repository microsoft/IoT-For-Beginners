# ರಿಲೇ ನಿಯಂತ್ರಣ - ವರ್ಚುವಲ್ ಐಒಟಿ ಹಾರ್ಡ್ವೇರ್

ಪಾಠದ ಈ ಭಾಗದಲ್ಲಿ, ನೀವು ಮಣ್ಣಿನ ತೇವಾಂಶ ಸೆನ್ಸಾರ್ ಜೊತೆಗೆ ನಿಮ್ಮ ವರ್ಚುವಲ್ ಐಒಟಿ ಸಾಧನಕ್ಕೆ ರಿಲೇವನ್ನು ಸೇರಿಸಿ, ಮತ್ತು ಮಣ್ಣಿನ ತೇವಾಂಶ ಮಟ್ಟದ ಆಧಾರದ ಮೇಲೆ ಅದನ್ನು ನಿಯಂತ್ರಿಸುವಿರಿ.

## ವರ್ಚುವಲ್ ಹಾರ್ಡ್ವೇರ್

ವರ್ಚುವಲ್ ಐಒಟಿ ಸಾಧನವು ಅನುಕರಿಸಿದ Grove ರಿಲೇ ಅನ್ನು ಬಳಸಲಿದೆ. ಇದು ಈ ಪ್ರಯೋಗಾಲಯವನ್ನು ಭೌತಿಕ Grove ರಿಲೇ ಬಳಕೆ ಮಾಡುತ್ತಿರುವ Raspberry Pi ಬಳಕೆಯಂತೆ ಇರಿಸುತ್ತದೆ.

ಭೌತಿಕ ಐಒಟಿ ಸಾಧನದಲ್ಲಿ, ರಿಲೇ ಸಾಮಾನ್ಯವಾಗಿ-ಮುಕ್ತ ರಿಲೇ ಆಗಿರುತ್ತದೆ (ಅರ್ಥಾತ್ ಯಾವುದೇ ಸಿಗ್ನಲ್ ರಿಲೇ‌ಗೆ ಕಳುಹಿಸಲಾಗದಿದ್ದಾಗ, ಔಟ್‌ಪುಟ್ ಸರ್ಕ್ಯೂಟ್ ತೆರೆದ ಅಥವಾ ಸಂಪರ್ಕವಿಚ್ಛೇದಿತವಾಗಿರುತ್ತದೆ). ಇಂತಹ ರಿಲೇ 250V ಹಾಗೂ 10A ಔಟ್‌ಪುಟ್ ಸರ್ಕ್ಯೂಟ್‌ಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ.

### CounterFit ಗೆ ರಿಲೇ ಸೇರಿಸಿ

ವರ್ಚುವಲ್ ರಿಲೇ ಬಳಸಲು, ನೀವು ಅದನ್ನು CounterFit ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಸೇರಿಸಬೇಕು.

#### ಕಾರ್ಯ

CounterFit ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ರಿಲೇ ಸೇರಿಸಿ.

1. ಹಿಂದಿನ ಪಾಠದಲ್ಲಿ ನೀವು ತೆರೆಯದಿದ್ದರೆ, VS ಕೋಡ್ ನಲ್ಲಿ `soil-moisture-sensor` ಪ್ರಾಜೆಕ್ಟ್ ತೆರೆಯಿರಿ. ನೀವು ಈ ಪ್ರಾಜೆಕ್ಟ್‌ಗೆ ಸೇರಿಸಲಿದ್ದೀರಿ.

1. CounterFit ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್ ಚಲಿಸುತ್ತಿರುವುದನ್ನು ಖಚಿತ ಪಡಿಸಿಕೊಳ್ಳಿ.

1. ರಿಲೇ ರಚಿಸಿ:

    1. *Actuators* ಪೇನಿನಲ್ಲಿ ಇರುವ *Create actuator* ಬಾಕ್ಸ್‌ನಲ್ಲಿ, *Actuator type* ಬಾಕ್ಸ್ ಡ್ರಾಪ್‌ಡೌನ್ ಮಾಡಿ *Relay* ಆಯ್ಕೆಮಾಡಿ.

    1. *Pin* ಅನ್ನು *5* ಆಗಿರುವಂತೆ ಸೆಟ್ ಮಾಡಿ.

    1. ಪಿನ್ 5 ರಲ್ಲಿ ರಿಲೇ ರಚಿಸಲು **Add** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ.

    ![ರಿಲೇ ಸೆಟ್ಟಿಂಗ್‌ಗಳು](../../../../../translated_images/kn/counterfit-create-relay.fa7c40fd0f2f6afc.png)

    ರಿಲೇ ರಚನೆಯಾಗಿ actuators ಪಟ್ಟಿಕೆಯಲ್ಲಿ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ.

    ![ರಿಲೇ ರಚಿಸಲಾಗಿದೆ](../../../../../translated_images/kn/counterfit-relay.bbf74c1dbdc8b9ac.png)

## ರಿಲೇ ಪ್ರೋಗ್ರಾಂ ಮಾಡಿ

ಮಣ್ಣು ತೇವಾಂಶ ಸೆನ್ಸಾರ್ ಅಪ್ಲಿಕೇಶನ್ ಈಗ ವಿಸ್ತಾರಿಸಿದ ವರ್ಚುವಲ್ ರಿಲೇ ಬಳಸುವಂತೆ ಪ್ರೋಗ್ರಾಂ ಮಾಡಬಹುದು.

### ಕಾರ್ಯ

ವರ್ಚುವಲ್ ಸಾಧನ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಿ.

1. ಹಿಂದಿನ ಪಾಠದಲ್ಲಿ ನೀವು ತೆರೆಯದಿದ್ದರೆ, VS ಕೋಡ್ ನಲ್ಲಿ `soil-moisture-sensor` ಪ್ರಾಜೆಕ್ಟ್ ತೆರೆಯಿರಿ. ನೀವು ಈ ಪ್ರಾಜೆಕ್ಟ್‌ಗೆ ಸೇರಿಸಲಿದ್ದೀರಿ.

1. ಇಮ್ಪೋರ್ಟ್‌ಗಳ ಕೆಳಗೆ `app.py` ಫೈಲ್‌ಗೆ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    from counterfit_shims_grove.grove_relay import GroveRelay
    ```

    ಈ ಹೇಳಿಕೆಯಿಂದ Grove Python ಶಿಂ ಲೈಬ್ರರಿಗಳಿಂದ `GroveRelay` ಅನ್ನು ಇಂಪೋರ್ಟ್ ಮಾಡಲಾಗುತ್ತದೆ, ಇದು ವರ್ಚುವಲ್ Grove ರಿಲೇ ಜೊತೆ ಸಂವಹನ ಮಾಡಲು.

1. `ADC` ಕ್ಲಾಸ್ ಘೋಷಣೆಯ ಕೆಳಗೆ GroveRelay ಉದಾಹರಣೆ ರಚಿಸಲು ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    relay = GroveRelay(5)
    ```

    ಇದು ಪಿನ್ **5** ಬಳಸಿ ರಿಲೇ ಅನ್ನು ರಚಿಸುತ್ತದೆ, ಇದು ನೀವು ರಿಲೇ ಸಂಪರ್ಕಿಸಿದ ಪಿನ್.

1. ರಿಲೇ ಕೆಲಸ ಮಾಡುತ್ತಿದೆ ಎಂದು ಪರಿಶೀಲಿಸಲು, `while True:` ಲೂಪ್‌ಗೆ ಈ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    relay.on()
    time.sleep(.5)
    relay.off()
    ```

    ಕೋಡ್ ರಿಲೇ ಅನ್ನು ಆನ್ ಮಾಡುತ್ತದೆ, 0.5 ಸೆಕೆಂಡುಗಳ ಕಾಲ ನಿರೀಕ್ಷಿಸುತ್ತದೆ, ನಂತರ ರಿಲೇ ಅನ್ನು ಆಫ್ ಮಾಡುತ್ತದೆ.

1. Python ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಚಲಿಸಿ. ಪ್ರತಿ 10 ಸೆಕೆಂಡ್‌ಗಳಿಗೆ ರಿಲೇ ಆನ್ ಆಗಿ ಆಫ್ ಆಗುತ್ತದೆ, ಆನ್ ಮತ್ತು ಆಫ್ ನಡುವೆ ಅರ್ಧ ಸೆಕೆಂಡಿನ ವಿಳಂಬವಿರುತ್ತದೆ. ನೀವು CounterFit ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ವರ್ಚುವಲ್ ರಿಲೇ ಇದೀಗ ಆನ್ ಮತ್ತು ಆಫ್ ಆಗುತ್ತಿರುವುದನ್ನು ನೋಡುವಿರಿ.

    ![ವರ್ಚುವಲ್ ರಿಲೇ ಆನ್ ಮತ್ತು ಆಫ್ ಆಗುವುದು](../../../../../images/virtual-relay-turn-on-off.gif)

## ಮಣ್ಣಿನ ತೇವಾಂಶದಿಂದ ರಿಲೇ ನಿಯಂತ್ರಿಸಿ

ಈಗ ರಿಲೇ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆ, ಅದನ್ನು ಮಣ್ಣಿನ ತೇವಾಂಶ ಓದುಗಳ ಪ್ರಕಾರ ನಿಯಂತ್ರಿಸಬಹುದು.

### ಕಾರ್ಯ

ರಿಲೇ ನಿಯಂತ್ರಿಸಿ.

1. ನೀವು ರಿಲೇ ಪರೀಕ್ಷಿಸಲು ಸೇರಿಸಿದ 3 ಸಾಲುಗಳನ್ನು ಅಳಿಸಿ. ಅವುಗಳ ಬದಲಿಗೆ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ:

    ```python
    if soil_moisture > 450:
        print("Soil Moisture is too low, turning relay on.")
        relay.on()
    else:
        print("Soil Moisture is ok, turning relay off.")
        relay.off()
    ```

    ಈ ಕೋಡ್ ಮಣ್ಣಿನ ತೇವಾಂಶ ಸೆನ್ಸರ್ ನಿಂದ ಮಣ್ಣಿನ ತೇವಾಂಶ ಮಟ್ಟವನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ. ಅದು 450 ಕ್ಕಿಂತ ಹೆಚ್ಚು ಇದ್ದರೆ, ರಿಲೇ ಆನ್ ಆಗುತ್ತದೆ, 450 ಕ್ಕಿಂತ ಕಡಿಮೆಯಾದರೆ ಆಫ್ ಆಗುತ್ತದೆ.

    > 💁 capacitive soil moisture sensor ಯಾದರೆ, ಮಣ್ಣಿನ ತೇವಾಂಶ ಮಟ್ಟ ಕಡಿಮೆಯಾದಂತೆ, ಮಣ್ಣಿನಲ್ಲಿ ಹೆಚ್ಚು ತೇವಾಂಶ ಇರುತ್ತದೆ ಎಂಬುದನ್ನು ನೆನಪಿನಲ್ಲಿಟ್ಟುಕೊಳ್ಳಿ ಮತ್ತು ಇದರ ವಿಲ್ಕಿ ಸರಿ.

1. Python ಅಪ್ಲಿಕೇಶನ್ ರನ್ ಮಾಡಿ. ರಿಲೇ ಮಣ್ಣಿನ ತೇವಾಂಶ ಮಟ್ಟಗಳ ಮೇಲೆ ಆನ್ ಅಥವಾ ಆಫ್ ಆಗುವುದನ್ನು ನೀವು ನೋಡಬಹುದು. ಮಣ್ಣಿನ ತೇವಾಂಶ ಸೆನ್ಸರ್‌ನ *Value* ಅಥವಾ *Random* ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ಬದಲಿಸಿ ಮೌಲ್ಯ ಬದಲಾಗುವುದನ್ನು ನೋಡಿ.

    ```output
    Soil Moisture: 638
    Soil Moisture is too low, turning relay on.
    Soil Moisture: 452
    Soil Moisture is too low, turning relay on.
    Soil Moisture: 347
    Soil Moisture is ok, turning relay off.
    ```

😀 ನಿಮ್ಮ ವರ್ಚುವಲ್ ಮಣ್ಣಿನ ತೇವಾಂಶ ಸೆನ್ಸಾರ್ ರಿಲೇ ನಿಯಂತ್ರಿಸುವ ಪ್ರೋಗ್ರಾಂ ಯಶಸ್ವಿಯಾಯಿತು!
