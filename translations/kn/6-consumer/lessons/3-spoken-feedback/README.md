## ಪರಿಚಯ

ಸ್ಮಾರ್ಟ್ ಸಹಾಯಕರು ಏಕ ದಿಕ್ಕಿನ ಸಂವಹನ ಸಾಧನಗಳಲ್ಲ. ನೀವು ಅವರಿಗೆ ಮಾತನಾಡುತ್ತೀರಿ, ಅವರು ಪ್ರತಿಕ್ರಿಯಿಸುತಾರೆ:

"ಅಲೆಕ್ಷಾ, 3 ನಿಮಿಷ ಟೈಮರ್ ಸೆಟ್ ಮಾಡಿ"

"ಸರೀ, ನಿಮ್ಮ ಟೈಮರ್ 3 ನಿಮಿಷಗಳಿಗೆ ಸೆಟ್ ಮಾಡಲಾಗಿದೆ"

ಕೊನೆಯ 2 ಪಾಠಗಳಲ್ಲಿ ನೀವು ಮಾತನ್ನಿಂದ ಪಠ್ಯವನ್ನು ತಯಾರಿಸುವ ಮತ್ತು ಆ ಪಠ್ಯದಿಂದ ಟೈಮರ್ ವಿನಂತಿಯನ್ನು ತೆಗೆದುಕೊಳ್ಳುವುದು ಹೇಗೆ ಎಂಬುದನ್ನು ತಿಳಿದುಕೊಂಡಿದ್ದೀರಿ. ಈ ಪಾಠದಲ್ಲಿ ನೀವು ಐಒಟಿ ಸಾಧನದಲ್ಲಿ ಟೈಮರ್ ಸೆಟ್ ಮಾಡುವುದನ್ನು, ಬಳಕೆದಾರರಿಗೆ ಅವರಿಗೆ ಟೈಮರ್ ಇರುವುದು ಎಂದು ಮಾತಿನ ಮೂಲಕ ದೃಢೀಕರಣ ನೀಡುವ ಮತ್ತು ಟೈಮರ್ ಮುಗಿದಾಗ ಅವರಿಗೆ ಎಚ್ಚರಿಸುವುದನ್ನು ಕಲಿಯುತ್ತೀರಿ.

## ಪಠ್ಯದಿಂದ ಮಾತಿಗೆ

ಪಠ್ಯದಿಂದ ಮಾತಿಗೆ ಎಂದರೆ, ಪಠ್ಯವನ್ನು ಮಾತಿನ ಪದಗಳಾಗಿ ಪರಿವರ್ತಿಸುವ ಪ್ರಕ್ರಿಯೆಯಾಗಿದೆ. ಮೂಲತಃ ಪಠ್ಯದಲ್ಲಿರುವ ಪದಗಳನ್ನು ಅವುಗಳ ಘೋಷಣಾ ಶಬ್ದಗಳು (ಫೋನೀಮ್ಸ್ ಎಂದು ಕರೆಯಲಾಗುವ) ಆಗಿ ವಿಭಜಿಸಿ, ಆ ಶಬ್ದಗಳಿಗಾಗಿ ಪೂರ್ವದಲ್ಲೇ ದಾಖಲಿಸಲಾಗಿರುವ ಅಥವ AI ಮಾದರಿಗಳಿಂದ ಉತ್ಪಾದಿಸಲಾದ ಧ್ವನಿಯನ್ನು ಜೋಡಿಸುವುದು.

![ಸಾಮಾನ್ಯ ಪಠ್ಯದಿಂದ ಮಾತಿಗೆ ವ್ಯವಸ್ಥೆಗಳ ಮೂರು ಹಂತಗಳು](../../../../../translated_images/kn/tts-overview.193843cf3f5ee09f.png)

ಪಠ್ಯದಿಂದ ಮಾತಿಗೆ ವ್ಯವಸ್ಥೆಗಳಲ್ಲಿ ಸಾಮಾನ್ಯವಾಗಿ 3 ಹಂತಗಳಿರುತ್ತವೆ:

* ಪಠ್ಯ ವಿಶ್ಲೇಷಣೆ
* ಭಾಷಾಶಾಸ್ತ್ರೀಯ ವಿಶ್ಲೇಷಣೆ
* ತರಂಗರೂಪನ ಉತ್ಪಾದನೆ

### ಪಠ್ಯ ವಿಶ್ಲೇಷಣೆ

ಪಠ್ಯ ವಿಶ್ಲೇಷಣೆಯು ನೀಡಲಾದ ಪಠ್ಯವನ್ನು ಕಡೆಗೆ ಮಾತುಗಳಾಗಿ ಪರಿವರ್ತಿಸುವುದನ್ನು ಒಳಗೊಂಡಿರುತ್ತದೆ. ಉದಾಹರಣೆಗೆ, "Hello world" ಗೆ ಪಠ್ಯ ವಿಶ್ಲೇಷಣೆ ಅಗತ್ಯವಿಲ್ಲ, ಆ ಎರಡು ಪದಗಳನ್ನು ನೇರವಾಗಿ ಮಾತಿಗೆ ಪರಿವರ್ತಿಸಬಹುದು. ಆದರೆ "1234" ಎಂಬಾಗ, ಅದು "ಒಂದು ಸಾವಿರ, ಎರಡು ನೂರು ಮೂವತ್ತಿ ನಾಲ್ಕು" ಅಥವಾ "ಒಂದು, ಎರಡು, ಮೂರು, ನಾಲ್ಕು" ಎಂದು ಸಂಪರ್ಕದ ಪ್ರಕಾರ ಬದಲಾಗಬಹುದು. "ನನಗೆ 1234 ಸೇಬುಗಳಿವೆ" ಅಂದ್ರೆ "ಒಂದು ಸಾವಿರ, ಎರಡು ನೂರು ಮೂವತ್ತಿ ನಾಲ್ಕು" ಆದರೆ "ಮಗು 1234 ಅನ್ನು ಎಣಿಸಿಕೊಂಡಿತು" ಅಂದ್ರೆ "ಒಂದು, ಎರಡು, ಮೂರು, ನಾಲ್ಕು".

ಬ್ಯಾಕರಣವು ಭಾಷೆಯ ಜೊತೆಗೆ ಆ ಭಾಷೆಯ ಸ್ಥಳೀಯತೆಗೂ ಅನುಗುಣವಾಗಿ ಬದಲಾಗುತ್ತದೆ. ಉದಾಹರಣೆಗೆ, ಅಮೆರಿಕನ್ ಇಂಗ್ಲೀಷ್ ನಲ್ಲಿ 120 ಹೀಗೆ ಹೇಳುತ್ತಾರೆ "One hundred twenty", ಬ್ರಿಟಿಷ್ ಇಂಗ್ಲೀಷ್ ನಲ್ಲಿ ಅದು "One hundred and twenty" ಆಗಿಡುತ್ತದೆ, ಇಲ್ಲಿ ನೂರಿನ ನಂತರ "and" ಬಳಕೆ ಆಗುತ್ತದೆ.

✅ ಮತ್ತಷ್ಟು ಉದಾಹರಣೆಗಳು ಎಂದರೆ "in" ಅನ್ನು ಇಂಚ್ ಸಂಕ್ಷೇಪವಾಗಿ ಮತ್ತು "st" ಅನ್ನು ಸೆಂಟ್ ಅಥವಾ ಸ್ಟ್ರೀಟ್ ಸಂಕ್ಷೇಪವಾಗಿ ಬಳಕೆ ಮಾಡುವುದು. ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ ಯಾವುದೇ ಸಂಬಂಧಭರಿತವಲ್ಲದ ಪದಗಳ ಉದಾಹರಣೆಗಳನ್ನ ನೀವು ಭಾವಿಸುತ್ತೀರಾ?

ಪದಗಳ ಸಂರಚನೆ ನಂತರ, ಅವನ್ನು ಭಾಷಾಶಾಸ್ತ್ರೀಯ ವಿಶ್ಲೇಷಣೆಗೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ.

### ಭಾಷಾಶಾಸ್ತ್ರೀಯ ವಿಶ್ಲೇಷಣೆ

ಭಾಷಾಶಾಸ್ತ್ರೀಯ ವಿಶ್ಲೇಷಣೆ ಪದಗಳನ್ನು ಫೋನೀಮ್ಸ್ ಗೆ ಕರಗಿಸುತ್ತದೆ. ಫೋನೀಮ್ಸ್ ಕೇವಲ ಅಕ್ಷರಗಳಲ್ಲ, ಪದದಲ್ಲಿರುವ ಇತರೆ ಅಕ್ಷರಗಳ ಮೇಲೆ ಅವಲಂಬಿತವಾಗಿರುತ್ತವೆ. ಉದಾಹರಣೆಗೆ, ಇಂಗ್ಲೀಷ್ ನಲ್ಲಿ 'car' ಮತ್ತು 'care' ನಲ್ಲಿ 'a' ಧ್ವನಿಗಳು ವಿಭಿನ್ನ. ಇಂಗ್ಲೀಷ್ ಭಾಷೆಯಲ್ಲಿ 26 ಅಕ್ಷರಗಳಿಗಾಗಿ 44 ವಿಭಿನ್ನ ಫೋನೀಮ್ಸ್ ಇದ್ದವೆ, ಕೆಲವು ಒಂದೇ ಫೋನೀಮ್ ಎರಡು ಅಕ್ಷರಗಳಲ್ಲಿ ಬಹುಮಾನಿತವಾಗಿವೆ, ಉದಾ: 'circle' ಮತ್ತು 'serpent' ಪದಗಳ ಮೊದಲ ಧ್ವನಿಗಳು ಒಂದೇ.

✅ ಸಂಶೋಧನೆ ಮಾಡಿ: ನಿಮ್ಮ ಭಾಷೆಗೆ ಫೋನೀಮ್ಸ್ ಯಾವುವು?

ಪದಗಳು ಫೋನೀಮ್ಸ್ ಗೆ ಮಾರ್ಪಟ್ಟ ನಂತರ, ಇವುಗಳಿಗೆ ಹೆಚ್ಚುವರಿ ಡೇಟಾ ಬೇಕಾಗುತ್ತದೆ ಹಚ್ಚಾಟ, ಧ್ವನಿ ಬಗೆ ಅಥವಾ ಅವಧಿ ಬದಲಿಸುವುದಕ್ಕೆ. ಉದಾಹರಣೆಗೆ, ಇಂಗ್ಲೀಷ್ ನಲ್ಲಿ pitch ಹೆಚ್ಚಿಸುವುದು ಪ್ರಶ್ನೆ ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸುವುದು. ಕೊನೆಯ ಪದದಲ್ಲಿ pitch ಎತ್ತುತ್ತಿದ್ದರೆ ಅದು ಪ್ರಶ್ನೆ ಎಂಬುದನ್ನು ಸೂಚಿಸುತ್ತದೆ.

ಉದಾಹರಣೆಗೆ - "You have an apple" ಎಂಬ ಪದವು ಹೇಳುತ್ತದೆ ನೀವು ಸೇಬು ಹೊಂದಿದ್ದೀರಿ. ಆದರೆ 'apple' ಪದದಲ್ಲಿ pitch ಏರಿದರೆ "You have an apple?" ಎಂದಂತೆ ಕೇಳುತ್ತದೆ. ಭಾಷಾಶಾಸ್ತ್ರೀಯ ವಿಶ್ಲೇಷಣೆ ಇದನ್ನು ಪ್ರಶ್ನೆಯ ಗುರುತು ಸೂಚನೆ ಮೂಲಕ ಮಾಡಿ pitch ಹೆಚ್ಚಿಸುತ್ತದೆ.

ಫೋನೀಮ್ಸ್ ತಯಾರಾದ ಮೇಲೆ, ಅವನ್ನು ತರಂಗರೂಪ ಪ್ರಧಾನಕ್ಕೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ.

### ತರಂಗರೂಪನ ಉತ್ಪಾದನೆ

ಆದಿಕಾಲ Electronic TTS ವ್ಯವಸ್ಥೆಗಳು ಪ್ರತಿಯೊಂದು ಫೋನೀಮ್ ಗೆ ಒಂದೇ ಧ್ವನಿದಾಖಲೆಗಳನ್ನು ಬಳಸುತ್ತವೆ, ಅದು ದಿನಚರೆಯಲ್ಲಿ ಬೊಟ್ಟದಂತೆ robotic ಧ್ವನಿಯನ್ನು ಕೊಡುತ್ತದೆ. ಭಾಷಾಶಾಸ್ತ್ರೀಯ ವಿಶ್ಲೇಷಣೆಯಿಂದ ಫೋನೀಮ್ಗಳು ಬರುತ್ತವೆ ಮತ್ತು ಅವುಗಳನ್ನು database ನಿಂದ ಪಡೆದು ಮೇಳೈಸಲಾಗುತ್ತದೆ.

✅ ಸಂಶೋಧನೆ ಮಾಡಿ: ಪ್ರಾಥಮಿಕ ಭಾಷಾ ಸಿಂಥೆಸಿಸ್ ಸ್ತರದ ಧ್ವನಿದಾಖಲೆಗಳನ್ನು ಹೋಲಿಸಿ ಆಧುನಿಕ ಸ್ಮಾರ್ಟ್ ಸಹಾಯಕರ ಮಾತಿನ ಸಿಂಥೆಸಿಸ್.

ನೆರವಾಗಿ, ಆಧುನಿಕ ತಂತ್ರಜ್ಞಾನ ML ಮಾದರಿಗಳನ್ನು ಬಳಸುತ್ತದೆ, ಬೃಹತ್ ನರನೇತ್ರಗಳು ಬೃಹತ್ ಮಟ್ಟದಲ್ಲಿ ಮಾನವ ಧ್ವನಿಗೆ ಹೋಲುವಂತೆ ಉತ್ಫನ್ನ ಧ್ವನಿಯನ್ನು ತಯಾರಿಸುತ್ತವೆ.

> 💁 ಕೆಲವು ML ಮಾದರಿಗಳನ್ನು ಬೇಗ ಪುನಶ್ಚಿಕitsa ಮಾಡಬಹುದು ನಿಜವಾದ ವ್ಯಕ್ತಿಗಳ ಧ್ವನಿಯನ್ನು ಹೋಲಲು. ಬ್ಯಾಂಕ್ ಗಳಲ್ಲಿ ಧ್ವನಿಯನ್ನು ಸೆಕ್ಯುರಿಟಿ ಸಾಧನವಾಗಿ ಬಳಸುವ ಪ್ರಯತ್ನಗಳು ಹೆಚ್ಚುತ್ತಿರುವುದರಿಂದ, ನಿಮ್ಮ ಧ್ವನಿಯ ಕೆಲವು ನಿಮಿಷಗಳ ರೆಕಾರ್ಡಿಂಗ್ ಯಾರಿಗೂ ದೊರೆತರೆ ಅವರು ನಿಮ್ಮನ್ನು ನಕಲಿಸಬಹುದು ಎಂದು ಗಮನಿಸಿ.

ಈ ML ತುಂಡುಗಳು ಎಲ್ಲ ಹಂತಗಳನ್ನು ಸೇರಿಸಿ ಅಂತಿಮ Speech synthesizer ಗಳಾಗಿ ತರಬೇತಿಗಳಾಗುತ್ತಿದ್ದವೆ.

## ಟೈಮರ್ ಸೆಟ್ ಮಾಡಿ

ಟೈಮರ್ ಸೆಟ್ ಮಾಡಲು ನಿಮ್ಮ ಐಒಟಿ ಸಾಧನ ರೂಸ್ತ್ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಅನ್ನು ಕರೆಮಾಡಬೇಕು ಮತ್ತು ಸೆಕೆಂಡುಗಳ ಸಂಖ್ಯೆ ಅನ್ನು ಬಳಸಿಕೊಂಡು ಟೈಮರ್ ನಿಗದಿಪಡಿಸಬೇಕು.

## ಪಠ್ಯವನ್ನು ಮಾತಿಗೆ ಪರಿವರ್ತಿಸಿ

ನೀವು ಭಾಷಣವನ್ನು ಪಠ್ಯಕ್ಕೆ ಪರಿವರ್ತಿಸಲು ಬಳಸಿದ ಇದೇ ಸೇವಾ ಪಠ್ಯವನ್ನು ಮತ್ತೊಮ್ಮೆ ಮಾತಿಗೆ ಪರಿವರ್ತಿಸಲು ಸಹ ಬಳಸಬಹುದು. ಇದನ್ನು ನಿಮ್ಮ ಐಒಟಿ ಸಾಧನದ ಸ್ಪೀಕರ್ ಮೂಲಕ ನಿರ್ವಹಿಸಬಹುದು. ಪರಿವರ್ತಿಸಬೇಕಾದ ಪಠ್ಯ ಮತ್ತು ಬೇಕಾದ ಧ್ವನಿ ಮಾದರಿಯನ್ನು (ಜಿಗೆ ಉದಾಹರಣೆಗೆ ಮಾದರಿ ತ್ವರಿತ) ಸೇವೆಗೆ ಒದಗಿಸಿ, ಧ್ವನಿ ಡೇಟಾ ಬೈನರಿ ರೂಪದಲ್ಲಿ ಪಡೆಯಲಾಗುತ್ತದೆ.

ನೀವು ಈ ವಿನಂತಿಯನ್ನು ಕಳುಹಿಸುವಾಗ, *Speech Synthesis Markup Language* (SSML) ಎಂಬ XML ಆಧಾರಿತ ಮಾರ್ಕ್ ಅಪ್ ಭಾಷೆಯನ್ನು ಬಳಕೆ ಮಾಡುತ್ತೀರಿ. ಇದು ಪರಿವರ್ತಿಸಲು ಬೇಕಾದ ಪಠ್ಯ, ಭಾಷೆ, ಧ್ವನಿ, ವೇಗ, ಧ್ವನಿಮಟ್ಟ ಮತ್ತು pitch ನಂತಹ ನಿಯಂತ್ರಣಗಳನ್ನು ಊಹಿಸುತ್ತದೆ.

ಉದಾಹರಣೆಗೆ, ಈ SSML "Your 3 minute 5 second time has been set" ಎಂಬ ಪಠ್ಯವನ್ನು British English ಧ್ವನಿಯ `en-GB-MiaNeural` ಬಳಸಿ ಮಾತಿಗೆ ಪರಿವರ್ತಿಸುವ ವಿನಂತಿಯನ್ನು ವಿನ್ಯಾಸಗೊಳಿಸುತ್ತದೆ.

```xml
<speak version='1.0' xml:lang='en-GB'>
    <voice xml:lang='en-GB' name='en-GB-MiaNeural'>
        Your 3 minute 5 second time has been set
    </voice>
</speak>
```

> 💁 ಬಹುತೇಕ ಪಠ್ಯದಿಂದ ಮಾತಿಗೆ ವ್ಯವಸ್ಥೆಗಳಲ್ಲಿ ಭಾಷೆಗೆ ಅನುಗುಣವಾಗಿ ವಿವಿಧ ಧ್ವನಿಗಳು ಲಭ್ಯವಿವೆ, ಉದಾಹರಣೆಗೆ ಬ್ರಿಟಿಷ್ ಇಂಗ್ಲೀಷ್ ಧ್ವನಿ, ನ್ಯೂಜಿಲೆಂಡ್ ಇಂಗ್ಲೀಷ್ ಧ್ವನಿ ಇತ್ಯಾದಿ.

## 🚀 ಚಾಲೆಂಜ್

SSML ಮೂಲಕ ಮಾತಿನಲ್ಲಿ ಆತ್ಮಸ್ಪೃಹೆ, ವಿರಾಮ, pitch ಬದಲಾವಣೆಗಳನ್ನು ಸೇರಿಸುವುದು ಅಥವಾ ಕಡಿಮೆ ಮಾಡುವುದು ಸಾಧ್ಯ. ನಿಮ್ಮ ಐಒಟಿ ಸಾಧನದಿಂದ ವಿಭಿನ್ನ SSML ಕಳುಹಿಸಿ ಮತ್ತು ಪರಿಣಾಮವನ್ನು ಹೋಲಿಸಿ ನೋಡಿ. SSML ಕುರಿತು ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗಾಗಿ, [Speech Synthesis Markup Language (SSML) Version 1.1 ವಿಶೇಷಣ - World Wide Web consortium](https://www.w3.org/TR/speech-synthesis11/) ನೋಡಿ.
