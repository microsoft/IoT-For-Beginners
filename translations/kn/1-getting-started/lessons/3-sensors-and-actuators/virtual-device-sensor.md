# ನೈಟ್‌ಲೈಟ್ ನಿರ್ಮಿಸಿ - ವರ್ಚುವಲ್ ಐಓಟಿ ಹಾರ್ಡ್‌ವೇರ್

ಪಾಠದ ಈ ಭಾಗದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ವರ್ಚುವಲ್ ಐಓಟಿ ಡಿವೈಸ್‌ಗೆ ಒಂದು ಲೈಟ್ ಸೆನ್ಸಾರ್ ಅನ್ನು ಸೇರಿಸುವಿರಿ.

## ವರ್ಚುವಲ್ ಹಾರ್ಡ್‌ವೇರ್

ನೈಟ್‌ಲೈಟ್‌ಗೆ ಕೌಂಟರ್‌ಫಿಟ್ ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಸೃಷ್ಟಿಸಲಾದ ಒಂದು ಸೆನ್ಸಾರ್ ಬೇಕಾಗುತ್ತದೆ.

ಆ ಸೆನ್ಸಾರ್ ಒಂದು **ಲೈಟ್ ಸೆನ್ಸಾರ್** ಆಗಿದೆ. ಭೌತಿಕ ಐಓಟಿ ಸಾಧನದಲ್ಲಿ, ಇದು ಬೆಳಕನ್ನು ವಿದ್ಯುತ್ ಸಂಕೇತಕ್ಕೆ ಪರಿವರ್ತಿಸುವ [ಫೋಟೋಡಯೋಡ್](https://wikipedia.org/wiki/Photodiode) ಆಗಿರಬಹುದು. ಲೈಟ್ ಸೆನ್ಸಾರ್‌ಗಳು ಅನಲಾಗ್ ಸೆನ್ಸರ್‌ಗಳಾಗಿದ್ದು, ಬೆಳಕಿನ ಸಂಬಂಧಿತ ಪ್ರಮಾಣವನ್ನು ಸೂಚಿಸುವ ಪೂರ್ಣಾಂಕ ಮೌಲ್ಯವನ್ನು ಕಳುಹಿಸುತ್ತವೆ, ಇದು ಯಾವುದೇ ಮಾನದಂಡದ ಮಾಪನ ಘಟಕಕ್ಕೆ (ಉದಾ: [ಲುಕ್ಸ](https://wikipedia.org/wiki/Lux)) ನಕ್ಷೆ ಮಾಡದೆ ಇರುತ್ತದೆ.

### ಸೆನ್ಸರ್‌ಗಳನ್ನು ಕೌಂಟರ್‌ಫಿಟ್‌ಗೆ ಸೇರಿಸಿ

ವರ್ಚುವಲ್ ಲೈಟ್ ಸೆನ್ಸಾರ್ ಬಳಕೆ ಮಾಡಲು, ಅದನ್ನು ಕೌಂಟರ್‌ಫಿಟ್ ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಸೇರಿಸಬೇಕಾಗುತ್ತದೆ.

#### ಕಾರ್ಯ - ಸೆನ್ಸರ್‌ಗಳನ್ನು ಕೌಂಟರ್‌ಫಿಟ್‌ಗೆ ಸೇರಿಸುವುದು

ಲೈಟ್ ಸೆನ್ಸಾರ್ ಅನ್ನು ಕೌಂಟರ್‌ಫಿಟ್ ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಸೇರಿಸಿ.

1. ಈ ನಿಯೋಜನೆಯ ಹಳೆಯ ಭಾಗದಿಂದ ಕೌಂಟರ್‌ಫಿಟ್ ವೆಬ್ ಅಪ್ ಚಾಲನೆಯಲ್ಲಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ಅಲ್ಲದಿದ್ದರೆ, ಅದನ್ನು ಪ್ರಾರಂಭಿಸಿ.

1. ಒಂದು ಲೈಟ್ ಸೆನ್ಸಾರ್ ರಚಿಸಿ:

    1. *ಸೆನ್ಸರ್ಸ್* ಪೇನ್‌ನ *ಸೆನ್ಸಾರ್ ರಚಿಸಿ* ಬಾಕ್ಸ್ನಲ್ಲಿ, *ಸೆನ್ಸಾರ್ ಪ್ರಕಾರ* ಬಾಕ್ಸ್‌ನ್ನು ಡ್ರಾಪ್ ಡೌನ್ ಮಾಡಿ ಮತ್ತು *ಲೈಟ್* ಆಯ್ಕೆಮಾಡಿ.

    1. *ಘಟಕಗಳು* ಅನ್ನು *ಯುನಿಟ್ ಇಲ್ಲ* ಗೆ ಇಡಿ

    1. *ಪಿನ್* ಅನ್ನು *0* ಆಗಿ ನಿಶ್ಚಿತಪಡಿಸಿ

    1. ಪಿನ್ 0 ನಲ್ಲಿ ಲೈಟ್ ಸೆನ್ಸಾರ್ ರಚಿಸಲು **ಸೇರಿಸಿ** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ

    ![The light sensor settings](../../../../../translated_images/kn/counterfit-create-light-sensor.9f36a5e0d4458d8d.png)

    ಲೈಟ್ ಸೆನ್ಸಾರ್ ರಚಿಸಲಾಗಿದ್ದು, ಸೆನ್ಸರ್ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣಿಸುತ್ತದೆ.

    ![The light sensor created](../../../../../translated_images/kn/counterfit-light-sensor.5d0f5584df56b90f.png)

## ಲೈಟ್ ಸೆನ್ಸಾರ್ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಿ

ಈಗ ಸಾಧನವನ್ನು ಬಿಲ್ಲ್ಟ್-ಇನ್ ಲೈಟ್ ಸೆನ್ಸಾರ್ ಬಳಸಲು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು.

### ಕಾರ್ಯ - ಲೈಟ್ ಸೆನ್ಸಾರ್ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಿ

ಸಾಧನವನ್ನು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಿ.

1. ಈ ನಿಯೋಜನೆಯ ಹಿಂದೆ ಭಾಗದಲ್ಲಿ ನೀವು ರಚಿಸಿದ ನೈಟ್‌ಲೈಟ್ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು VS ಕೋಡ್‌ನಲ್ಲಿ ತೆರೆಯಿರಿ. ರೈಲೀಂಟ್ ಆಗಿ ಟರ್ಮಿನಲ್‌ನನ್ನೂ ಮುಚ್ಚಿ ಮರುಸೃಷ್ಟಿಸಿ, ಅಗತ್ಯವಿದ್ದರೆ ವರ್ಚುವಲ್ ಪರಿಸರವನ್ನು ಎಡವಾಟದಂತೆ ಕಲಂತರಿಸಿ.

1. `app.py` ಫೈಲ್ ತೆರೆಯಿರಿ

1. `app.py` ಫೈಲ್‌ನ ಮೇಲೆ ಇತರ `import` ಹೇಳಿಕೆಗಳ ಜೊತೆಗೆ ಈ ಕೆಳಗಿನ ಕೋಡ್ ಸೇರಿಸಿ ಕೆಲವು ಅಗತ್ಯ ಲೈಬ್ರರಿಗಳನ್ನು ಆಮದು ಮಾಡಿಕೊಳ್ಳಲು:

    ```python
    import time
    from counterfit_shims_grove.grove_light_sensor_v1_2 import GroveLightSensor
    ```

    `import time` ಹೇಳಿಕೆ Python `time` ಗಣಕವನ್ನು ಆಮದು ಮಾಡುತ್ತದೆ, ಇದು ಈ ನಿಯೋಜನೆಯಲ್ಲಿ ಮುಂದಿನ ಹಂತಗಳಲ್ಲಿ ಬಳಕೆಯಾಗಲಿದೆ.

    `from counterfit_shims_grove.grove_light_sensor_v1_2 import GroveLightSensor` ಹೇಳಿಕೆ CounterFit Grove ಶಿಮ್ Python ಲೈಬ್ರರಿಗಳಿಂದ `GroveLightSensor` ಅನ್ನು ಆಮದು ಮಾಡುತ್ತದೆ. ಈ ಲೈಬ್ರರಿ ಕೌಂಟರ್‌ಫಿಟ್ ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ರಚಿಸಲಾದ ಲೈಟ್ ಸೆನ್ಸಾರ್ ನಿಯಂತ್ರಿಸಲು ಅವಕಾಶ ನೀಡುತ್ತದೆ.

1. ಲೈಟ್ ಸೆನ್ಸಾರ್ ನಿರ್ವಹಿಸುವ ಕ್ಲಾಸ್‌ಗಳ ಉದಾಹರಣೆಗಳನ್ನು ರಚಿಸಲು ಕೆಳಗಿನ ಕೋಡ್ ಫೈಲ್‌ನ ಕೆಳಭಾಗದಲ್ಲಿ ಸೇರಿಸಿ:

    ```python
    light_sensor = GroveLightSensor(0)
    ```

    `light_sensor = GroveLightSensor(0)` ಎಂಬ ಸಾಲು **0**ನೇ ಪಿನ್ (ಕೌಂಟರ್‌ಫಿಟ್ ಗ್ರೋವ್ ಪಿನ್)ಗೆ ಲೈಟ್ ಸೆನ್ಸಾರ್ ಅನ್ನು ಸಂಪರ್ಕಿಸುವ `GroveLightSensor` ಕ್ಲಾಸ್‌ನ ಉದಾಹರಣೆಯನ್ನು ರಚಿಸುತ್ತದೆ.

1. ಮೇಲಿನ ಕೋಡ್‌ನ ನಂತರ ಅನಂತ ಲೂಪ್ ಸೇರಿಸಿ, ಇದು ಲೈಟ್ ಸೆನ್ಸಾರ್ ಮೌಲ್ಯವನ್ನು ಪರಿಶೀಲಿಸಿ ಕನ್ಸೋಲ್‌ನಲ್ಲಿ ಮುದ್ರಿಸುತ್ತದೆ:

    ```python
    while True:
        light = light_sensor.light
        print('Light level:', light)
    ```

    ಇದು `GroveLightSensor` ಕ್ಲಾಸ್‌ನ `light` ಗುಣಲಕ್ಷಣದಿಂದ ಪ್ರಸ್ತುತ ಬೆಳಕಿನ ಮಟ್ಟವನ್ನು ಓದುತ್ತದೆ. ಈ ಗುಣಲಕ್ಷಣವು ಪಿನ್‌ನಿಂದ ಅನಲಾಗ್ ಮೌಲ್ಯವನ್ನು ಓದುತ್ತದೆ. ಆ ಮೌಲ್ಯವನ್ನು ನಂತರ ಕನ್ಸೋಲ್‌ಗೆ ಮುದ್ರಿಸಲಾಗುತ್ತದೆ.

1. `while` ಲೂಪ್ ಅಂತ್ಯದಲ್ಲಿ ಒಂದು ಸಣ್ಣ ನಿದ್ರೆ (ಒಂದು ಸೆಕೆಂಡು) ಸೇರಿಸಿ, ಬೆಳಕಿನ ಮಟ್ಟವನ್ನು ನಿರಂತರವಾಗಿ ಪರಿಶೀಲಿಸುವ ಅಗತ್ಯವಿಲ್ಲ. ನಿದ್ರೆ ಸಾಧನದ ವಿದ್ಯುತ್ ಬಳಕೆಯನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ.

    ```python
    time.sleep(1)
    ```

1. VS ಕೋಡ್ ಟರ್ಮಿನಲ್‌ನಿಂದ, ನಿಮ್ಮ Python ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಈ ಕೆಳಗಿನಂತೆ ಚಲಾಯಿಸಿ:

    ```sh
    python3 app.py
    ```

    ಬೆಳಕಿನ ಮೌಲ್ಯಗಳು ಕನ್ಸೋಲ್‌ಗೆ ಹೊರಗುಡಿಯುತ್ತವೆ. ಆರಂಭದಲ್ಲಿ ಈ ಮೌಲ್ಯ 0 ಆಗಿರುತ್ತದೆ.

1. ಕೌಂಟರ್‌ಫಿಟ್ ಅಪ್ಲಿಕೇಶನ್‌ನಿಂದ, ಅಪ್ಲಿಕೇಶನ್ ಓದುವ ಲೈಟ್ ಸೆನ್ಸಾರ್ ಮೌಲ್ಯವನ್ನು ಬದಲಾಯಿಸಿ. ನೀವು ಈ ಕಾರ್ಯವನ್ನು ಕೆಳಗಿನ ಎರಡು ವಿಧಾನಗಳಲ್ಲಿ ಮಾಡಬಹುದು:

    * ಲೈಟ್ ಸೆನ್ಸಾರ್‌ಗಾಗಿ *ಮೌಲ್ಯ* ಬಾಕ್ಸಿನಲ್ಲಿ ಸಂಖ್ಯೆ ನಮೂದಿಸಿ, ನಂತರ **ಸೆಟ್** ಬಟನ್ ಆಯ್ಕೆ ಮಾಡಿ. ನೀವು ನಮೂದಿಸಿದ ಸಂಖ್ಯೆ ಸೆನ್ಸಾರ್ ಹಿಂತಿರುಗಿಸುವ ಮೌಲ್ಯವಾಗಿರುತ್ತದೆ.

    * *ಆಕಸ್ಮಿಕ* ಚೆಕ್ಬಾಕ್ಸ್ ಅನ್ನು ಗುರುತಿಸಿ, ನಂತರ *ಕನಿಷ್ಠ* ಮತ್ತು *ಗರಿಷ್ಠ* ಮೌಲ್ಯಗಳನ್ನು ನಮೂದಿಸಿ, ನಂತರ **ಸೆಟ್** ಬಟನ್ ಆಯ್ಕೆ ಮಾಡಿ. ಪ್ರತಿಯೊಂದು ಬಾರಿ ಸೆನ್ಸಾರ್ ಮೌಲ್ಯ ಓದುವಾಗ, ಅದು ಕನಿಷ್ಠ ಮತ್ತು ಗರಿಷ್ಠ ನಡುವಿನ ಒಂದು ಯಾದೃಚ್ಛಿಕ ಸಂಖ್ಯೆಯನ್ನು ಓದುತ್ತದೆ.

    ನೀವು ಸೆಟ್ ಮಾಡಿದ ಮೌಲ್ಯಗಳು ಕನ್ಸೋಲ್‌ಗೆ ಹೊರಗುಡಿಯುತ್ತವೆ. ಮೌಲ್ಯವನ್ನು ಬದಲಾಯಿಸಲು *Value* ಅಥವಾ *Random* ಸೆಟ್ಟಿಂಗ್ಗಳನ್ನು ಬದಲಾಯಿಸಿ.

    ```output
    (.venv) ➜  GroveTest python3 app.py 
    Light level: 143
    Light level: 244
    Light level: 246
    Light level: 253
    ```
