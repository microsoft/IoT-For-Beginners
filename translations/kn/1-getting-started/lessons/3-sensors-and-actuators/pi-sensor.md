# ನೈಟ್‌ಲೈಟ್ ನಿರ್ಮಿಸಿ - ರಾಸ್ಪ್ಬೆರ್ರಿ ಪೈ

ಪಾಠದ ಈ ಭಾಗದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ರಾಸ್ಪ್ಬೆರ್ರಿ ಪೈಗೆ ಲೈಟ್ ಸೆನ್ಸರ್ ಅನ್ನು ಸೇರಿಸುವಿರಿ.

## ಹರ್ಡ್‌ವೇರ್

ಈ ಪಾಠಕ್ಕಾಗಿ ಸೆನ್ಸರ್ ಒಂದು **ಲೈಟ್ ಸೆನ್ಸರ್** ಆಗಿದ್ದು, ಅದು ಬೆಳಕು ಅನ್ನು ಎಲೆಕ್ಟ್ರಿಕಲ್ ಸಿಗ್ನಲ್‌ಗೆ ಪರಿವರ್ತಿಸುವ [ಫೋಟೋಡೈಓಡ್](https://wikipedia.org/wiki/Photodiode) ಅನ್ನು ಬಳಸುತ್ತದೆ. ಇದು ಒಂದು ಅನಾಲಾಗ್ ಸೆನ್ಸರ್ ಆಗಿದ್ದು, 0 ರಿಂದ 1,000 ರ ವರೆಗೆ ಇಂಟಿಜೆರ್ ಮೌಲ್ಯವನ್ನು ಕಳುಹಿಸುತ್ತದೆ, ಇದು ಲೈಟ್‌نىڭ ಸಂಬಂಧಿತ ಪ್ರಮಾಣವನ್ನು ಸೂಚಿಸುತ್ತದೆ ಮತ್ತು ಯಾವುದೇ ಪ್ರಮಾಣದ ಘಟಕಕ್ಕೆ (ಮಾದರಿ) เช่น [ಲಕ್ಸ್ನ](https://wikipedia.org/wiki/Lux) ಗೆ ಹೊಂದಿಕೊಳ್ಳದು.

ಲೈಟ್ ಸೆನ್ಸರ್ ಒಂದು ಹೊರಗಿನ Grove ಸೆನ್ಸರ್ ಆಗಿದ್ದು, ರಾಸ್ಪ್ಬೆರ್ರಿ ಪೈನಲ್ಲಿ Grove ಬೇಸ್ ಹ್ಯಾಟ್‌ಗೆ ಸಂಪರ್ಕಿಸಲು ಬೇಕಾಗುತ್ತದೆ.

### ಲೈಟ್ ಸೆನ್ಸರ್ ಅನ್ನು ಸಂಪರ್ಕಿಸಿ

ಬೆಳಕು ಮಟ್ಟಗಳನ್ನು ಕಂಡುಹಿಡಿಯಲು ಬಳಸುವ Grove ಲೈಟ್ ಸೆನ್ಸರ್ ಅನ್ನು ರಾಸ್ಪ್ಬೆರ್ರಿ ಪೈಗೆ ಸಂಪರ್ಕಿಸಬೇಕಾಗಿದೆ.

#### ಕಾರ್ಯ - ಲೈಟ್ ಸೆನ್ಸರ್ ಅನ್ನು ಸಂಪರ್ಕಿಸಿ

ಲೈಟ್ ಸೆನ್ಸರ್ ಅನ್ನು ಸಂಪರ್ಕಿಸಿ

![A grove light sensor](../../../../../translated_images/kn/grove-light-sensor.b8127b7c434e632d.png)

1. Grove ಕೇಬಲಿನ ಒಂದು ಅಂಚನ್ನು ಲೈಟ್ ಸೆನ್ಸರ್ ಮಾಗ್ಡ್ಯೂಲ್‌ನ ಸಾಕೆಟ್ನಲ್ಲಿ ಹಾಕಿ. ಅದು ಒಂದೇ ದಿಕ್ಕಿನಲ್ಲಿ ಮಾತ್ರ ಹೋಗುತ್ತದೆ.

1. ರಾಸ್ಪ್ಬೆರ್ರಿ ಪೈ ಪವರ್ ಆಫ್ ಮಾಡಿರುವಾಗ, Grove ಕೇಬಲಿನ ಇನ್ನೊಬ್ಬ ಅಂಚನ್ನು Grove ಬೇಸ್ ಹ್ಯಾಟ್ ಮೇಲೆ ಮಾರ್ಕ್ ಮಾಡಲಾದ **A0** అనಾಲೋಗ್ ಸಾಕೆಟ್ಗೆ ನೆಟ್ಟಗೆ. ಈ ಸಾಕೆಟ್ GPIO ಪಿನ್ಸ್ ಬಳಿ ಇರುವ ಸಾಲಿನಲ್ಲಿ ಬಲದಿಂದ ಎರಡನೆದು.

![The grove light sensor connected to socket A0](../../../../../translated_images/kn/pi-light-sensor.66cc1e31fa48cd7d.png)

## ಲೈಟ್ ಸೆನ್ಸರ್ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಿ

ಈ ಸಾಧನವನ್ನು Grove ಲೈಟ್ ಸೆನ್ಸರ್ ಬಳಸಿ ಈಗ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು.

### ಕಾರ್ಯ - ಲೈಟ್ ಸೆನ್ಸರ್ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಿ

ಸಾಧನವನ್ನು ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಿ.

1. ಪೈ ಅನ್ನು ಪವರ್ ಅಪ್ ಮಾಡಿ ಮತ್ತು ಬಂದಾಗ ಕಾಯಿರಿ

1. ಹಿಂದಿನ ಭಾಗದಲ್ಲಿ ನೀವು ರಚಿಸಿದ nightlight ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು VS ಕೋಡ್‌ನಲ್ಲಿ ತೆರೆಯಿರಿ, ನೇರವಾಗಿ ಪೈನಲ್ಲಿ ಅಥವಾ Remote SSH ವಿಸ್ತರಣೆ ಉಪಯೋಗಿಸಿ ಸಂಪರ್ಕಿಸಿ.

1. `app.py` ಫೈಲ್ ತೆರೆಯಿರಿ ಮತ್ತು ಅದರಲ್ಲಿನ ಎಲ್ಲಾ ಕೋಡ್ ಅಳಿಸಿ

1. ಕೆಳಗಿನ ಕೋಡ್ ಅನ್ನು `app.py` ಫೈಲ್‌ಗೆ ಸೇರಿಸಿ ಕೆಲವು ಅಗತ್ಯವಿರುವ ಗ್ರಂಥಾಲಯಗಳನ್ನು ಇಂಪೋರ್ಟ್ ಮಾಡಿ:

    ```python
    import time
    from grove.grove_light_sensor_v1_2 import GroveLightSensor
    ```

    `import time` ಹೇಳಿಕೆಯನ್ನು ಈ ಉಪವ್ಯವಸ್ಥೆಯಲ್ಲಿ ನಂತರ ಬಳಸುವ `time` ಮಾಯೂಡಲ್ ಅನ್ನು ಇಂಪೋರ್ಟ್ ಮಾಡುತ್ತದೆ.

    `from grove.grove_light_sensor_v1_2 import GroveLightSensor` ಹೇಳಿಕೆಯಿಂದ Grove ಪೈಥಾನ್ ಗ್ರಂಥಾಲಯಗಳಿಂದ `GroveLightSensor` ಅನ್ನು ಇಂಪೋರ್ ಮಾಡುತ್ತದೆ. ಈ ಗ್ರಂಥಾಲಯ Grove ಲೈಟ್ ಸೆನ್ಸರ್ ಜೊತೆ ಸಂಪರ್ಕಿಸಲು ಕೋಡ್ ಹೊಂದಿದೆ ಮತ್ತು ಪೈ ಸೆಟಪ್ ಸಮಯದಲ್ಲಿ ಗ್ಲೋಬಲಿ ಸ್ಥಾಪಿತವಾಯಿತು.

1. ಮೇಲಿನ ಕೋಡ್ ನಂತರ ಕೆಳಗಿನ ಕೋಡ್ ಅನ್ನು ಸೇರಿಸಿ, ಇದು ಲೈಟ್ ಸೆನ್ಸರ್ ನಿರ್ವಹಿಸುವ ವರ್ಗದ ಒಂದು ಇನ್ಸ್ಟಾನ್ಸ್ ಅನ್ನು ರಚಿಸುತ್ತದೆ:

    ```python
    light_sensor = GroveLightSensor(0)
    ```

    `light_sensor = GroveLightSensor(0)` ಸಾಲು `GroveLightSensor` ವರ್ಗದ ಒಂದು ಇನ್ಸ್ಟಾನ್ಸ್ ರಚಿಸಿ, ಪಿನ್ **A0** ಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ - ಇದು ಲೈಟ್ ಸೆನ್ಸರ್ ಸಂಪರ್ಕಿತ ಅನಾಲಾಗ್ Grove ಪಿನ್.

1. ಮೇಲಿನ ಕೋಡ್ ನಂತರ ಒಂದು ಶಾಶ್ವತ ಲೂಪ್ ಸೇರಿಸಿ, ಇದು ಲೈಟ್ ಸೆನ್ಸರ್ ಮೌಲ್ಯವನ್ನು_poll ಮಾಡಿ ಕಾನ್ಸೋಲ್‌ಗೆ ಮುದ್ರಿಸುತ್ತದೆ:

    ```python
    while True:
        light = light_sensor.light
        print('Light level:', light)
    ```

    ಇದು `GroveLightSensor` ವರ್ಗದ `light` ಪ್ರಾಪರ್ಟಿಯನ್ನು ಉಪಯೋಗಿಸಿ 0-1,023 ಮಿತಿಯೊಳಗಿನ ಪ್ರಸ್ತುತ ಲೈಟ್ ಮಟ್ಟವನ್ನು ಓದುತ್ತದೆ. ಈ ಪ್ರಾಪರ್ಟಿ ಪಿನ್‌ನಿಂದ ಅನಾಲಾಗ್ ಮೌಲ್ಯವನ್ನು ಓದುತ್ತದೆ. ನಂತರ ಈ ಮೌಲ್ಯ ಕಾನ್ಸೋಲ್‌ಗೆ ಮುದ್ರಿಸಲ್ಪಡುತ್ತದೆ.

1. ಲೈಟ್ ಮಟ್ಟಗಳನ್ನು ನಿರಂತರವಾಗಿ ಪರಿಶೀಲಿಸುವ ಅಗತ್ಯವಿಲ್ಲದ ಕಾರಣ, ಲೂಪಿನ ಕೊನೆಯಲ್ಲಿ ಒಂದು ಸೆಕೆಂಡ್ ನಿದ್ರೆಯನ್ನು ಸೇರಿಸಿರಿ. ನಿದ್ರೆ ಸಾಧನದ ಶಕ್ತಿಯ ಬಳಕೆಯನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ.

    ```python
    time.sleep(1)
    ```

1. VS ಕೋಡ್ ಟೆರ್ಮಿನಲ್‌ನಿಂದ ನಿಮ್ಮ ಪೈಥಾನ್ ಅಪ್ಲಿಕೇಶನ್ ಚಾಲನೆ ಮಾಡಲು ಕೆಳಗಿನ ಆಜ್ಞೆಯನ್ನು ಚಲಾಯಿಸಿ:

    ```sh
    python3 app.py
    ```

    ಲೈಟ್ ಮೌಲ್ಯಗಳು ಕಾನ್ಸೋಲ್ ಗೆ ಔಟ್‌ಪುಟ್ ಆಗುತ್ತವೆ. ಲೈಟ್ ಸೆನ್ಸರ್ ಮುಚ್ಚಿ ತೆಗೆಯಿರಿ, ಮೌಲ್ಯಗಳು ಬದಲಾಗುತ್ತವೆ:

    ```output
    pi@raspberrypi:~/nightlight $ python3 app.py 
    Light level: 634
    Light level: 634
    Light level: 634
    Light level: 230
    Light level: 104
    Light level: 290
    ```
