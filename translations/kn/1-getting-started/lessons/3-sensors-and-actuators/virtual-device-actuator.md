# ರಾತ್ರಿರಭ್ಯ ಬೆಳಕು ನಿರ್ಮಿಸಿ - ವರ್ಚುವಲ್ IoT ಹಾರ್ಡ್‌ವೇರ್

ಪಾಠದ ಈ ಭಾಗದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ವರ್ಚುವಲ್ IoT ಸಾಧನಕ್ಕೆ ಒಂದು LED ಅನ್ನು ಸೇರಿಸಿ ಅದನ್ನು ರಾತ್ರಿರಭ್ಯ ಬೆಳಕಾಗಿ ಬಳಸಲಿವೆ.

## ವರ್ಚುವಲ್ ಹಾರ್ಡ್‌ವೇರ್

ರಾತ್ರಿರಭ್ಯ ಬೆಳಕಿಗೆ ಒಂದು ಕ್ರಿಯಾಪ್ರಣಾಳಿಕೆಯು ಬೇಕಾಗಿದ್ದು, ಅದನ್ನು CounterFit ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ರಚಿಸಲಾಗಿದೆ.

ಆ ಕ್ರಿಯಾಪ್ರಣಾಳಿಕೆ ಒಂದು **LED** ಆಗಿದೆ. ಭೌತಿಕ IoT ಸಾಧನದಲ್ಲಿ, ಇದು [ಲಾಗುತ್ತಿರುವ ಡಯೋಡ್](https://wikipedia.org/wiki/Light-emitting_diode) ಆಗಿದ್ದು, ಅದರಲ್ಲಿ ವಿದ್ಯುತ್ ಹರಿಯುವಾಗ ಬೆಳಕು ಹೊರಹೊಮ್ಮುತ್ತದೆ. ಇದು ಡಿಜಿಟಲ್ ಕ್ರಿಯಾಪ್ರಣಾಳಿಕೆಯಾಗಿದೆ, ಅದು 2 ಸ್ಥಿತಿಗಳಲ್ಲಿ ಇರುತ್ತದೆ: ಆನ್ ಮತ್ತು ಆಫ್. 1 ಮೌಲ್ಯವನ್ನು ಕಳುಹಿಸುವುದು LED ಅನ್ನು ಆನ್ ಮಾಡುತ್ತದೆ ಮತ್ತು 0 ಕಳುಹಿಸುವುದು ಅದನ್ನು ಆಫ್ ಮಾಡುತ್ತದೆ.

ರಾತ್ರಿರಭ್ಯ ಬೆಳಕಿನ ಲಾಜಿಕ್ ಸೂತ್ರದಲ್ಲಿ:

```output
Check the light level.
If the light is less than 300
    Turn the LED on
Otherwise
    Turn the LED off
```

### CounterFitಗೆ ಕ್ರಿಯಾಪ್ರಣಾಳಿಕೆ ಸೇರಿಸಿ

ವರ್ಚುವಲ್ LED ಬಳಕೆಗೆ, ಅದನ್ನು CounterFit ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಸೇರಿಸಬೇಕಿದೆ

#### ಕೆಲಸ - CounterFitಗೆ ಕ್ರಿಯಾಪ್ರಣಾಳಿಕೆ ಸೇರಿಸಿ

LED ಅನ್ನು CounterFit ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಸೇರಿಸಿ.

1. ಈ ನಿಯೋಜನೆಯ ಹಿಂದಿನ ಭಾಗದಿಂದ CounterFit ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್ ಚಾಲನೆಯಲ್ಲಿದೆ ಎಂದು ಖಚಿತಪಡಿಸಿ. ಇಲ್ಲದಿದ್ದರೆ, ಅದನ್ನು ಪ್ರಾರಂಭಿಸಿ ಮತ್ತು ಲೈಟ್ ಸೆನ್ಸರ್ ಅನ್ನು ಮತ್ತೆ ಸೇರಿಸಿ.

1. ಒಂದು LED ರಚಿಸಿ:

    1. *Actuator* ವಿಭಾಗದಲ್ಲಿರುವ *Create actuator* ಬಾಕ್ಸಿನಲ್ಲಿ, *Actuator type* ಬಾಕ್ಸನ್ನು ಡ್ರೋಪ್ ಮಾಡಿ ಮತ್ತು *LED* ಆಯ್ಕೆಮಾಡಿ.

    1. *Pin* ಅನ್ನು *5* ಆಗಿ ಸೆಟ್ ಮಾಡಿ

    1. LED ಅನ್ನು Pin 5 ರಲ್ಲಿ ಸೃಷ್ಟಿಸಲು **Add** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ

    ![The LED settings](../../../../../translated_images/kn/counterfit-create-led.ba9db1c9b8c622a6.png)

    LED ಸೃಷ್ಟಿಯಾಗುತ್ತದೆ ಮತ್ತು ಅದನ್ನು ಕ್ರಿಯಾಪ್ರಣಾಳಿಕೆ ಪಟ್ಟಿ ಹೋಲಿಕೆಯ ಚಿತ್ರಣದಲ್ಲಿ ಕಾಣಿಸಿಕೊಡುತ್ತದೆ.

    ![The LED created](../../../../../translated_images/kn/counterfit-led.c0ab02de6d256ad8.png)

    LED ಸೃಷ್ಟಿಯಾದ ಮೇಲೆ, *Color* ಆಯ್ಕೆಕಾರವನ್ನು ಬಳಸಿಕೊಂಡು ಬಣ್ಣವನ್ನು ಬದಲಾಯಿಸಬಹುದು. ಆಯ್ಕೆ ಮಾಡಿದ ನಂತರ ಬಣ್ಣ ಬದಲಿಸಲು **Set** ಬಟನ್ ಆಯ್ಕೆಮಾಡಿ.

### ರಾತ್ರಿರಭ್ಯ ಬೆಳಕಿಗೆ ಪ್ರೋಗ್ರಾಂ ಬರೆಯಿರಿ

ಈ ರಾತ್ರಿರಭ್ಯ ಬೆಳಕನ್ನು CounterFit ಲೈಟ್ ಸೆನ್ಸರ್ ಮತ್ತು LED ಬಳಸಿ ಪ್ರೋಗ್ರಾಮ್ ಮಾಡಬಹುದು.

#### ಕೆಲಸ - ರಾತ್ರಿರಭ್ಯ ಬೆಳಕಿಗೆ ಪ್ರೋಗ್ರಾಮ್ ಬರೆಯಿರಿ

ರಾತ್ರಿರಭ್ಯ ಬೆಳಕಿಗೆ ಪ್ರೋಗ್ರಾಮ್ ಬರೆಯಿರಿ.

1. ನೀವು ಈ ನಿಯೋಜನೆಯ ಹಿಂದಿನ ಭಾಗದಲ್ಲಿ ರಚಿಸಿದ್ದ ರಾತ್ರಿರಭ್ಯ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು VS Code ನಲ್ಲಿ ತೆರೆಯಿರಿ. ಟರ್ಮिनಲ್ ಅನ್ನು ಕೊಚ್ಚಿ ಮರು ರಚಿಸಿ, virtual environment ಬಳಕೆಯೊಂದಿಗೆ ಅದು ಬೆಳೆಯುತ್ತಿದೆಯೆಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.

1. `app.py` ಫೈಲ್ ತೆರೆಯಿರಿ

1. ಕೆಳಗಿನ ಕೋಡ್ ಅನ್ನು `app.py` ಫೈಲ್‌ಗೆ ಸೇರಿಸಿ, ಅಗತ್ಯ ಗ್ರಂಥಾಲಯವನ್ನು ಆಮದುಮಾಡಲು. ಇದು ಇತರ `import` ಸಾಲುಗಳ ಕೆಳಗೆ ಮೇಲ್ಭಾಗದಲ್ಲಿ ಸೇರಿಸಬೇಕು.

    ```python
    from counterfit_shims_grove.grove_led import GroveLed
    ```

    `from counterfit_shims_grove.grove_led import GroveLed` ಹೇಳಿಕೆಯು CounterFit Grove ಶಿಂ Python ಗ್ರಂಥಾಲಯದಿಂದ `GroveLed` ಅನ್ನು ಆಮದು ಮಾಡಿಕೊಳ್ಳುತ್ತದೆ. ಈ ಗ್ರಂಥಾಲಯಕ್ಕೆ CounterFit ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ರಚಿಸಿದ LED ಜೊತೆಗೆ ಸಂವಹನ ಮಾಡಲು ಕೋಡ್ ಇದೆ.

1. `light_sensor` ಘೋಷಣೆಯ ನಂತರ ಈ ಕೆಳಗಿನ ಕೋಡ್ ಅನ್ನು ಸೇರಿಸಿ, LED ನಿರ್ವಹಿಸುವ ಕ್ಲಾಸ್‌ನ ಉದಾಹರಣೆ ಸೃಷ್ಟಿಸಲು:

    ```python
    led = GroveLed(5)
    ```

    `led = GroveLed(5)` ಈ ಸಾಲು CounterFit Grove ಪಿನ್ **5** ಜೋಡಿಸುವ `GroveLed` ಕ್ಲಾಸ್‌ನ ಉದಾಹರಣೆಯನ್ನು ಸೃಷ್ಟಿಸುತ್ತದೆ - LED ಇಲ್ಲಿ ಜೋಡಿಸಲಾಗಿದೆ.

1. `while` ಲೂಪ್ ಒಳಗೆ, `time.sleep` ಮುಂಚೆ ಲೈಟ್ ಮಟ್ಟವನ್ನು ಪರಿಶೀಲಿಸಿ LED ಅನ್ನು ಆನ್ ಅಥವಾ ಆಫ್ ಮಾಡಲು ಕೆಳಗಿನ ಚೆಕ್ ಸೇರಿಸಿ:

    ```python
    if light < 300:
        led.on()
    else:
        led.off()
    ```

    ಈ ಕೋಡ್ `light` ಮೌಲ್ಯವನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ. ಇದು 300 ಕಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ `GroveLed` ಕ್ಲಾಸಿನ `on` ವಿಧಾನವನ್ನು ಕರೆಸುತ್ತದೆ, ಇದು LED ಗೆ 1 ಡಿಜಿಟಲ್ ಮೌಲ್ಯ ಕಳುಹಿಸಿ ಅದನ್ನು ಆನ್ ಮಾಡುತ್ತದೆ. ಲೈಟ್ ಮೌಲ್ಯ 300 ಅಥವಾ ಅದಕ್ಕಿಂತ ಹೆಚ್ಚು ಇದ್ದರೆ `off` ವಿಧಾನವನ್ನು ಕರೆಸಿ 0 ಡಿಜಿಟಲ್ ಮೌಲ್ಯ ಕಳುಹಿಸಿ LED ಅನ್ನು ಆಫ್ ಮಾಡುತ್ತದೆ.

    > 💁 ಈ ಕೋಡ್ `print('Light level:', light)` ಸಾಲಿನ ಮಟ್ಟದಾದಷ್ಟು ಇಂದೆಂಟ್ ಮಾಡಬೇಕು, ಅಂದರೆ ಲೂಪ್ ಒಳಗೆ ಇರಬೇಕು!

1. VS Code ಟರ್ಮಿನಲ್‌ನಿಂದ, ನಿಮ್ಮ Python ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಕೆಳಗಿನಂತೆ ಚಾಲನೆ ಮಾಡಿ:

    ```sh
    python3 app.py
    ```

    ಲೈಟ್ ಮೌಲ್ಯಗಳು ಕಂಸೋಲ್‌ಗೆ ಔಟ್‌ಪುಟ್ ಆಗಲಿವೆ.

    ```output
    (.venv) ➜  GroveTest python3 app.py 
    Light level: 143
    Light level: 244
    Light level: 246
    Light level: 253
    ```

1. *Value* ಅಥವಾ *Random* ಸೆಟ್ಟಿಂಗ್ಸ್ ಬದಲಿಸಿ ಲೈಟ್ ಮಟ್ಟವನ್ನು 300 ಯೊಳಗಿನ ಮತ್ತು ಮೇಲಿನ ಮಾಪಿಸಲು. LED ಆನ್ ಮತ್ತು ಆಫ್ ಆಗುತ್ತದೆ.
